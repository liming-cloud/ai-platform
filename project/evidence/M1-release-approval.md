## M1 批准范围

- 复核 `WP-0009` 的全量验证、代码走查和容器交付演练证据。
- 接受 M1 仅为可部署受限演示，不构成生产就绪、真实模型质量或商业容量承诺。
- 接受门店与校园合成数据、确定性模型、回环网络、固定评测和已登记剩余风险作为 M1 演示边界。
- 确认产品、测试和运维职责共同批准 M1 退出，允许将当前里程碑切换到 M2。

## 后续真实模型调用授权

用户批准后续研发使用阿里云百炼进行真实模型调用，但授权仅覆盖研发、测试和受控验收环境，不覆盖生产发布。

- 真实调用优先使用现有 `OPENAI_COMPATIBLE` 扩展；若协议、公共契约、密钥存储或出站策略需要变化，必须先新增 ADR 和工作包。
- API Key 只能由未提交的部署密钥或受管密钥存储注入；不得写入 Git、文档、日志、测试快照、接口响应或聊天摘要。
- 调用前后必须遵守 ADR-0010 的地址校验、短生命周期密钥清零、超时、异常脱敏和预算限制。
- 实际调用前必须确认模型名称、区域、预算上限、调用环境和可复核的脱敏验收方法；本批准记录不代替该次调用的执行记录。
- 本授权在 M5 开始前有效；若适配器、密钥存储或出站安全策略发生变化，则提前失效并重新评审。
