# WP-0005：供应商连接治理闭环证据

## 结论

供应商连接已经形成首个可部署纵向闭环：租户管理员可在受控权限和配额内创建、
幂等重放、分页读取并探测连接；数据库只保存密钥引用，公共响应不返回密钥引用；
租户隔离、乐观锁和连接名称唯一性由应用与 PostgreSQL 共同保证。

实现提交：`205838492`

## 已证明行为

- 创建、列表和探测接口只从可信请求上下文取得租户与权限。
- 创建请求需要幂等键；相同请求可重放，不同请求复用同一幂等键会被拒绝。
- 租户连接配额在事务级租户锁内校验，避免并发请求突破上限。
- 连接名称在租户内不区分大小写且唯一。
- 探测更新使用乐观版本，过期版本不能覆盖新事实。
- 密钥明文不进入数据库；公共视图只返回“已配置凭据”事实。
- 游标分页有长度、编码、时间和标识格式校验。
- 两个演示租户的模型读取和写入权限已显式授权，数据相互隔离。
- 控制面可在最小启动测试中关闭模型目录，不强制装配数据库映射器。
- 容器镜像可从迁移版本 `202607270005` 正常启动，并完成创建、探测和列表脱敏。
