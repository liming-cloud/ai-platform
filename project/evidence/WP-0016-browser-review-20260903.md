## 必须关闭的缺陷

| 编号 | 复现与原因 | 退出条件 |
| --- | --- | --- |
| WP-0016-B01 | 打开 `screen=login&state=success` 无账号/密码表单，反而显示租户管理员导航。图谱证实 `renderScreen` 没有调用已有 `renderLogin`，落入通用页面 | 独立登录入口、字段校验、拒绝和进入授权助手的完整原型通过浏览器测试 |
| WP-0016-B02 | 发送问题，等待 COMPLETED 后刷新，新问题消失。`submitQuestion` 只追加 DOM 和固定答案，却显示“已持久化/已原子提交” | 创建、续问、刷新、切换历史与断线恢复由同一合成会话状态驱动；移除无依据成功提示 |
| WP-0016-B03 | 390px 的平台角色页在 success/partial/disabled 下宽度约 445px；英文角色码撑宽且双栏重叠 | 自然中文角色名、详情布局与长内容换行经三档视口回归，无遮盖与文档级溢出 |
| WP-0016-B04 | 1280×720 展开原型审查器并重置后，summary 超出视口，无法点击收起，还遮挡页面操作 | 审查器自身可滚动、关闭入口始终可达，不遮断产品任务；键盘及低高度视口通过 |

- 首次执行在第 3 条断言后因未展开 details 直接点击 `#review-reset` 超时；原 catch 错误写成“未授权”。实际已启动 Chromium，不能沿用该归因。
