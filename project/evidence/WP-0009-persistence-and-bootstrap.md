## 4. 边界结论

- MyBatis-Plus 的 Page、IPage 和 Wrapper 没有进入领域层、应用层和公共响应。
- 事件序号回放保留固定 LIMIT，但登记为 `EVENT_REPLAY`，不属于列表分页。
- bootstrap 主代码每个模块只保留一个 Spring Boot 启动类。
- 各业务 Bean 由所属上下文、平台或扩展的自动配置创建，bootstrap 未新增集中业务装配。
- 全量容器与走查证据尚未完成，因此 WP-0009 和 M1 继续保持阻塞。
