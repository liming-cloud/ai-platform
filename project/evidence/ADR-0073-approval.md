# ADR-0073 人工接受记录

用户于 2026-08-31 明确回复“接受 ADR-0073 方案 A”。

本次接受授权以下产品与安全语义进入红绿实现：

- 平台管理员独占租户管理员的建立、分配、替换、停用和恢复；
- 租户管理员只治理当前租户普通成员；
- 活动平台管理员绑定与启用租户成员资格互斥，历史撤销／停用事实可保留；
- 平台角色绑定、租户建立、成员建立和成员启用在共同 `SubjectIdentity` 行锁后复核对侧事实；
- 候选目录与命令资格谓词保持一致，但候选过滤不替代服务端命令授权；
- 该决策只在双重活动身份处取代 ADR-0072 第 2 条，平台仍无租户知识库正文能力。

本次接受不授权租户自定义角色、个人直接权限、平台读取租户正文、账户硬删除、生产环境自动修复冲突
