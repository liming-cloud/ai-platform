# WP-0002 后端工程基线证据

## 证据范围

- Maven Wrapper 固定为 3.9.16。
- JDK 门禁固定为 26.0.2。
- Spring Boot、Spring AI、Sa-Token、MyBatis-Plus、Hutool 和 Spring Modulith 使用 ADR-0006 批准版本。
- 根 Maven 反应堆、平台内核、模型运行时上下文、确定性供应商扩展和三个运行入口已建立。
- 供应商探测公共契约不暴露 Spring AI 类型和明文凭据。
- 三个运行入口可以在无外部基础设施时完成最小上下文启动。
- 模型核心和厂商扩展的依赖方向由 ArchUnit 验证。

## 验证命令

```bash
./mvnw --version
./mvnw -q clean test
```

## 验证结果

- Maven：3.9.16。
- Java：26.0.2。
- 构建结果：通过。
- 单元、运行入口和架构测试：通过。
- 验证时间：2026-07-26T23:27:55+08:00。

## 已发现并关闭的问题

- 首轮严格编译发现异常类缺少序列化版本号，已修正。
- ArchUnit 1.4.1 无法分析 JDK 26 字节码，升级至正式版 1.4.2 后通过全量清理构建。

## 边界

该证据只证明 WP-0002 的后端工程基线和第一条本地确定性供应商契约，不表示六个上下文、真实 OpenAI 兼容探测、前端、Docker Compose 或 M1 演示闭环已经完成。
