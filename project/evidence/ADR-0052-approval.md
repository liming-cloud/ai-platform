# ADR-0052 人工接受记录

## 决策

用户于 2026-08-05 接受 ADR-0052 方案 A：M6 评测数据集登记、运行触发和自动发布决定复用同租户
`assistant:write`；实际发布仍必须同时满足该权限和与目标草稿修订完全匹配的 `ReleaseAuthorization`。

## 授权范围

- 可在 WP-0014 内实现私有评测内容端口、评测／决定应用编排、发布授权接入、真实 PostgreSQL、自动配置和受限 HTTP。
- 实现必须证明令牌派生授权、同租户边界、无正文投影和不匹配授权失败关闭。

## 仍不授权

本次不授权独立评测角色、正文读取、人工例外、预算、审计导出、成员权限管理、M7 或 M8 实现。
