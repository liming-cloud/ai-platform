# ADR-0070 人工接受

用户于 2026-08-24 明确人工确认并授权执行平台供应商权威模型发现切片：优先覆盖火山方舟与
OpenAI-compatible 连接；火山方舟分别使用推理 API Key 与控制面 AK/SK；元数据不足时进入管理员确认，
不得按模型名称猜测 `CHAT`／`EMBEDDING` 能力。

用户同时授权为验收执行最小真实火山方舟／OpenAI-compatible 读取和能力探测调用，并接受其必要费用；
实现仍不得向页面、日志或证据泄露供应商原始响应、错误码、内部标识、Endpoint 或秘密。

验收范围固定为红绿 TDD、真实 PostgreSQL、HTTP、Compose 与 Chrome，并续证 1024×768、390×844、
真实 200% 缩放、键盘导航和 `prefers-reduced-motion`。本次只授权本地中文提交，不授权推送或生产发布。

该记录只提供当前仓库和对话的本地追溯，不声明用户身份的密码学验签。M6 与 `WP-0014` 保持进行中；
全部供应链、助手、评测、问答和人工评审证据完成前不得进入 M7。
