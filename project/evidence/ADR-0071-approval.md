# ADR-0071 人工接受

用户于 2026-08-28 明确要求把平台管理员重新初始化为账号 `admin`、密码 `admin@123`，并在只更新现有
账户与完全重制之间选择“完全重制”。

该授权只适用于当前项目的本地 Compose：在可恢复完整备份后重建 `foundation_v1` PostgreSQL 数据库，
并清空同一项目 Redis 的本地会话状态。MinIO、Git 文件、其他项目及共享、测试、预发布和生产环境均不在
删除范围。旧 `platform.root`、旧密码和旧会话必须失效。

M6 与 `WP-0014` 保持进行中，本次重制不构成人工验收通过，也不激活 M7。
