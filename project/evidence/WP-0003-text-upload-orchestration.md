# WP-0003 文本内容上传编排证据

## 证据边界

本证据验收存储无关的文本上传与发布编排，不代表 MinIO 客户端选型、正式对象存储适配器、控制台任务流或 Docker 全新卷验收已经完成。

- 实现提交：`c79ec9c4d7d214aace7781852bb004e6e2e010d3`
- 关联决策：`ADR-0014`
- 验证日期：2026-07-27
- 验证环境：macOS、JDK 26.0.2、Maven Wrapper 3.9.16、Docker Desktop、PostgreSQL 18.4 与 Redis 8.8.1 测试容器

## 红灯证据

```bash
./mvnw -q -pl backend/runtimes/control-plane -am \
  -Dtest=TextDataSourceApiTest \
  -Dsurefire.failIfNoSpecifiedTests=false test
```

首次接入受控测试存储时，控制平面同时存在拒绝型默认适配器与测试适配器，应用上下文因对象存储端口候选不唯一而启动失败。将测试适配器显式声明为测试环境主实现后恢复绿灯，生产默认行为仍为拒绝型适配器。

## 绿灯证据

```bash
./mvnw -q -pl backend/contexts/knowledge-data,backend/runtimes/control-plane -am test
make backend-test
make project-verify
```

结果：

- `POST /api/v1/data-sources/{id}/content` 直接接收请求流，不在控制器中构造整文件字节数组。
- 上传只接受带 UTF-8 字符集声明的纯文本，统一经过 20 MiB 平台上限、严格字符集、SHA-256 和临时文件清理治理。
- 对象写入发生在数据库登记之前；对象引用的内容版本、摘要、字节数和媒体类型不一致时拒绝登记。
- 相同幂等键和相同请求可历史重放，不重复写入对象；相同幂等键和不同内容摘要由数据库幂等事实拒绝。
- 发布前重新读取对象元数据并与数据库引用逐项核验；元数据被篡改时返回网关错误，数据源保持内容就绪且不产生发布事件。
- 未配置正式对象存储时，写入、读取元数据和删除均明确返回服务不可用，不产生伪成功。
- 应用服务只依赖对象存储端口，公共契约不暴露具体客户端或厂商类型。
- 全后端清理测试、真实 PostgreSQL 与 Redis 接口测试、架构规则、7 项治理测试和控制面一致性校验通过。

## 失败语义

- 请求内容或媒体类型不合法：客户端请求错误。
- 对象存储未配置或暂时不可用：服务不可用。
- 对象存储元数据与数据库事实不一致：上游完整性错误。
- 暂存或请求流读取失败：服务不可用。
- 数据库登记失败后可能遗留未引用对象，后续由独立清理任务处理；请求线程不执行破坏性补偿删除。

## 当前结论

文本数据源已经具备不可绕过的上传与发布编排接缝。正式 MinIO 适配器仍需在批准的一手资料研究后实现，本证据中的受控测试适配器只用于验证协议和失败语义，不能作为对象存储交付证据。
