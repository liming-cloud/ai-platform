# WP-0003 门店与校园合成检索数据证据

## 证据边界

- 工作包：WP-0003
- 实现提交：`8078142163c64841fc59e548cc50df453676bb96`
- 执行环境：当前 macOS 工作区、JDK 26.0.2、Docker Desktop
- 数据范围：连锁门店商品知识、高校公共信息与图书馆知识

## 已验证事实

1. 门店与校园数据分别使用 `demo-store`、`demo-campus` 租户编码，未混合行业概念到核心领域模型。
2. 两份知识文本均明确标记为合成数据，并声明数据口径和禁止收集或承诺的边界。
3. 门店数据覆盖商品位置、含税价格、最近三十日销量、库存状态和人工服务兜底。
4. 校园数据覆盖图书馆开放、借阅规则、校园卡服务和空间预约。
5. 八条检索用例均声明预期记录和回答必须包含的事实，校验器确认记录引用及答案要点真实存在于知识文本。
6. 清单固定知识文件路径、严格 UTF-8、二十兆字节上限和 SHA-256 内容摘要，变更后必须同步更新摘要。
7. 路径越界、摘要不一致、缺少合成标识、重复用例编号和不存在的答案要点均会失败关闭。
