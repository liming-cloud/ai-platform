# WP-0014 全 SPA UI 重构代码审查

- 审查基线：`12ad62d46d531f9c794ff49c9443861f8b46ea14`
- 审查候选：当前工作区纵向切片
- 规范来源：仓库 `AGENTS.md`、`project/CHARTER.md`、`project/STATE.yaml`、`WP-0014`、ADR-0059、ADR-0067、ADR-0068、ADR-0069，以及 `docs/design/m6-full-spa-ui-redesign.md`

## 规范轴

- 修改只落在共享设计令牌、`ProductShell`、登录入口、`ConsoleApp` 任务导航、回归测试和本工作包证据；未改变 API、数据库、认证、会话或权限边界。
- 继续使用既有 React、Vite 和 Fluent UI React v9；没有因视觉重构引入第二套组件栈或推测性通用页面框架。
- 新增源码自然语言均为简体中文；未新增无工作包 TODO、内部标识输入、原始后端信息或 Emoji 产品图标。
- 工作区原有无关修改为零；本地数据库重置有精确目标、可恢复备份和重置后事实核对。

## 需求轴

- 共享壳具备明确页面标题、上下文、摘要、导航状态、账户角色和已有加载／拒绝／错误恢复状态。
- 登录入口以单一真实任务卡承载平台／租户选择和凭据输入；产品上下文克制呈现，不使用渐变、玻璃态、巨大指标或装饰性卡片堆叠。
- 桌面、紧凑侧栏和移动底栏均有 CSS 契约；导航统一使用 Fluent 图标与 Tooltip，二级任务改用具备键盘语义的 `TabList`。
- 页面只显示三个角色的中文产品名称；没有把枚举、内部标识、异常、追踪字段或厂商原始响应新增到可见层。

## 六维结论

- 正确性：红绿回归、前端 128 项测试、真实基础设施后端和生产构建通过；审查中发现的两处登出回调缺失已先红后绿修复。
- 复杂度：实现依赖三个既有 seam，仅增加局部 `LoginFrame` 和 `TaskNavigation`。
- 冗余：重复任务按钮条和重复登录外框均已收敛。
- 性能：候选生产构建 profile 已登记；没有新增请求、轮询、客户端分页聚合或运行时依赖。没有把构建体积证据扩大成 Web Vitals 结论。
- 架构：前端组合层变化，不跨越服务和上下文边界。
- 测试质量：静态结构契约适合防止视觉基线倒退，已有全量行为测试兜底；物理窄屏和登录后主流程仍必须由操作电脑证据补齐。

## 结论

规范轴和需求轴未发现尚未解决的源码阻断项。操作电脑主流程、1024×768、390×844、真实 200% 缩放与 `prefers-reduced-motion` 是人工验收阻断，不是可以由本代码审查豁免的项目；因此 M6 与 WP-0014 继续进行中。
