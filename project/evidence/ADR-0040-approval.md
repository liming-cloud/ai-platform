# ADR-0040 人工接受记录

| 字段 | 值 |
| --- | --- |
| 决定编号 | ADR-0040 |
| 决定类型 | M5 模型能力与公共契约边界 |
| 结论 | 用户接受冻结聊天模型路由、有限回退和内部调用轨迹设计。 |
| 批准人 | 用户，代表产品与架构负责人。 |
| 批准时间 | 2026-08-02 |
| 提议基线 | `b3a4583d5`、`42757f34a` |

## 接受范围

- 新发布助手版本可以冻结一个主聊天候选和最多两个后备候选；仅标准化瞬态调用失败可在未交付正文前回退。
- 嵌入模型保持单一且与已发布索引兼容；不因聊天调用失败回退。
- 路由执行只能由 model-runtime 的唯一门面承担；普通查询与草稿测试继续经同一可信回答执行路径。
- 内部调用轨迹与各自运行终态原子提交，且不增加 `QueryDiagnostic` 的公开字段或留存敏感正文、端点、凭据和供应商原始错误。

## 不授权范围

- 工具、MCP、多模态、音频、用户配置厂商／端点／密钥。
- M6 的预算、评测、发布审批或审计导出，以及 M7、M8 的任何功能。

本记录使 ADR-0040 成为 `WP-0013` 可实施的仓库事实；后续实现仍必须先产生实际红灯测试并按工作包证据合同验证。
