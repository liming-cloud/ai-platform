# WP-0013：M5 冻结聊天路由 TDD 路线

## 状态与前置条件

| 项目 | 内容 |
| --- | --- |
| 状态 | 设计路线，尚未执行红灯或实现。 |

| 不允许修改 | 已发布索引的嵌入绑定、M4 的 `QueryDiagnostic` 响应、普通查询 `PUBLISHED` 边界、令牌派生身份语义。 |

ADR-0040 未接受前，本记录只约束未来测试顺序，不创建测试或生产代码，因而不存在可报告的实际红灯或绿灯。

## 红绿切片顺序

| 切片 | 先写的红灯反例 | 最小实现边界 | 绿灯与回归证据 |
| --- | --- | --- | --- |
| 1. 冻结聊天路由值 | 拒绝空路由、非 `CHAT` 候选、重复候选、超过一主两备、未冻结修订和嵌入候选混入。 | 在 `AssistantVersion` 所属上下文增加不可变路由值对象；不创建实体、仓储或页面。 | 纯领域测试，既有助手版本发布与快照回归。 |
| 2. 受控路由执行 | 主候选的标准化可回退失败后才调用下一候选；权限、配置不匹配、检索、引用或未分类失败绝不调用后备。 | model-runtime 的唯一 `ChatRouteExecutor` 门面；不把循环放入 `QueryRunService` 或 `AssistantTestRunService`。 | model-runtime 应用测试；`AssistantTrustedAnswerExecutor` 委派与现有可信引用回归。 |
| 3. 执行目标传播 | 普通查询和草稿测试均只消费同一冻结路由，历史单绑定版本保持原行为。 | 扩展公开助手执行快照，保持向后兼容；不读取当前助手版本。 | assistant-delivery 与 trusted-query 应用测试、自动配置测试。 |
| 4. 最小调用轨迹 | 轨迹不得含问题、回答、提示词、候选正文、端点、原始供应商错误、密钥或令牌；终态任一写入失败整体回滚。 | 各运行所属持久化边界中的内部不可变投影；不得变成公开事件或 `QueryDiagnostic` 字段。 | 真实 PostgreSQL 事务、级联／保留和故障注入回归。 |
| 5. 受控运行入口 | Bearer 上下文决定租户与权限；回退对终端用户只表现为既有成功或失败语义。 | 复用既有草稿测试和查询 HTTP 入口；不新增用户提交模型参数的接口。 | Bootstrap HTTP 回归；伪造租户、主体、路由和令牌参数均无效。 |
| 6. 角色浏览器验收 | 最终用户和助手负责人无法看到模型标识、后备顺序或供应商错误；受权操作仍完成。 | 仅在既有任务页面展示已有结果，必要时增加不泄漏细节的状态文案。 | 真实浏览器的助手负责人草稿测试、最终用户查询、无权限与会话过期反例。 |

## 必测的失败分类

| 失败来源 | 是否可回退 | 断言 |
| --- | --- | --- |
| 受控聊天运行时已标准化的瞬态超时、暂时不可用或限流 | 是 | 未交付正文时按冻结顺序尝试下一候选；记录最小标准化结果。 |
| 身份、租户、权限或助手版本不可用 | 否 | 不调用任何后备候选。 |
| 冻结配置／目录／能力修订不匹配 | 否 | 失败关闭，不读取当前配置替代。 |
| 嵌入、检索、证据再鉴权或引用核验失败 | 否 | 不改变嵌入绑定，不调用后备聊天模型。 |
| 模型返回不符合冻结目标或未分类异常 | 否 | 不将异常细节传播到 HTTP、事件、轨迹或日志断言中。 |

真实 PostgreSQL、HTTP 与浏览器命令必须在具体切片的证据中记录精确测试类、环境和结果；不能以本设计路线代替实际红灯、绿灯或人工验收。

## 六维质量门禁

| 维度 | 未来实现的通过条件 |
| --- | --- |
| 正确性 | 仅冻结、受权、标准化可回退的候选参与执行，且终态与轨迹原子一致。 |
| 复杂度 | 单一 `ChatRouteExecutor` 隐藏回退循环；调用方不复制分支。 |
| 冗余 | 普通查询与草稿测试共享可信执行路径，不维护两套回退算法。 |
| 性能 | 最大三次聊天尝试；不重复嵌入、检索、证据选择或读取当前配置。 |
| 架构 | 路由值归助手版本，运行时执行归 model-runtime，运行终态归各自上下文。 |
| 测试质量 | 每个反例先实际红灯，再以真实 PostgreSQL、HTTP、浏览器和全量门禁闭合。 |
