## 问题

知识接入尚未形成从多格式输入到可观察解析、失败恢复、单文件重建和全库重建的安全产品闭环。

## 本工作包唯一结果

交付粘贴文本、文档、表格、PDF 和图片从输入到受限解析结果的纵向闭环。

## 范围内

- 实现小型试点原子配额预留。
- 支持 TXT、Markdown、DOC／DOCX、XLS／XLSX、CSV、PDF、PNG、JPEG、WebP。
- 以 Tika、PDFBox、POI 和隔离 Tesseract adapter 解析，落实 CPU、内存、页数、像素、解压比和超时限制。
- 实现 RECEIVED 到 READY／FAILED 状态机、结构化错误码和安全阶段重试。
- 冻结 SourceRevision、内容哈希、解析器版本、单文件重建和全库重建契约。
- 对照已确认原型逐闭环实现前端。

## 范围外

- 网页抓取、远程 URL、宏 Office、加密文件和 TB 级知识库。
- 多模态向量主检索。
- 自动激活重建索引。

## 公共接口与数据

公共契约必须表达来源、来源修订、解析阶段、结构化错误、配额预留和重建任务。具体 API、表和事件须在实现前由本包专属 ADR 接受。

## 约束

- application 和 domain 不依赖解析器、对象存储或 Spring 类型。
- 解析器运行在受限 worker；MIME、压缩炸弹、宏、加密和损坏输入失败关闭。
- 触及的 legacy、Java 内联 SQL、手工分页和框架泄漏先清理再扩展。
- 先建立恶意与正常 fixture corpus 的失败测试。

## 验收标准

- 所有首版格式从输入到可观察解析结果通过。
- 配额、并发预留、病毒／压缩炸弹、OCR、超时、重试和幂等测试通过。
- 单文件重新索引只替换该 SourceRevision；全库重建不原地修改活动索引。
- 容器、浏览器和原型对照验收通过。
