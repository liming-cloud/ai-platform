## 问题

M1 仅使用确定性模型证明受治理闭环，不能证明真实模型供应商在密钥、网络、超时、配额、引用校验和失败关闭边界内可用。用户已授权在后续研发中使用阿里云百炼，但不得把 API Key、厂商差异或未验证的真实调用扩散到产品领域和仓库。

## 范围内

- 使用现有 `OPENAI_COMPATIBLE` 扩展，以未提交的部署密钥完成阿里云百炼受控探测。
- 验证真实 Chat 与 Embedding 调用的密钥解析、地址策略、超时、错误脱敏和最小预算边界。
- 用真实模型生成可复核但不含秘密或业务正文的研发验收报告。
- 验证真实模型调用仍经过现有租户、配额、授权检索、证据再鉴权和引用校验流水线。
- 明确真实模型质量、成本和性能与确定性演示证据的边界，更新风险和验收资料。

## 范围外

- 提交 API Key、密钥引用、真实业务内容、模型响应正文或供应商认证材料。
- 将研发调用视为生产发布、商业 SLA 或真实客户质量承诺。
- 新增厂商专属领域模型、绕过出站策略，或降低租户隔离、引用和配额门禁。
- 多模型路由、工具调用、多模态、MCP、在线评测平台和生产密钥托管。

## 公共接口与数据

本工作包优先复用现有供应商连接、模型部署和运行时公共契约。若阿里云百炼接入需要新增公共字段、厂商参数模式、密钥存储或出站策略，必须先新增 ADR，并在获得批准后实施。

## 约束

- API Key 只存在于受控运行环境，不能进入版本控制、命令行输出、日志、测试夹具、截图或证据。
- 真实调用仅在显式环境开关、固定预算和可撤销凭据下执行；默认构建和离线测试不得依赖外部网络。
- 任何真实回答都必须通过现有引用校验；不能把模型生成的链接或事实直接视为可信证据。
- 研发验收记录只保存稳定错误码、耗时、令牌/费用汇总、模型版本和不可逆摘要。

## 验收标准

- 阿里云百炼连接在 ADR-0010 的 HTTPS 公网地址策略下完成受控探测，且失败不泄露密钥或认证材料。
- 真实 Chat 与 Embedding 调用通过现有运行时端口，不新增厂商泄漏到领域或公共契约。
- 租户隔离、查询配额、授权检索、证据再鉴权和引用拒答反例在真实模型路径回归通过。
- 真实调用的预算、超时、错误分类、脱敏和审计摘要可复核。
- 默认无密钥构建、离线测试和 Docker 演示仍可重复通过。
- 新增或更新的风险、验证命令和证据均不包含秘密。
