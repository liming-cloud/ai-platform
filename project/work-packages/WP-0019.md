## 问题

普通用户没有独立入口、授权助手目录、会话聚合、真实 token 流、历史恢复、续问和断线续传闭环；现有 SSE 仅回放同步完成结果。

## 本工作包唯一结果

交付普通用户从登录、选择助手、创建会话到真实流式问答、引用、历史切换和续问的完整闭环。

## 范围内

- 新增 QUERY_APP access channel 和普通用户路由。
- 会话创建固定一个已发布 AssistantVersion；新版本不漂移旧会话。
- 提交 turn 快速返回 202 与 QueryRun，沿用现有事件端点和 Last-Event-ID。
- 持久化 RUN_ACCEPTED、RETRIEVAL_COMPLETED、TOKEN_DELTA、CITATIONS_FINALIZED 和终态事件。
- TOKEN_DELTA 每 100 ms 或 256 字符合并；最终答案、引用和终态原子提交。
- 历史正文与模型上下文分离，最多 6 个完成轮次和 3,000 tokens 做问题改写。
- 对照原型实现登录、助手目录、会话目录、消息流和异常状态。

## 范围外

- 独立会话记忆库、用户长期记忆和多知识库助手。
- 最终答案缓存和逐字确定性。
- 租户管理员读取用户问答正文。

## 公共接口与数据

实现 ADR-0074 定义的 conversations 与 turns API，消息使用 beforeSequence 和 limit。普通目录使用 page、size 和 total；消息时间线不得使用第二套页码分页。

## 约束

- 普通用户只能访问自己的会话，且每次正文、引用和历史恢复重新检查当前授权。
- 权限撤销后立即失败关闭；租户管理员默认只读脱敏指标。
- Spring AI stream 必须进入真实链路，application 和 domain 不直接发 HTTP。
- clientRequestId 保证幂等，事件可断线恢复，终态只能提交一次。

## 验收标准

- 独立登录、授权助手搜索、会话创建、真实 token 流、引用、历史切换、续问和断线恢复可用。
- SSE 增量、幂等、断线续传和终态原子性自动测试通过。
- 首 token p95 小于 4 秒。
- 管理端原有路径无回归，三档宽度、键盘和 reduced-motion 对照原型通过。
