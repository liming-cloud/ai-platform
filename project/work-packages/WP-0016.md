## 问题

现有页面从功能堆叠出发，存在一次性问答、多个分页、助手选择与主任务混杂等产品断层。继续直接改生产前端会放大返工。

## 本工作包唯一结果

用锁定版本的 OpenDesign 交付全部关键流程的高保真原型、设计令牌、夹具和自动验证，并取得人工确认。

## 范围内

- 从官方仓库安装签名稳定版 OpenDesign 并锁定版本；macOS 使用绝对 MCP 路径。
- 以 `docs/prototypes/wp-0016/page-inventory.json` 为单一事实源，原型覆盖当前产品蓝图中的全部页面任务。
- M6 覆盖平台治理、租户治理、知识接入、索引、模型、助手、评测、普通用户登录、助手选择、聊天、历史和异常恢复。
- M7 设备问答与 M8 平台运维只做信息架构和视觉前置原型，不因此获得生产实现授权。
- 覆盖 loading、empty、error、denied、partial、disabled、success。
- 覆盖键盘、reduced-motion 和 390、1024、1440 宽度。
- 固定一个页面一个主要任务和一个普通目录分页的布局规则。

## 范围外

- 2026-09-05 用户明确暂缓渠道绑定、设备凭据、邮件邀请，排除出本次验收；保留既有设计，不标记实现，也不作为当前阻塞项。
- 修改生产前端、后端 API 或数据库。
- 把原型代码直接当作生产实现。
- 在人工确认前推进 WP-0017。

## 公共接口与数据

使用脱敏 fixtures 表达拟议契约，不创建真实 API。普通用户目标路由为 /app/login、/app/assistants、/app/conversations/:conversationId。

## 约束

- 本轮人工业务复核仍不通过；按 `docs/prototypes/wp-0016/BUSINESS-CLOSURE.md` 及 `TENANT-SETUP.md` 修复交互。ADR-0075 已确认两级功能控制；ADR-0076 开放配额与三项登录策略编辑原型。新账户邀请、真实登录锁定和生产配额合同不得伪装为既有能力。

- 先形成 DESIGN.md、tokens、fixtures 和原型，再做视觉与任务评审。
- 助手使用可搜索选择器；完整目录进入独立页面。
- 聊天页只包含左侧会话历史、中央消息流和顶部助手信息；消息按事件序号加载更早内容。
- 人工拒绝时保持本工作包进行中，不修改生产前端。

## 验收标准

- 全页操作覆盖账本必须区分真实模拟、部分模拟、仅导航、待决策、未实现和用户暂缓；本次范围内有无结果操作时不得宣称整套原型可验收。M6 为其余 56 个页面任务，M7/M8 的另外 10 页只核对信息架构与视觉。
- 按 ADR-0075 先验证功能能用，再验收交互易用性；租户功能上限和普通成员对话权限必须有保存、取消、刷新及拒绝结果。

- 所有关键流程和状态有可操作高保真原型。
- 页面清单、审查器入口和实际渲染完全一致，不允许只写页面名称而没有实际原型。
- 三档宽度、键盘和 reduced-motion 检查通过；临时截图不得提交仓库。
- 人工明确确认产品任务、信息架构和视觉基线。

## 证据

- 本轮将长表单拆为真实三步，修复输入对齐与措辞；平台可保存资源配额与三项登录策略，租户用量页只读。Node、静态和 lint 结果见当前证据，不代表生产能力。
- 新租户登录进入自己的空工作区；知识、模型、助手、评测与审计按组织投影，详情 URL 不因跨页签而漂移。文档更新保留来源身份，单文件重建冻结新版本并复用其他内容的索引标识。
- 最新验证：Node 137/137、浏览器 134/134；68 页、7 状态、3 视口共 1,428 场景、9,644 断言、14 阶段通过。静态 3,177 断言、OpenDesign lint 通过；截图仅存临时目录。
- 范围内 56 页七态共 5,733 控件实例，页面错配、未接线和运行异常均为 0。账本 143 个业务操作组，范围内已登记代码缺口为 0，3 项暂缓；干净数据枚举不能覆盖旧浏览器的全部状态。
- OpenDesign MCP `write_file` 保存 87 个原型/代码/设计/资源文件并逐项比较预览 SHA-256；`ACCEPTANCE.md` 保留全页三角色验收入口。监听器接线不能代替业务正确性或穷举所有输入。
- 用户当前 Chrome 已复现 A12 旧数据登录失败；新增两个登录页的明确确认修复，保留业务数据，不覆盖已重置/停用身份，不自动登录。6 个状态和 4 个浏览器专项通过；个人 Chrome 只核对修复入口，确认留给用户。原人工拒绝仍有效。
- 配额与登录策略编辑原型按 ADR-0076 实施，生产调整合同、策略上下限与会话生效时机留待后续工作包。
- 按 ADR-0077，OpenDesign 是原型内容与视觉验收唯一事实源；仓库不再保存浏览器截图，只保留契约、脚本与机器可读报告。
- OpenDesign 0.21.1 和同一项目已复用；历史设计、原始红灯与阶段结果只在证据索引中保留，当前工作包不累加过程。
