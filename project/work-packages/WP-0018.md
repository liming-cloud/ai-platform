## 问题

现有索引版本和模型治理基础尚未形成成员授权前置、混合召回、RRF、rerank、可校准拒答与非自动激活的检索闭环。

## 本工作包唯一结果

交付从非活动索引构建、冻结评测到授权原子激活的版本化混合检索闭环。

## 范围内

- 按内容结构版本化分块，保留父子块、邻接和实际引用块。
- 在 SQL／向量查询内部前置 tenant、member、assistant、knowledge space、source revision 和 active index 过滤。
- 并行 dense top 50 与 sparse top 50，以 RRF k=60 合并，rerank top 30，最终提供最多 8 个证据块。
- 按模型冻结维度、规范化和距离度量；以 exact search 对照 HNSW。
- Embedding、解析器或分块变化自动创建全量重建任务但不自动激活。
- 用冻结评测集校准拒答阈值和授权过滤召回损失。

## 范围外

- 多知识库助手和 TB 级索引。
- 自动激活新索引。
- 最终答案缓存和逐字一致性承诺。

## 公共接口与数据

必须冻结 Chunk、IndexVersion、检索策略、RerankerPort、评测结果和激活决定。公共契约不得暴露 pgvector、MyBatis-Plus、Spring AI 或厂商 SDK 类型。

## 约束

- 稳定 Assistant 与知识库永久 1:1。
- 成员授权必须在 ANN 与 FTS 候选生成前失败关闭；rerank、引用和缓存再次校验。
- Rerank 从检索后处理 seam 接入，不伪造 OpenAI-compatible 标准。
- 触及旧版／治理版分支、可空依赖、兼容构造器、内联 SQL 和手工分页先清理。

## 验收标准

- 模型或分块变化创建新 IndexVersion，旧索引持续服务且无自动切换。
- dense、sparse、RRF、rerank、授权过滤和原子激活集成测试通过。
- Recall@10 不低于 0.85，引用正确率不低于 0.95，混合检索 p95 小于 800 ms。
- 跨租户和越权候选泄漏为 0。
