## 问题

评测若必须依赖已发布助手，会与首次索引激活、助手发布形成循环；评测专用模型调用也不能证明普通问答的真实检索与流式质量。

## 本工作包唯一结果

交付从冻结私有评测集、选择候选目标、运行共用真实 RAG 流式执行，到指标、失败归因和修复事项的闭环；后续索引、助手和会员问答复用同一执行能力。

## 原型承接

6 个 screen：`evaluation-datasets`、`evaluation-dataset-detail`、`evaluation-run-create`、`evaluation-run-detail`、`evaluation-comparison`、`evaluation-failure-analysis`。数据集编辑、发布、创建运行和修复事项各自保存；运行结果不可被页面改成通过。

## 范围内

- 私有评测集清单、题目与期望证据维护、复制为新草稿、版本发布、冻结运行、比较、失败分类和去重修复事项。
- 定义明确的 `CandidateIndexTarget` 与 `AssistantVersionTarget`，用 sealed hierarchy 表达，禁止可空字段组合；候选索引目标不要求已发布助手。
- 候选目标冻结知识库、索引、评测集、检索及 Chat/rerank 配置；助手目标冻结助手版本及完整依赖，不以当前配置替换历史事实。
- 期望证据保存来源修订、原文位置、内容哈希，并派生索引 chunk 映射；重分块后重新映射，不能沿用旧 chunk ID 或删除映射失败样本。
- 接通已有 `SpringAiChatModelAdapter.stream` 与受控检索、证据再授权、提示构造、引用检查和终态语义。评测、试问和普通问答只有一套执行规则，不建立独立评测生成器。
- 记录真实首增量、检索、生成与终态时序；流中暂定文本和最终已验证答案分开，拒答、失败和取消不能伪装完整答案。
- 每知识库至少 100 题：60 可回答、20 应拒答、10 越权/撤权、10 多轮；首批仍为合成内容，生产历史和用户正文不得自动转存评测集。

## 范围外

- 前置 WP-0020 已提交，模型能力来自 WP-0019；先在当前检索接口上验证共用执行 seam，使用隔离测试库内真实持久化种子索引，不用前端模拟成功。
- 新分块、混合检索和候选索引激活归 WP-0022；完整助手发布归 WP-0023；会话、HTTP/SSE 和浏览器首 token 归 WP-0024。
- WP-0022 接入新检索后重测候选门禁，WP-0023 重测冻结助手，WP-0024 重测用户端时延；本包结果不能直接代替这些后续结论。
- 不开放平台读取评测正文，不自动采集真实客户问题，不提供人工降低指标或强行放行功能。

## 公共接口与数据

实现前由专属 ADR 冻结两类 `EvaluationTarget`、运行生命周期、共用执行输入/增量/终态契约、私有内容访问、取消和失败语义。评测上下文拥有数据集、运行与质量结论，不跨上下文直接读取表。

题目、回答及证据正文仅在受控私有内容边界内处理；普通运行事实、事件、日志、错误和审计只保存版本、摘要、计数和安全分类。任何正文留存范围变化须另有已接受决定。

## 约束

- Chat/Embedding 只经内部 Port 与 Spring AI；rerank 经最小 Port 接入后处理，application/domain 不直接 HTTP。
- 指标冻结实现版本、分母和目标版本；空样本、执行失败、无法计算、未知/越权引用或映射失败均非通过。
- 索引门禁保持 Recall@10 ≥ 0.85、引用正确率 ≥ 0.95、拒答准确率 ≥ 0.98，跨租户和未授权泄漏 0；不能把首次索引评测降为只测召回。
- 混合检索 p95 < 800 ms、用户端首 token p95 < 4 s 的最终要求不变；执行层时序不等于端到端 SLA。
- 触及兼容分支和框架泄漏先清理；共享视觉、中文、安全、JDK/Lombok 与证据规范遵循 ADR-0079。

## 验收标准

- 没有发布助手时可以对真实候选索引创建并完成评测；跨租户、未冻结或版本不匹配的目标失败关闭。
- 提取、召回、模型流、引用和指标确实来自同一执行能力；首个增量早于模型完整生成结束，失败和取消只形成一个终态。
- 评测集不可变、草稿复制、期望块映射、非零分母、重复样本、未知引用、超时、失败分类与事项去重测试通过。
- 低于门禁、空数据或运行不完整不能进入发布；正式/模拟供应商结果、版本与环境在报告中可区分。
- 6 页独立任务、权限、保存/取消、刷新恢复、大量运行记录、七态和三档尺寸等原型对照通过。
