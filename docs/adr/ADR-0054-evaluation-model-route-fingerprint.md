# ADR-0054：评测运行的受控模型路由摘要

## 状态

已接受。

## 日期

2026-08-05

## 决策负责人

产品、架构、安全、助手负责人和评测负责人。

## 背景

ADR-0050 要求 `EvaluationRun` 冻结评测目标的模型路由标识。现有草稿助手版本可冻结有序 Chat 候选与 Embedding 绑定，但仅保存助手版本标识和修订不能使 evaluation-operations 独立复核实际受控模型路由。

## 决策内容

evaluation-operations 只接收 assistant-delivery 提供的确定性 SHA-256 路由摘要。摘要的规范输入按固定字段名、固定顺序和 UTF-8 编码包含：有序 Chat 候选的配置标识、配置修订、目录条目标识、目录条目修订，以及 Embedding 配置标识、配置修订、目录条目标识和目录条目修订。

摘要不得包含端点、密钥、厂商原始错误、提示词、题目、回答、证据正文、令牌或成员信息。助手版本修订仍与摘要共同冻结；任一不匹配均使评测或发布失败关闭。

## 后果

assistant-delivery 必须通过最小草稿快照或专用门面提供该摘要，evaluation-operations 只持久化摘要而不读取助手表。摘要算法或字段集变化必须使用新的指标／策略版本，不能重新计算历史运行。
