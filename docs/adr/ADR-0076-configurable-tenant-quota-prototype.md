# ADR-0076：租户配额与登录安全配置原型

## 状态

已接受

## 日期

2026-09-03

## 背景

用户人工复核要求租户建立流程中的配额可以编辑，不再只展示固定默认值，并要求缩短表单、改进名称及输入框对齐。ADR-0075 的两级功能控制与安全底线继续有效。

## 决策

1. 在 WP-0016 可丢弃原型中，由平台管理员配置租户资源配额；现有小型试点值作为预填值而非不可编辑上限。覆盖知识库数量、每库有效文档数、每库原始内容容量、单文件大小和粘贴文本大小。
2. 创建时可修改配额，详情中可编辑、取消和保存；保存后合成状态立即生效并可刷新恢复。租户管理员只能查看平台分配的资源配额。该决定不授予平台读取租户正文的能力。
3. 原型采用保守边界：正数与有限数校验，数量为整数；资源容量不能小于已用量。降低单次接入限制只影响后续新增，不删除既有资料。具体生产容量上限、原子预留和并发更新合同在后续实现包冻结，不以本原型数值证明生产承载能力。
4. 将创建流程拆为真实步骤，每步只展示当前任务所需字段，前后切换和刷新保留非秘密草稿；错误、取消、提交和成功回显可操作。界面使用自然中文业务名称。
5. 用户本轮补充确认：平台管理员可修改会话有效期、登录失败次数与锁定时长；租户隔离、权限校验和密码不回显始终开启，不提供关闭开关。配置在租户详情独立编辑，避免创建表单再次变长；支持保存、取消、刷新和错误定位。
6. 原型合成预填值为 8 小时、5 次、15 分钟，均要求正整数；这些值用于验证配置操作，不是生产安全默认值或风险评估结论。生产上下限及对已登录会话的生效时机须在后续认证实现工作包确认。本轮只模拟配置保存，不声称已实现真实会话过期、登录限流或锁定。
7. 邮件邀请与自助激活仍未获授权。

## 影响和验证

- 本 ADR 解除 ADR-0075 中配额和三项登录策略的原型待决策项，不改变生产 API、领域、持久化和授权契约。
- 验证不同配额创建、编辑、取消、刷新、低于已用量拒绝、租户角色拒绝及存储失败回滚；平台仅见脱敏用量聚合。
- 人工验收仍未通过，不推进 WP-0017；余项按照操作账本闭环，不以可点击或页面数量宣称完成。
