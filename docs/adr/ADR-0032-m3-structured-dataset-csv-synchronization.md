# ADR-0032：M3 结构化数据集 CSV 同步与质量规则

## 状态

提议，等待产品与架构负责人确认；未接受前不得实现对应同步、质量、发布、索引或公共接口。

## 日期

2026-07-30

## 背景

ADR-0030 已接受平台私有 UTF-8 CSV、冻结字段映射、主内容字段、可选标题字段和受控行过滤；ADR-0031 要求同步产物、质量结论和来源状态转换只能由命名领域服务创建并作为不可变操作结果原子提交。

当前受控登记已经冻结 CSV 对象事实与映射，但尚未定义 CSV 方言、标题与映射匹配方式、行级错误的失败语义、空主内容的处理、可索引文本规范化和质量规则版本。任意选择都会改变发布资格、索引输入和知识管理员的恢复动作，不能在应用服务或基础设施中隐式决定。

## 提议的决策

### 1. 输入方言与资源上限

- 只接受严格 UTF-8、单一 CSV 文档和唯一标题行；解析器遵循 RFC 4180 的逗号、双引号和换行转义语义，不接受自定义分隔符、公式执行、外部引用或多文件压缩包。
- 标题必须与来源修订冻结字段集合逐项一致且顺序一致；重复、缺失、额外或空标题均为阻断错误。
- 同步使用部署受控的字节、行数、单行字节数和单字段字符数上限；超过任一上限为阻断错误。具体数值由部署配置提供，不由知识管理员请求指定。

### 2. 字段与文本投影

- 同步只读取冻结的主内容字段和可选标题字段；其他字段即使为 `PUBLIC` 也不写入同步产物、质量问题、索引、读取投影或日志。
- 主内容与标题只接受已由修订校验为可检索的 `TEXT`／`PUBLIC` 字段；`CONFIDENTIAL`、`RESTRICTED` 字段不得被解析为索引输入。
- 规范化文本由稳定的 `dataset-csv-v1` 规则产生：保留 Unicode 内容，统一行尾为 `\n`，删除首尾空白；有标题时以固定“标题换行内容”顺序组合。不得拼接其他字段、原始 CSV 行或列名。

### 3. 行过滤、质量与恢复

- `ALL_ROWS` 要求每条数据行的主内容规范化后非空；空内容行为阻断质量错误。
- `NON_BLANK_CONTENT` 跳过空主内容行；只要至少存在一条有效行即同步成功，并以被跳过行数产生 `WARN`。没有有效行时为阻断质量错误。
- CSV 语法错误、标题不匹配、编码错误、资源超限和无有效行均产生 `BLOCK`，来源进入可恢复的 `FAILED(SYNCHRONIZATION)`，不写入半成品。
- 成功同步创建 `SyncArtifact`、`QualityReport` 与来源 `READY` 的不可变领域操作结果。质量规则版本固定为 `dataset-csv-v1`；`BLOCK` 不可显式发布，`WARN` 仍可由知识管理员显式发布。

### 4. 领域与技术边界

- `StructuredDatasetCsvSynchronization` 是 knowledge-data 的命名领域服务：接收已加载的 `GovernedDataSource`、`SourceRevision`、不含敏感正文的解析摘要和新产物标识，创建同步产物、质量结论及操作结果；它不读取对象、不鉴权、不解析 CSV、不访问数据库。
- 应用服务只执行 `knowledge:write`、来源加载、`SYNCING` 状态登记、事务外私有对象读取与解析、领域服务调用和仓储提交；它不得自行构造同步产物、质量结论或来源完成状态。
- CSV 读取端口只按冻结 `StructuredDatasetCsvReference` 读取平台私有对象；基础设施实现流式 RFC 4180 解析和资源限制，不接收用户提供的对象位置、端点或凭据。

## 备选方案

### 方案 A：按本提议的严格 CSV 与失败关闭规则实现

推荐。它复用已接受的 `SyncArtifact`／`QualityReport` 语义，输入和质量结果可审计，且不会把敏感字段或任意表达式带入索引。

### 方案 B：宽松接受任意标题、分隔符或部分损坏行

拒绝。它会使冻结字段映射失去约束力，且不同解析器可能产生不同索引输入和发布资格。

### 方案 C：在应用服务或 MinIO 适配器中直接拼装产物与质量结论

拒绝。它违反 ADR-0031 的领域操作边界，无法以纯领域反例守住跨聚合不变量。

## 接受后的验收

- 纯领域测试覆盖来源类型、修订、行过滤、质量状态、过期版本和发布阻断反例。
- 应用测试覆盖权限前置、事务外 I/O、解析失败恢复和操作结果提交。
- 真实 PostgreSQL 验证同步产物、质量和来源状态的原子提交、跨租户不可见和并发关闭失败。
- 真实 MinIO 验证冻结私有 CSV 读取、摘要／长度核验与敏感字段不进入任何产物投影。
- HTTP 与浏览器覆盖成功、空数据、无权限、阻断质量和恢复路径；M3 仍须经人工评审后才可进入 M4。
