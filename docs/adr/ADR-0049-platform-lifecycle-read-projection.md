# ADR-0049：平台租户生命周期读取投影与角色验收夹具

## 状态

提议

## 日期

2026-08-04

## 决策负责人

产品、架构、安全与平台运营负责人。

## 背景和难以逆转的约束

ADR-0048 要求一个浏览器登录入口按已验证角色呈现可用任务，并要求平台管理员在两个同源页签中完成
租户建立、激活、挂起和恢复。实际浏览器验收显示，第二页签能恢复平台会话，却无法找到第一页签刚建立的
租户。代码图谱确认当前 `PlatformTenantLifecycleWorkspace` 仅在页面内存保存最近一次写入响应；控制面也只有
建立和状态迁移命令，没有服务端权威读取契约。

把生命周期对象或标识通过 `BroadcastChannel`、`localStorage`、URL 临时参数或前端缓存传给另一页签，会把
服务端权威业务事实降为可丢失、可伪造的客户端状态，且不能支持刷新、重新登录和并发操作者。另一方面，
平台运营权限不能据此扩大为租户成员、知识正文、问答正文、密码摘要或当前平台操作者读取权。

本地演示库只有一个具有 `tenant-governance:write` 的活动平台主体，缺少一个能够完成失败关闭浏览器验收的
“已获平台会话但没有生命周期写权限”的运营主体。该夹具只服务隔离演示与测试，不能成为生产授权委派模型。

## 决策内容

选择方案 B：由 `organization-access` 提供服务器权威、分页且最小披露的租户生命周期读取投影，并为隔离
演示／测试提供无写权限平台运营夹具。

1. `TenantLifecycle` 继续是唯一生命周期聚合根。读取结果是应用层不可变 `TenantLifecycleSummary` 投影，
   不是第二个聚合、可写实体或跨上下文共享对象。
2. 仅恢复自 `PlatformRequestContext` 且拥有 `tenant-governance:write` 的请求可以分页读取生命周期投影；
   权限缺失、会话范围错误或平台会话失效都沿用既有平台生命周期命令的失败关闭语义，不泄露租户是否存在。
3. 投影固定只含 `tenantId`、`tenantCode`、`displayName`、`status`、`version` 和创建／最后变更时间；不得返回
   初始管理员、成员、主体、权限、凭据、知识正文、问答正文、审计正文或当前操作者。
4. 平台工作区从此投影重新加载并以返回的 `tenantId` 发起既有建立、激活、挂起、恢复命令。页签之间只共享
   “会话失效”事实；每次读取和写入仍由服务端重新授权，写后重新读取或以命令响应刷新，不能复制生命周期对象。
5. 隔离演示和测试新增一个活动平台会话主体，但不授予 `tenant-governance:write`。其浏览器能力不得展示
   生命周期工作区；直接访问生命周期读取或命令同样失败关闭。夹具口令必须遵循现有演示密码和本地环境安全边界，
   不得写入证据、截图、日志或版本库的真实环境配置。

## 主要备选方案及拒绝原因

### 方案 A：将最近写入响应通过 `BroadcastChannel` 或浏览器存储同步

拒绝。它只覆盖仍在线的页签，刷新或重新登录后丢失；更关键的是把平台受控业务资源变成可伪造的前端事实，
无法满足服务端重新授权和分页浏览的产品一致性要求。

### 方案 B：服务器权威的最小分页读取投影与无写权限运营夹具

接受。它把生命周期归属继续留在 `organization-access`，使两个页签、刷新和独立操作者读取同一受控事实，
同时不把平台能力扩大为租户正文或成员读取。分页、最小字段和每次授权使可见性和负载边界明确。

### 方案 C：只增加按 `tenantId` 的单条读取

拒绝。第二页签没有受控发现途径，仍需依赖客户端复制标识；也无法支持正常的生命周期工作台列表。

### 方案 D：复用租户成员查询或返回完整平台租户资料

拒绝。成员和平台租户治理拥有不同的权限语义；复用会泄露成员、权限或正文相关事实，违背 ADR-0041、
ADR-0043 和 ADR-0048 的范围隔离。

## 后果和后续证据

- 接受前不得新增读取 API、数据库迁移、前端路由、浏览器存储同步或演示运营主体。
- 接受后先以红灯证明：第二页签无法读取新生命周期、无写权限运营主体不能读取或迁移、伪造前端能力不改变
  服务端授权、投影不含受限字段、分页和跨页签顺序失败关闭。
- 再补齐领域／应用查询、真实 PostgreSQL、自动配置、HTTP、前端、真实浏览器两页签、平台运营拒绝、
  HTTPS Cookie 和会话自然过期证据；所有写入仍走现有聚合和状态迁移服务。
- 该决策不授权成员资格列表、邀请、密码重置、平台授权委派、租户正文读取、评测、预算、发布审批、
  审计导出或 M7／M8 实现。
