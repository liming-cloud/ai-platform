# ADR-0071：本地平台管理员凭据与数据完全重制

## 状态

已接受。

## 日期

2026-08-28

## 决策负责人

用户，代表本地研发与 M6 人工验收负责人。

## 背景

ADR-0069 固定了纯本地空库管理员 `platform.root` 与公开开发口令，但当前 Compose 已积累租户、成员和
人工验收数据。用户要求把本地平台重新初始化为账号 `admin`、密码 `admin@123`，并明确选择完全重制，
不能只修改现有主体的登录名或密码摘要。

主体固定使用 `subject_id=1`。若只重建 PostgreSQL 而保留 Redis 会话，旧主体会话可能错误继承新主体身份，
因此本次重制还必须清除同一 Compose 项目的本地会话状态。

## 决策内容

1. `local` profile 的空库初始化账号改为唯一活动账户 `admin`，固定公开开发密码改为 `admin@123`；同时
   建立活动 `PLATFORM_ADMINISTRATOR` 绑定和平台授权修订事实。
2. 数据库仍只保存现有 `Pbkdf2PasswordAdapter` 契约生成的 `pbkdf2-sha256` 摘要，不保存明文；公开值只
   登记在 `deploy/compose/.env.example`。
3. 初始化继续只在主体、租户和成员均为空时，于同一 Flyway 事务原子写入三项身份事实；标准迁移和任何
   非空数据库不得建立、覆盖或重置该账号。
4. 用户授权对当前项目 Compose 的 `foundation_v1` 本地数据库执行一次完全重建。执行前必须生成权限为
   `0600`、可由 `pg_restore --list` 读取的完整备份；不得删除 MinIO 数据卷、Git 文件或其他项目数据库。
5. 数据库重建时清空当前项目 Redis 数据库中的本地会话、撤销和租约状态，防止旧主体会话继承新身份。
   该操作不扩展到其他 Redis 实例或非本地环境。
6. 重建后旧账号 `platform.root`、旧密码以及旧浏览器会话必须失效；`admin`／`admin@123` 必须通过同源
   HTTP 登录，并拥有唯一活动平台管理员绑定。租户、成员和产品业务事实必须为零。

## 取代关系

本 ADR 只取代 ADR-0069 的固定本地登录名、固定本地密码和当前 Compose 一次性更新方式；ADR-0069 的
纯本地范围、PBKDF2 存储、空库失败关闭和其他环境不得加载固定凭据等安全边界继续有效。

## 后果与验证

- 先用真实 PostgreSQL 红灯证明旧初始化 SQL 和公开配置不满足新凭据，再实施最小修改并复跑同一测试。
- 回归标准迁移、已有租户和已有主体三条反例，证明本地初始化不会覆盖非空数据库。
- Compose 重建后核对 PostgreSQL 事实、Redis 空状态、服务健康和同源 HTTP：新凭据返回成功，旧账号及
  旧密码返回未认证，响应不得泄露密码摘要、Cookie、请求凭据或异常。
- 本决策不授权删除 MinIO、修改非 `local` profile、弱化生产密码策略、进入 M7 或把公开开发口令用于
  共享、测试、预发布、生产及任何真实数据环境。
