# ADR-0051：私有评测数据集与首批质量发布门禁

## 状态

待决定。

## 日期

2026-08-05

## 决策负责人

产品、架构、安全、助手负责人和评测负责人。

## 背景和难以逆转的约束

ADR-0050 已将 `EvaluationRun`、`ReleaseDecision` 与 `ReleaseAuthorization` 的归属固定为
evaluation-operations，但尚未定义评测输入、可复核指标和样本不足时的失败语义。

`AssistantTestRun` 仅持久化题目摘要、最小引用、用量和终态；`QueryFeedback`、
`QueryDiagnostic` 与 `ModelInvocationTrace` 同样不保存题目、回答或证据正文。它们按 ADR-0036、
ADR-0038 与 ADR-0040 的最小留存约束不能反向构造成评测数据，也不能作为发布通过证明。

项目章程已确认产品质量目标：验收集 Recall@10 不低于 `0.85`、引用正确率不低于 `0.95`、
证据不足时正确拒答率不低于 `0.98`。这些是现有的产品成功标准，不应由页面、当前模型表现或
测试脚本临时降低。吞吐、延迟、成本和容量仍分别属于运行与预算治理，不能在没有对应事实来源时
伪装为本 ADR 的质量指标。

## 提案内容

推荐采用方案 A：evaluation-operations 拥有私有、版本化的 `EvaluationDataset`，首个
`quality-gate-v1` 固定章程中的三项质量门禁；`EvaluationRun` 只引用数据集与政策版本，并把最小
指标结论冻结为可供 ADR-0050 的发布决定消费的事实。

1. 一个 `EvaluationDataset` 版本由不可变清单和私有内容引用组成。清单只保存数据集标识、版本、
   租户归属、内容摘要、条目数、内容分类、创建时间和保留策略标识；题目、期望证据、允许答案和
   拒答期望只保存在 evaluation-operations 管理的私有内容中，不能出现在事件、审计投影、错误响应、
   URL、日志或普通查询表。
2. 首批数据集只接受 `SYNTHETIC` 内容分类。使用客户问题、生产查询、助手测试正文或反馈正文前，
   必须由另一个 ADR 明确同意、脱敏、保留和删除语义；不得把现有运行历史复制进评测库。
3. 每个条目固定一个评测输入、可选的期望证据稳定标识集合，以及 `ANSWER` 或 `REFUSE` 期望。
   `ANSWER` 条目的期望证据集合不能为空；`REFUSE` 条目表示证据不足且不得用回答替代拒答。数据集版本发布后
   条目不可修改；任何题目、期望证据、分类或保留语义变化都创建新版本。
4. `quality-gate-v1` 冻结三项指标及失败关闭阈值：`Recall@10 ≥ 0.85`、引用正确率 `≥ 0.95`、
   证据不足时正确拒答率 `≥ 0.98`。其中 `Recall@10` 的分子为首十个检索候选中命中的去重期望证据稳定标识数，
   分母为 `ANSWER` 条目的去重期望证据稳定标识数；引用正确率的分子为回答实际声明且属于该条目期望证据集合的去重
   引用稳定标识数，分母为回答实际声明的去重引用稳定标识数。`REFUSE` 的正确拒答仅在运行结果为拒答、没有回答
   正文且没有引用时计数。三个分母均不得为零，`ANSWER` 的空引用、超过十个候选、重复以外的未知引用、跨租户
   结果、未授权证据、条目执行失败或指标无法计算均使运行结论为非通过。指标实现版本必须与 `EvaluationRun` 一起冻结。
   现有演示夹具的 `citationCompleteness` 只验证预期记录是否被命中，不验证额外引用是否正确，不能直接充当
   本指标的实现或通过证据。
5. `EvaluationRun` 只保存数据集／政策／目标版本、每项计数、指标值、通过或失败结论和完成时间；
   它不保存题目、模型回答、引用正文、候选正文、端点、密钥、令牌或当前调用方身份。`ReleaseDecision`
   只能引用结论为通过且目标草稿修订完全匹配的运行。
6. 该门禁仅验证受控质量结果；不设货币预算、人工例外、延迟／容量 SLA、审计导出或平台运营权限。
   这些仍须独立 ADR，且不得由 `quality-gate-v1` 的通过结论隐式放行。

## 主要备选方案及拒绝原因

### 方案 A：私有版本化数据集与冻结质量门禁

推荐。数据集内容与运行历史的最小留存边界保持分离，版本、摘要和内容分类可用于复核与保留治理；
三项门禁直接采用项目章程已确认的质量目标，失败、空样本和无法计算均可稳定失败关闭。发布侧只需
消费一个最小结论，不读取评测正文或当前策略。

### 方案 B：从 `AssistantTestRun`、`QueryRun` 或反馈历史实时生成评测集

拒绝。这些事实按设计不含可执行题目或期望答案；强行补写正文会破坏既有保留与同意边界，也会让
当前历史形态改变发布结果，无法复核数据集版本。

### 方案 C：把题目、回答和期望证据放进普通关系表或浏览器缓存

拒绝。它扩大正文的读取面、备份和日志风险，并使刷新、前端篡改或跨租户读取成为评测事实来源；
不满足最小披露与服务端权威边界。

## 后果和后续证据

接受后，先以红灯证明：运行不能引用未发布或跨租户数据集；缺条目、空指标、低于任一阈值、
错误拒答、错误引用或执行失败均不能形成通过结论；数据集清单、运行事实、事件和发布决定不含题目、
回答、证据正文、凭据或令牌。随后才补齐私有存储、真实 PostgreSQL、自动配置、受限 HTTP、
角色浏览器、发布授权和全量验证。

本 ADR 不授权非合成评测数据、预算、人工例外、审计导出、正文读取、平台运营工作台、M7 或 M8
实现。正式 HTTPS 浏览器 Cookie、跨页签注销与自然到期仍按 ADR-0048 的部署证据要求独立完成。
