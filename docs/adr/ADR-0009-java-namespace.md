# ADR-0009：Java 命名空间

## 状态

已接受

## 背景

绿地工程需要在首个源码提交前固定 Java 命名空间。当前仓库未提供可验证的企业互联网域名，不能凭空假定组织域名归属。

## 决策

基础产品暂使用与仓库名称一致的 `com.aiplatform.foundation` 作为 Java 根命名空间，Maven 坐标使用 `com.aiplatform.foundation`。

该命名空间表示产品技术身份，不表示兼容旧系统，也不允许复用旧系统公共契约。若产品正式发布前获得企业自有域名，必须通过新的 ADR 评估并一次性完成命名空间替换。

## 影响

- 所有限界上下文、平台机制、扩展和运行入口必须位于该根命名空间下。
- 不允许新增 `com.example`、旧系统包名或厂商命名空间下的产品源码。
- 正式发布后不再接受无兼容计划的根命名空间变更。
