# ADR-0002：DDD 模块与三个运行进程

## 状态

已接受

## 背景

六人团队需要清晰的领域所有权和运行隔离，但不应过早承担微服务的运维与分布式一致性成本。

## 决策

使用一个 Maven 多模块工程，按限界上下文组织代码，并由 Spring Modulith 和 ArchUnit 验证。构建三个 Spring Boot 入口：

- `control-plane`
- `query-runtime`
- `ingestion-worker`

上下文只暴露小型应用契约和领域事件，每个入口只装配其拥有的上下文。

## 影响

- 领域和应用代码无需网络即可测试。
- 查询与摄取负载可以独立扩容。
- 未来只有在运维证据充分时才拆分服务。
- 跨上下文访问内部包将导致构建失败。
