# ADR-0023：分层模型配置治理与数据库密文凭据

## 状态

已接受

## 日期

2026-07-27

## 决策负责人

产品负责人确认：平台管理员、租户管理员和普通用户分别维护其授权范围内的模型配置；厂家类型由平台受控管理。

## 背景

M1 的 `ProviderConnection` 仅属于一个租户，数据库保存 `secret://` 引用，使用 `model:write` 管理连接。该边界能够证明确定性演示的隔离与密钥不回显，但无法表达平台托管模型、租户自带模型与个人自带模型共存，也无法满足“创建或编辑时提交 API Key，之后不可查看”的产品要求。

将 API Key 明文保存、回显密文或允许用户任意填写厂家和端点，都会造成凭据泄漏、SSRF、成本归属不清和模型能力绕过。

## 决策

### 1. 平台受控厂家目录

- 厂家类型、认证方式、端点模板、可用模型编码、能力、区域和参数模式由平台管理员维护。
- 租户管理员与普通用户只能从已发布厂家目录选择；不得新增厂家类型、任意端点或未批准模型编码。
- 厂家目录变更是平台治理动作，必须经过探测、版本化和审计；禁止把厂商名称或专属参数泄漏到助手、查询和评测领域。
- 每个已发布目录条目必须冻结一种模型类型及其运行时能力快照：上下文窗口、对话输出上限或嵌入维度。能力值由平台探测和确认，不能由租户或成员提交。

### 2. 三层模型配置

模型配置具有明确所有权范围：

| 范围 | 维护者 | 使用者 |
| --- | --- | --- |
| `PLATFORM` | 平台管理员 | 被平台授予权限的租户或成员 |
| `TENANT` | 租户管理员 | 本租户内被授予权限的成员 |
| `PERSONAL` | 普通用户本人 | 本人，或其显式绑定的助手版本 |

- 助手版本必须显式绑定一对已授权、已启用的模型配置：一个 `CHAT` 配置和一个 `EMBEDDING` 配置；不使用个人、租户和平台之间的隐式回退。
- 发布助手版本时冻结两个配置标识、配置修订和目录能力快照。查询在配额占用后重新验证配置可用性，停用或撤销后必须拒绝调用。
- 模型配置的可见、可用、编辑、轮换和停用权限分离；获得使用权限不代表能够读取或轮换凭据。
- 平台模型按授权范围、租户配额、预算和审计使用；租户与个人模型分别归属、计量和审计。

### 3. 数据库存储的加密凭据

- API Key 只在创建、编辑或轮换请求中接收，接口只返回 `credentialConfigured`、密钥版本、最近轮换时间和不可逆指纹，不返回明文、密文、nonce 或可解析引用。
- 数据库保存独立凭据记录：AES-256-GCM 密文、随机 nonce、算法、主密钥版本、不可逆指纹、轮换时间和所属模型配置标识。
- 每次加密使用新的数据密钥；数据密钥经 `SecretEncryptionKeyProvider` 提供的主密钥封装后与密文一同保存。主密钥不进入数据库。
- M2 本地研发可由未提交的环境变量主密钥提供者实现；生产环境必须使用 KMS 或 Vault 实现，禁止以环境变量主密钥进入生产。
- 解密必须发生在完成归属、租户、模型授权、配额和预算检查之后；明文使用 `SecretValue` 短生命周期保存并在调用结束后清零。

### 4. 权限与审计

- 平台管理员拥有厂家目录、平台模型配置、平台授权和平台预算权限。
- 租户管理员拥有本租户模型配置、成员授权、租户预算和租户审计权限。
- 普通用户只能维护本人模型配置并使用被授权模型；无权查看他人或平台凭据状态细节。
- 创建、更新、轮换、探测、发布、授权、撤销和调用都记录不含密钥材料的审计事实。

## 数据与迁移边界

- 新增受控厂家目录、模型配置、模型配置授权和加密凭据记录；所有归属、唯一约束和查询条件必须包含平台、租户或成员范围。
- M1 的 `ProviderConnection` 与确定性演示链路保持可用；迁移完成前不得删除或降级其租户隔离、版本冻结、探测和发布语义。
- 公共 HTTP 契约必须使用写入专用 API Key 字段和只读状态字段，禁止复用现有 `credentialReference` 向客户端暴露密钥存储实现。
- 助手版本迁移期间保留 M1 `ModelDeployment` 事实与确定性演示路径；新发布版本不得以旧部署引用替代受控模型配置绑定。

## 后果与验收

- `WP-0010` 必须先以红绿测试证明：密钥不回显、密文不可被列表和审计读取、跨范围读写拒绝、授权撤销立即生效、主密钥版本轮换和真实 PostgreSQL 事务回滚。
- 需新增 AES-GCM 篡改、nonce 复用、错误脱敏、并发轮换、跨租户和跨成员反例测试。
- 真实模型调用只能消费已授权配置的解密短生命周期凭据，并继续遵守 ADR-0010 的出站地址、超时、脱敏和预算边界。
- 任何新增厂家、端点模板、主密钥提供者或生产 KMS 适配器均需独立工作包和契约测试。
