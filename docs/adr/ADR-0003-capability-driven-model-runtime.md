# ADR-0003：能力驱动的 Spring AI 模型运行时

## 状态

已接受

## 背景

不同厂商具有不同模型类型、参数、认证、区域、限制和失败语义。如果产品代码按厂商名称分支，变化会扩散到助手、RAG、评测和页面。

## 决策

在模型目录与运行时上下文中管理供应商连接和不可变模型部署，并显式描述真实能力。通过不同模型类型的基础设施工厂使用 Spring AI 的通用模型、ChatClient、Advisor、RAG、工具、MCP、结构化输出和可观测能力。对于 Spring AI 没有统一模型接口的能力，例如重排，使用平台端口适配。

厂商参数使用带版本、带白名单的 JSON Schema。公共契约只使用平台类型。

## 影响

- 厂商差异被限制在适配器和参数 Schema。
- 路由可以拒绝缺少必需能力的部署。
- 新增厂商不应修改助手、查询和评测领域。
- 每个适配器必须通过统一厂商契约测试。
