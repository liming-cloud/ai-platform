# ADR-0005：任务导向的 Fluent UI

## 状态

已接受

## 背景

企业控制台需要支持高密度工作，但不能暴露后端模块树，也不能不断累积互不相关的管理页面。

## 决策

生产组件基座只使用 Fluent UI React v9。导航按照用户任务组织，并根据角色裁剪，所有页面执行复杂度预算。模型管理归入“治理”，不新增顶级产品区域。

### WP-0016 原型视觉与易用性补充（2026-09-08）

用户已明确要求采用 OpenDesign 内置 `Claude (Anthropic)` 设计体系，并授权执行整体整改计划。该选择是原型视觉体系，不是 AI 执行模型选择，也不授权替换生产组件框架。内置包为整理后的参考设计，不宣称为 Anthropic 官方完整企业组件规范。

- 原型保留 `7/5/7`，统一暖纸色背景、陶土强调、暖中性色和柔和圆角。保持包的 token 名称，中文字体、可访问性色和企业界面密度作为集中扩展；不加载未授权专有字体。
- 正文 16px、表格不小于 15px、区块间距 24–32px；不套用营销页大标题和大留白。确认弹窗统一标题、内容、操作区，不依赖内部是否为表单；复杂流程独立成页。
- 导航采用对象工作区：知识库是内容唯一主入口，文档、处理任务和索引是其子任务。成员目录、成员账号、对话功能与可用助手独立页面及保存范围；首次引导与日常直接访问并存。
- 动效使用 150/200/240ms 和 `cubic-bezier(0.2,0,0,1)`，用于控件、内容、弹窗、步骤及结果反馈。快速操作可中断，业务结果不等待动画；授权撤销立即隐藏受限正文。`reduced-motion` 禁用位移、闪动和循环。
- 先完成全量旧页面去向地图、公共组件及一条完整样板流程。样板人工确认前不进行其余页面全量迁移；全量原型人工确认前不实施生产前端。

## 影响

- 每个页面和功能必须有明确用户、任务和结果。
- 同质卡片网格和大而全管理页不能通过设计评审。
- 低频和厂商专属控制使用渐进披露。
