# ADR-0079：M6 原型承接、顺排实施与真实会员验收

## 状态

已接受

## 日期

2026-09-14

## 决策负责人

用户，代表产品、架构、安全与验收负责人；依据本任务确认的完整计划、顺排编号选择、实际平台验收会员选择及“执行计划”。

## 背景

WP-0016 原型已人工验收。原 WP-0017～0020 尚未生产实施，原四包不能覆盖平台、成员、模型、评测、助手和查询治理全部任务。本记录使已确认计划成为仓库事实，不证明任何生产功能完成。

### 2. 唯一原型承接

OpenDesign 项目 249f81f2-6f1a-46ff-988c-da3cdedb35e7 是已验收设计来源。保留 Claude 风格、7/5/7；生产沿用 React 19、Fluent UI v9、唯一 SPA，不复制模拟账户、localStorage 业务状态或 token 动画。

project/m6-implementation-map.json 只引用现有页面和操作 ID，记录责任、分类和验证状态，不复制设计正文。生产操作逐包补齐 API、保存边界、权限、反例、证据及提交；跨包操作单独归属，不能因主页面交付而提前完成。

普通控件 36px，表格/分页 32px，登录/触控至少 44px；按钮 14px、输入 16px、表格行基准 48px。同排误差不超过 1px，帮助和错误不牵动同行控件。一页一主任务、一主要保存边界、一普通目录分页；页码、总数、10/20/50/100 条与跳转，默认 20。长记录有界加载，弹窗分区与焦点恢复，三尺寸、200% 文字、键盘、reduced-motion 均验收。截图临时检查，不带入仓库。

### 3. 跨包依赖

- WP-0020 验收到 EXTRACTED；CHUNKING/INDEXING/READY 归 WP-0022，助手发布归 WP-0023。此条正式修订原 WP-0017 的 READY 退出条件，不减少完整 M6 能力。
- WP-0021 的 EvaluationTarget 区分候选索引和助手版本，冻结索引、模型、检索、数据集和门禁指纹；候选评测不要求已发布助手，不使用可空字段组合。
- 期望证据保存来源修订、原文位置、内容哈希，派生每个目标索引的实际 chunk 映射；重分块后不能复用旧 ID、删除失败样本或跨数据集版本比较。
- WP-0021 前移同一份真实流式执行能力；WP-0022 接入新混合检索重测，WP-0023 发布和 WP-0024 问答复用。WP-0024 增加会话、HTTP/SSE、恢复后重测用户端首 token，不能以独立模型延迟代替。
- 上游测试可用隔离数据库的真实种子对象，不用前端模拟成功；依赖齐备后重新跑空环境完整旅程。审计、幂等和诊断事实随业务写入交付，不留到 WP-0025 补造。

### 4. 已冻结的产品边界

- 保持统一身份、三角色和平台/租户活动资格互斥。平台管理租户管理员；租户管理员只管理普通会员。助手选择和访问策略共用版本化授权事实，有效权限取角色、租户功能、成员功能、对象授权交集。
- 登录策略：绝对会话 1～24 小时默认 8；固定 15 分钟观察窗口内失败 3～10 次默认 5；锁定 5～60 分钟默认 15。变更先提示影响，再立即撤销受影响租户会话。这些是产品值，不是通用安全标准；隔离、权限检查和密码不回显不可关闭。
- 保留试点默认配额：每租户 3 库、每库 1,000 有效文档与 10 GB 原始内容、单文件 50 MB、粘贴 1 MiB；配额服务端原子预留，不能低于用量。归档不占有效数但占存储。查询配额继续部署配置、只读展示，不与可编辑资源配额混同。
- 全格式输入用受限 Tika/PDFBox/POI 和隔离 Tesseract，失败关闭处理宏、加密、未知 MIME、损坏和资源超限，不接受远程 URL。来源、解析器、内容哈希、错误和重试安全阶段可追溯。
- 分块版本化：结构文档父块 1,200 tokens，子块目标 400、150～700、同节重叠 60；纯文本 500/75；表格不跨工作表、重复表头、30 行或 600 tokens；OCR 保留页码/区域并使用 400/60。引用必须指向实际证据。
- dense/sparse 各 50，RRF k=60，rerank 30，生成最多 8 块；中文分词和拒答阈值以冻结集校准。HNSW 仅用于授权范围物理隔离的索引，其他细粒度范围在物化授权集合内精确搜索；iterative scan 和 exact 对照不得省略，ANN 后过滤不是授权前置。
- Embedding/维度/距离度量/解析器/分块变化只自动创建候选重建，不自动激活；Chat/rerank 变化只产生助手新版本。助手永久绑定一个知识库，最多一个未发布候选；不静默截断向量或改变精度。
- 旧会话读取冻结且仍有授权的旧索引，不强制最新 ACTIVE；被有效会话或评测引用的版本不自动清除。本项在旧会话范围上调整 ADR-0015 第 9 项，索引和来源仍不可变。
- 会话固定发布版本，同一会话最多一轮运行；幂等 ID 异参冲突拒绝。token 每 100 ms 或 256 字符合并持久化，答案、引用和终态原子提交，沿用事件端点及 Last-Event-ID；按 ADR-0074 调整 M1 临时最终事件行为，不新增平行 v2。
- 模型上下文最多 6 个完成轮次/3,000 tokens 做改写，超出使用版本化可重建摘要；无独立记忆库、用户长期记忆和最终答案缓存。撤权覆盖输出、引用、缓存和历史。
- Chat/Embedding 经内部 Port/Spring AI，rerank 独立最小端口。HTTP 仅基础设施受控适配；厂商预设版本化且经过真实探测，密钥不进入响应、日志或普通配置对象。

### 5. 真实会员与数据边界

用户选择实际平台验收会员，不是新开开发任务。WP-0017 通过真实界面/API 创建隔离验收租户及管理员；WP-0018 创建普通会员，默认无助手；WP-0023 发布后通过真实授权页赋权；WP-0024 验证问答和历史；WP-0026 复验撤权和停用。三角色独立浏览器会话，不用管理员 cookie 冒充会员。合成身份、真实持久化；密码不写 Git、日志或证据，不设公开演示密码生产回退。

仅明确识别的开发基座数据可备份并验证隔离恢复后重建，不授权重置原型、密钥、用户文件或其他项目，不宽泛清卷。开发数据不要求长期旧新读取分支；触及 ADR-0028/0029 兼容路径时仍须所属包显式取代设计，不隐式改写历史语义。

### 6. 执行与验收

一包一个主前沿，先失败用例再实现；公共契约、领域、持久化、安全变更先接受专属 ADR。触及旧新分支、可空依赖、兼容构造器、内联 SQL、手工分页、框架泄漏先清理；无关债务只登记责任与退出条件。保留 JDK 正式特性、受限 Lombok 与四层约束。

每库至少 100 题（60 可回答、20 拒答、10 越权/撤权、10 多轮）及期望证据；泄漏 0，Recall@10≥0.85，引用≥0.95，拒答≥0.98，混合检索 p95<800ms，用户端首 token p95<4s。同题五次无事实矛盾/无依据引用，版本变化重新评测。Docker、供应商或评测缺失不能静默跳过；原型测试、脚本单测、八题演示均不能代替。

M6 完成受控 Compose 和隔离恢复；M7 设备、M8 运维及正式 TLS/密钥托管/公开发布遵守后续环境门禁。状态活动证据≤8、前沿 ADR≤12、恢复上下文≤12KiB。证据与中文提交绑定前不得标完成；最终回 WP-0014 人工复评，不自动激活 M7。

## 后果

顺排与覆盖校验先于生产修改。具体 API、数据库及失败语义由当前工作包专属 ADR 冻结，本 ADR 只接受整体边界，不冒称功能已实现。
