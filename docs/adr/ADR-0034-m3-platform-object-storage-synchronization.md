# ADR-0034：M3 平台对象存储同步与私有产物规则

## 状态

提议，等待产品与架构负责人确认；未接受前不得实现 `OBJECT_STORAGE` 同步、质量、发布、索引或新的部署正文映射。

## 日期

2026-07-30

## 决策负责人

产品与架构负责人

## 背景和难以逆转的约束

ADR-0030 已接受由部署平台预置不透明对象范围、选择修订和冻结对象元数据。当前 `ConfiguredPlatformObjectRangeSelectionAdapter` 只把这些元数据转为 `ObjectStorageObjectCollection`；`PlatformObjectContentReaderPort` 只有失败关闭实现，因而没有任何代码能把不透明对象标识安全地映射为正文。

另一方面，现有 `IndexSourceSnapshot` 只读取一个平台私有 `TextContentReference`，而 `SyncArtifact` 只冻结摘要和记录数。若直接把部署对象键写入领域、来源修订或公共响应，会泄漏平台定位；若在索引构建时重新扫描可变范围，会违反已冻结来源修订。对象正文映射、集合规范化和失败语义因此必须先被固定。

## 提议的决策

### 1. 部署私有正文映射

- 部署配置以“租户、知识空间、范围标识、选择修订、平台对象标识”唯一定位一个内部对象位置。该位置只由 `PlatformObjectContentReaderPort` 的基础设施适配器持有，不能进入领域值对象、PostgreSQL、HTTP、事件、日志、审计摘要或浏览器状态。
- 读取端口接收冻结的范围选择及其 `PlatformObjectReference`，只允许读取该选择中的对象；适配器在流式读取时核验长度、SHA-256 和媒体类型与冻结元数据完全一致。不存在映射、映射重复、对象不属于该选择、读取失败或任一核验不一致均失败关闭。
- M3 不引入对象范围管理 API、用户输入的桶名／对象键／端点／凭据，亦不把这套部署映射泛化为外部连接器。

### 2. 可索引私有产物

- M3 `OBJECT_STORAGE` 首版只接受严格 UTF-8 `text/plain` 对象。集合按冻结顺序读取；任一对象编码无效、内容为空、媒体类型不匹配或超过部署受控字节上限时，整个同步失败，不生成部分产物。
- 同步将已核验的对象正文按稳定顺序以固定空行分隔写入新的平台私有文本产物；对象标识、对象位置和原始范围标识不写入正文。产物摘要是该私有正文的 SHA-256，记录数等于冻结对象数。
- `SyncArtifact` 及其索引快照必须冻结该私有产物引用，不能在发布或索引时重读可变部署范围。该引用按租户、知识空间、数据源、来源修订和同步产物身份隔离，且不对外暴露。

### 3. 质量、状态与发布

- `object-storage-text-v1` 是首版质量规则。全部对象均通过读取、完整性和 UTF-8 校验时为 `PASS`；首版不跳过单个对象，也不产生部分成功的 `WARN`。任何失败都使来源进入可恢复的 `FAILED(SYNCHRONIZATION)`，并删除本次刚写入但尚未提交的私有产物。
- `ObjectStorageSynchronization` 是 knowledge-data 的命名领域服务，负责校验来源类型、当前修订、同步状态和操作结果；它创建 `SyncArtifact`、`QualityReport` 与完成来源，不读取对象、不鉴权、不访问数据库。
- 显式发布仅接受上述非阻断产物，并复用 ADR-0029 的发布快照语义；应用层只做可信上下文授权、状态登记、事务外 I/O、领域服务调用和原子提交。

## 主要备选方案及拒绝原因

### 方案 A：部署私有映射加私有规范化产物

推荐。对象定位不跨越基础设施边界，索引始终读取不可变的私有产物，且集合的任何完整性失败都不会污染已发布索引。

### 方案 B：在领域或数据库保存部署对象键，并在索引时直接读取它

拒绝。对象定位会泄漏到错误层和读取投影，也无法证明索引没有在冻结修订后读取可变范围。

### 方案 C：同步时忽略读取失败或不支持的对象，发布其余对象

拒绝。它会让相同范围选择产生不可预测的索引输入，且会把缺失事实伪装为可发布质量结论。

## 后果和后续证据

接受后，先以纯领域反例验证来源类型、修订、状态和产物归属；再以应用、真实 MinIO／PostgreSQL、自动配置、HTTP 与浏览器回归验证部署映射不泄漏、正文核验、失败清理、原子提交、跨租户隔离和显式发布。索引构建需证明只读取冻结私有产物。

本 ADR 不接受 ADR-0032，不变更 STRUCTURED_DATASET 规则，也不表示 M3 完成或可以进入 M4。
