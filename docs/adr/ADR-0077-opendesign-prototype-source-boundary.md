# ADR-0077：OpenDesign 原型事实源与截图存储边界

## 状态

已接受

## 日期

2026-09-04

## 背景

WP-0016 已在 OpenDesign 中维护可操作高保真原型。将大量浏览器截图同时提交到仓库，会形成第二份易漂移的视觉事实、增加恢复上下文和版本库体积，也不利于继续逐任务修正原型。

## 决策

1. OpenDesign 项目是 WP-0016 高保真原型内容与视觉验收的唯一事实源；仓库只保留原型契约、设计令牌、脱敏夹具、可执行验证脚本和机器可读报告。
2. 浏览器验证仍可生成 390、1024、1440 与 reduced-motion 截图用于当次目视检查，但默认写入系统临时目录，不提交 Git。失败截图同样只作为临时诊断产物。
3. 自动验证报告可以记录截图数量、视口与结论，但不得把仓库内截图路径作为可复现前提。人工验收直接在 OpenDesign 中完成并登记结论。
4. 本决定不删除既有历史证据；从本决定生效的闭环开始不再增加截图。本轮移除上一账户闭环新增且可由验证脚本再生的截图，保留其 TAP、JSON 和 lint 报告。

## 影响和验证

- 浏览器脚本默认输出目录改为系统临时目录，并以 `.gitignore` 防止 WP-0016 PNG 误入库。
- `project-verify`、原型静态验证、浏览器专项和 OpenDesign lint 继续作为机器门禁；它们不替代人工验收。
- 不修改生产前端、后端、API、数据或部署。
