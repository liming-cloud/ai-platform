# ADR-0053 人工接受记录

## 决策

用户于 2026-08-05 接受 ADR-0053 方案 A：私有评测数据集使用严格 UTF-8 JSON Lines；服务端校验条目、
计算 SHA-256 与条目数，调用方不再提交或主张这些事实。

## 授权范围

- 可在 WP-0014 内实现私有内容校验操作结果、真实 MinIO／PostgreSQL 失败补偿、自动配置和令牌派生 multipart HTTP。
- 实现必须证明畸形编码／JSON、空集、`ANSWER` 空证据、`REFUSE` 允许答案、重复证据标识、伪造计数、无权限和跨租户均失败关闭。

## 仍不授权

本次不授权正文读取、导出、预算、人工例外、独立评测权限、`AssistantService.publishVersion` 接入、M7 或 M8 实现。
