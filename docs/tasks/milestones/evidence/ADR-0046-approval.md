# ADR-0046 人工接受记录

## 决策

用户于 2026-08-03 接受 ADR-0046 方案 A：完整历史回填与最小生命周期认证切换事实必须在同一事务
提交；切换后，`TenantLifecycle.status = ACTIVE` 是租户新会话资格的唯一状态来源。

## 授权范围

- 可在 WP-0014 内实现认证切换事实、与历史回填的原子提交、基于生命周期根的认证投影，以及
  新租户建立、激活、挂起与恢复的受限平台治理链路。
- 可建立纯领域、真实 PostgreSQL、自动配置、Bearer HTTP 和浏览器角色任务的红绿回归。

## 仍不授权

邀请、密码重置、租户销毁、正文读取、平台授权管理、评测、发布审批和 M7／M8 实现仍不在本次授权范围内。
