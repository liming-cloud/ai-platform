# ADR-0049 人工接受记录

## 决策

用户于 2026-08-04 接受 ADR-0049 方案 B：由 `organization-access` 提供服务器权威、分页且最小披露的
租户生命周期读取投影，并在隔离演示／测试中提供不含 `tenant-governance:write` 的平台运营主体。

## 授权范围

- 可在 WP-0014 内以测试先行实现生命周期读取投影、分页契约、平台权限失败关闭、最小前端读取工作区和
  演示／测试运营夹具。
- 可建立领域、应用、真实 PostgreSQL、自动配置、HTTP、浏览器两页签与运营拒绝的红绿回归。

## 仍不授权

成员资格列表、邀请、密码重置、平台授权委派、租户正文读取、评测、预算、发布审批、审计导出和 M7／M8
实现仍不在本次授权范围内。
