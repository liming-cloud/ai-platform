# ADR-0042 人工接受记录

| 字段 | 值 |
| --- | --- |
| 决定编号 | ADR-0042 |
| 决定类型 | M6 初始租户管理员身份与凭据模型 |
| 结论 | 用户接受方案 A：全局主体与凭据聚合。 |
| 批准人 | 用户，代表产品、架构与安全负责人。 |
| 批准时间 | 2026-08-03 |
| 提议基线 | `ce2b05084` |

## 接受范围

- organization-access 建立全局 `SubjectIdentity`，并让租户成员资格仅引用受控主体。
- 平台与租户登录共用主体凭据验证，再分别恢复 `PlatformRequestContext` 或 `TrustedRequestContext`。
- 建立租户只能选择已启用主体作为初始管理员，不复制密码哈希。

## 不授权范围

- 邮件邀请、密码初始化、外部身份联邦、租户销毁和数据保留。
- 评测、预算、发布审批、审计导出及 M7、M8 功能。

本记录使 ADR-0042 成为 `WP-0014` 的仓库事实。后续实现必须先产生实际红灯测试，迁移应保留原租户登录语义并经真实 PostgreSQL、HTTP、浏览器和全量门禁验证。
