# M6 人工评审拒绝：登录页视觉与任务引导

| 字段 | 值 |
| --- | --- |
| 决定编号 | HITL-0007-M6-REJECTION |
| 决定类型 | M6 人工评审拒绝 |
| 决定日期 | 2026-08-14 |
| 结论 | 拒绝 M6 验收；不得关闭 `WP-0014` 或进入 M7 |
| 依据 | 人工审阅本地登录页截图，认为视觉层级、品牌表达和任务引导缺失，界面不具备企业产品的可验收质量。 |

## 影响

- `project/evidence/M6-automatic-acceptance-review.md` 的技术自动验收仍有效，但不再足以申请 M6 通过。
- 当前前沿恢复为统一企业 SPA 登录页的视觉与可用性整改；不改变已验收的账户、权限、模型供应链、分页或服务端安全契约。
- 后续切片须先完成登录页设计卡和前端红绿测试，再实施最小视觉整改，并以真实浏览器进行人工复核。

## 必须关闭的验收缺口

1. 登录页须建立清晰的产品品牌、主任务和信息层级，不得呈现为裸表单。
2. 平台管理员与租户工作区的登录意图须可被人类理解；租户编码何时需要填写不能只依赖字段括号说明。
3. 桌面端须形成完整、稳定的登录画面，不出现被裁切、无内容承载或大面积无意义留白的布局。
4. 不得以改变认证、会话、租户隔离或密码输入安全边界换取视觉效果。

## 退出条件

- 设计、TDD、前端生产构建和本地浏览器回归均通过。
- 人工再次审阅登录页和登录后的统一工作区；只有明确批准后，才可重新申请 M6 里程碑评审。

本记录只反映人工对产品视觉质量的拒绝，不撤销 ADR-0057、ADR-0058、ADR-0059，也不改变 M6 仍在进行中的状态。
