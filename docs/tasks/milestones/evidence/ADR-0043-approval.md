# ADR-0043 人工接受记录

| 字段 | 值 |
| --- | --- |
| 决定编号 | ADR-0043 |
| 决定类型 | M6 平台租户治理授权与启动边界 |
| 结论 | 用户接受独立 `PlatformAccessGrant` 与 `tenant-governance:write`。 |
| 批准人 | 用户，代表产品、架构与安全负责人。 |
| 批准时间 | 2026-08-03 |
| 提议基线 | `c6b5f71fa` |

## 接受范围

- 平台会话仅在已启用全局主体拥有有效 `tenant-governance:write` 授权时签发。
- 平台与租户 Sa-Token 会话使用不同 login type；平台上下文不含租户、成员、目标资源或调用方追踪标识。
- 平台路由中的租户标识只是生命周期业务资源目标，不构成登录状态或正文读取权限。

## 不授权范围

- 平台授权管理接口、授权委派、邀请、密码重置、外部联邦与平台运营角色管理。
- 租户知识、问答、对象或审计正文读取。
- M6 后续评测、预算、发布审批、审计导出及 M7、M8 功能。

本记录使 ADR-0043 成为 `WP-0014` 的仓库事实。后续实现必须先有反例红灯，并以真实 PostgreSQL、自动配置、HTTP／事件、浏览器和全量门禁证明失败关闭。
