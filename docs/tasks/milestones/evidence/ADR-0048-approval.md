# ADR-0048 人工接受记录

## 决策

用户于 2026-08-03 接受 ADR-0048 方案 B：浏览器只保留一个同源登录入口，服务端以一次身份验证
签发不可互用的租户与平台 HttpOnly 会话 cookie；前端只读取非敏感能力清单，不能持有 Bearer token
或将其跨页签传播。

## 授权范围

- 可在 WP-0014 内以测试先行实现浏览器 cookie 会话、CSRF 防护、最小能力投影、统一前端会话状态和
  平台租户生命周期控制台。
- 可建立平台安全、organization-access、真实 PostgreSQL／Redis、自动配置、HTTP cookie 和浏览器
  角色任务的红绿回归。

## 仍不授权

成员资格列表、邀请、密码重置、平台授权委派、正文导出、评测、预算、发布审批和 M7／M8 实现仍不在
本次授权范围内。
