# ADR-0050 人工接受记录

## 决策

用户于 2026-08-05 接受 ADR-0050 方案 A：evaluation-operations 拥有独立且冻结的
`EvaluationRun` 与 `ReleaseDecision`；assistant-delivery 只能消费 `ReleaseAuthorization`
返回的、与发布前草稿修订完全匹配的不可变授权结果，再执行既有 `AssistantVersion` 状态迁移。

## 授权范围

- 可在 WP-0014 内继续完成评测、发布制度及其跨上下文最小事实的设计、影响分析和后续 ADR 提案。
- 后续指标、数据集、预算或例外规则获独立 ADR 接受后，可按测试先行实施相应的最小纵向切片。

## 仍不授权

本次不设指标阈值、预算计量、例外审批与期限、审计导出字段或保留规则；在这些规则各自通过 ADR
确认前，不得创建评测、发布决定、预算或导出生产实现。成员资格列表、邀请、正文读取、平台运营
工作台、M7 与 M8 实现也不在本次授权内。
