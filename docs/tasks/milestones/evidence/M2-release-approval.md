## 批准范围

- 接受 M2 的受控真实模型、数据库密文凭据、三层模型配置、可信问答与产品经理浏览器验收证据。
- 确认 API Key 不可回显，真实模型调用仅限研发与受控验收，不构成生产 SLA、质量或成本承诺。
- 确认产品采用企业控制台、问答工作台、设备问答界面三个前端应用，并通过 SDK/API 提供渠道调用能力。
- 确认企业控制台包含严格隔离的平台管理范围与租户管理范围；平台管理员和平台运营为独立授权角色。
- 批准 M3 仅开始受治理数据工作，不提前交付 M4 至 M8 的功能。
