# ADR-0072 人工接受

用户于 2026-08-30 明确要求：知识库操作不得作为平台管理员功能，知识库必须归属单一租户，并由各租户在自身租户范围内创建、维护和使用。

用户同时要求使用真实浏览器操作完成验收。该要求固定为不可由 HTTP、Playwright 截图或静态代码检查替代的人工门禁；平台管理员、租户管理员和普通用户必须分别验证导航、直接 URL、实际任务与失败关闭。

本次接受允许在 `WP-0014` 内将租户知识库提升为一等工作区，并把“首份文本发布”调整为可选快速入门。平台基础设施连接、可授权对象范围和脱敏聚合继续属于平台治理，但不授予平台读取租户知识库名称、来源、正文、引用或成员明细的能力。

该记录只提供当前仓库和对话的本地追溯，不声明用户身份的密码学验签。M6 与 `WP-0014` 保持进行中；真实浏览器角色验收及既有 P0/P1 全部关闭前不得进入 M7。
