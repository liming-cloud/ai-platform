# ADR-0062 人工接受记录

用户于 2026-08-11 接受租户历史直接权限退役的方案 A：由租户运营负责人提供显式、可审计的逐成员迁移清单，
服务端完成权限等价校验、原子角色绑定、会话撤销、审计与直接权限删除。

本次接受不授权按权限集合自动创建角色，也不授权删除 `membership_permission`、认证兼容读取、最后访问管理员
保护或表结构。每份实际清单仍须由运营负责人提供租户、成员、历史权限摘要、目标角色及批准撤销例外；包含
`model-tenant:write`、`model-personal:write`、`model-platform:write` 的成员资格尤其不得由实现推断职责。

正式浏览器 HTTPS 角色证据继续按 ADR-0048 的本地延期处理，不能由本记录替代；M6 与 M7 的既有门禁不变。
