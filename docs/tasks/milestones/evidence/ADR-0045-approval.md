# ADR-0045 人工接受记录

## 决策

用户于 2026-08-03 接受 ADR-0045 的严格方案 A：历史租户状态不是持久化赋值来源，回填必须通过
`TenantLifecycle` 的合法迁移达到与历史状态一致的最终状态。

## 授权范围

- 历史 `ENABLED` 租户在同一回填事务中完成建立、初始管理员确认和激活，最终为 `ACTIVE`。
- 历史 `DISABLED` 租户在同一回填事务中完成建立、初始管理员确认、激活和挂起，最终为 `SUSPENDED`。
- 可在 WP-0014 内为这两条路径建立领域、真实 PostgreSQL、发件箱、自动配置和受限平台治理路由的
  红绿验证。

## 仍不授权

历史映射值写入版本库、日志、令牌、HTTP 请求或应用配置；以及平台授权管理、邀请、密码重置、
租户销毁、正文读取、评测、发布审批和 M7／M8 实现，仍不在本次授权范围内。
