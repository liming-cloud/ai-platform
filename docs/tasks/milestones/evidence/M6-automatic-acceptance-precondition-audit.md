# M6 自动验收前置条件审计

## 结论

截至本次 `WP-0014` 目录可用性切片，ADR-0063 的本地身份基线、ADR-0064 的空库认证切换和 ADR-0066 的平台范围供应链均已落实；ADR-0062 的逐成员清单不再是本地 M6 路径的输入，且相应未接线迁移代码已经删除。全局目录现在只消费平台范围已发布、当前可用的部署快照，租户范围连接和部署没有被提升或复用。M6 自动验收仍不得发起：缺少从已登录平台管理员到租户首份发布的完整当前镜像任务证据，以及该闭环后的全量验证汇总和人工评审。`M7` 必须保持未激活。本记录不替代任何浏览器角色验收。

## 硬阻塞与退出条件

1. **已登录供应链到首份发布的当前镜像回归**：以平台管理员实际完成确定性平台连接、发现、发布嵌入部署、建立并发布目录；再以租户管理员创建／启用模型配置并完成首份发布。需要复核服务端分页、显式嵌入模型选择、MinIO／PostgreSQL HTTP 行为和浏览器注意力保护，不能以直接 SQL、无会话 HTTP 或页面加载代替。
2. **可授权浏览器会话**：当前统一 SPA 仅能显示登录页，工作区没有可授权使用的验收账户凭据；不得猜测、读取摘要或伪造浏览器会话。提供受控测试会话或允许的测试账户后方可执行上一项。
3. **自动验收汇总**：上述回归完成后，以当前提交重新执行工作包声明的全量验证并登记 M6 自动验收记录；随后才可请求独立人工评审。

ADR-0062 的清单迁移只适用于不可清理的非本地历史环境。ADR-0063 已明确将它排除出当前本地 M6 基线，并要求删除未接线实现；因此它既不是本地自动验收的硬阻塞，也不是需要人工回答的问题。

## 门禁判定

## 2026-08-12 续证更新

ADR-0064 已按 local repeatable migration 落实：空库切换事实存在，已有租户时不写入。当前本地租户已完成平台建立、激活与浏览器登录，模型供应链已完成确定性连接、真实探测和发现摘要续证。平台运营员的 HTTP／浏览器回归现固定为只进入无数据 `/platform`、直达平台租户与账户治理均拒绝，修正了过期的空工作区断言。此前的生命周期认证切换硬阻塞已解除；`http://localhost:13000` 继续作为 ADR-0063 允许的本地浏览器验收入口。剩余条件是首份发布的真实 PostgreSQL／MinIO／HTTP／浏览器续证，以及以当前提交执行完整 M6 自动验收汇总；人工评审登记前 `M7` 仍必须保持未激活。

- 当前工作区的 `make project-verify`、`make validate`、后端 Maven 反应堆、前端构建和平台角色浏览器回归均已通过；这些事实由 `WP-0014-local-identity-baseline-and-browser-regression.md` 绑定当前基线，但不证明租户会话已可签发。
- 受信任 TLS 已由 ADR-0063 移出 M6 门禁；`http://localhost:13000` 验收仍保留 `Secure`、`HttpOnly`、`SameSite=Lax` 与 `__Host-` cookie，不得将本地例外扩展为生产配置。
- 生命周期认证切换决定、首份发布回归与自动验收汇总完成并登记前，不得创建 M6 自动验收通过记录、不得请求 M6 人工评审、不得激活 M7。

## 2026-08-13 当前前沿复核

ADR-0065 的固定 `PLATFORM_ADMINISTRATOR` 角色、`model-platform:write` 能力投影、PostgreSQL
角色约束、同源 HTTP 与统一 SPA 浏览器回归已经完成。ADR-0066 已接受并落实独立的平台范围连接、发现、
部署、验证与目录来源；它不引入开发、测试、生产等多环境复制功能。ADR-0063 的
`http://localhost:13000` 本地浏览器基线继续有效；受信任 TLS、历史直接权限迁移和空历史认证切换均不是
当前本地 M6 的阻断项。

当前自动验收**仍不可发起**，原因是完整业务任务尚未续证，不是目录所有权边界或 TLS 环境。目录创建／发布、
租户模型配置建立／启用与运行时均会复核平台来源；目录选择页也已在 PostgreSQL 分页／总数层排除失效快照。
但未取得允许使用的已登录浏览器会话，不能将无会话 HTTP 或登录页加载误记为完成。

| 条件 | 当前状态 | 退出证据 |
| --- | --- | --- |
| 平台目录供应来源 | 已完成；ADR-0066 的平台范围连接、发现、部署与目录快照保持独立于租户资源。 | `ADR-0066-approval.md`、平台供应链与目录快照证据。 |
| ADR-0065 目录闭环 | 后端失效关闭和选择器分页已完成；完整已登录任务未完成。 | 平台连接至目录发布、租户配置启用及失效关闭的当前 Compose HTTP 与浏览器证据。 |
| 首份发布续证 | 未完成；依赖可用的目录和租户模型配置。 | 当前 Compose 的 PostgreSQL、MinIO、HTTP 与浏览器“显式模型选择→首份发布”证据。 |

评审或激活 M7。
