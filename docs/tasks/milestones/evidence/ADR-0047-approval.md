# ADR-0047 人工接受记录

## 决策

用户于 2026-08-03 接受 ADR-0047 方案 A：创建租户可提交
`initialAdministratorSubjectId` 作为既有受管业务资源目标；平台操作者、权限、令牌、渠道和追踪标识
仍只能由 `PlatformRequestContext` 从 Bearer 会话恢复。

## 授权范围

- 可在 WP-0014 内实现新租户的原子建立、初始管理员成员资格、最小生命周期状态事实及受限平台路由。
- 可建立纯领域、应用服务、真实 PostgreSQL、自动配置、Bearer HTTP 和浏览器角色任务的红绿回归。
- 新租户在 `PROVISIONING` 时不得取得租户会话，后续只能通过合法生命周期迁移激活。

## 仍不授权

主体搜索或详情、邀请、密码初始化、外部身份联邦、租户销毁、正文读取、平台授权管理、评测、发布审批和
M7／M8 实现仍不在本次授权范围内。
