# M6 实现与验收

细项唯一来源为 [implementation-map.json](implementation-map.json)：78 入口、155 操作，66 个 M6 生产入口。页面与跨包操作分别判定，不能以页面存在或原型通过替代真实生产。

按 [ADR-0092](../../../architecture/decisions/ADR-0092-m6-platform-overview-late-delivery.md)，工作顺序为 WP-0017 → 0018 → 0019 → 0020 → 0021 → 0022 → 0023 → 0024 → 0025 → 0027 → 0026 → WP-0014 人工复评。ADR-0094 将租户概览并入 WP-0027、新会话正例移交 WP-0024，四项仍待真实验证；平台概览仍待专属事实契约，WP-0026 只做全量复验。当前状态只读[任务索引](../../README.md)。

矩阵只接受已冻结契约、真实验证命令、责任包证据和完整源码提交。原型页面清单与操作账本从 WP-0016 冻结资产读取；原人审仅证明原型。历史 G1～G10 的时点证据由 history-index 恢复，不声称当前 M6 已通过。

M6 收口同时满足安全、可信质量、性能、三角色真实旅程、功能与原型一致性及人工接受。WP-0017 在 ADR-0092 调整后的范围完成[组合证据与最终部署收口](../../WP-0017/evidence/WP-0017-adjusted-scope-closure-20261006.md)。WP-0018 各独立切片证据及调整范围后的整包复验前沿见[任务恢复入口](../../WP-0018/README.md)，实时操作状态只由实现矩阵维护；这里不复制进度计数。完整租户工作区及新会话正例按 ADR-0094 由后置包完成，不能把责任移交当作验收。66 页生产实现和 M6 仍未完成。
