## 行为和只读数据库事实

最终镜像使用新建 0700 临时目录与 0600 输入/输出文件执行 `make acceptance-work-package WP=WP-0017 SLICE=security`，**10/10 组通过**：平台管理员真实登录，经正式 API 原子创建独立目标与对照租户；服务端默认 8 小时/5 次/15 分钟；取消零写入、范围拒绝、保存版本递增、目标旧会话立即撤销、对照租户和平台会话不受影响；新目标浏览器会话为 4 小时；旧版本、未知字段、缺少 CSRF 和租户身份写入均拒绝；两种租户登录入口共用目标身份失败观察，三次失败锁定且正确口令不能提前解锁；390/1024/1440px、200% 文字、键盘和 reduced-motion 无裁切。用本轮新建的未锁定对照管理员执行 `SLICE=login`，**15/15 组通过**。

## 原型视觉对照与限定差异

同一独立 Chrome 对固定 OpenDesign 和最终部署页在 390/1024/1440px 分别截图并人工查看；截图、运行日志和凭据只在 `/private/tmp`，未入仓库。观察数据 SHA-256 为 `1dba5e5bcd79ae71df6d16a89d50901fe92a82249efa4d3edf1a9cc5fb005526`。暖色画布、16px 正文、Georgia/中文宋体标题、单个 `h1`、`R` 与“可信 RAG”、租户设置五项、三项顺序和值单位、导航当前/非当前色、取消与保存短按钮的 14px 字体及 54/82px 宽度一致。主卡片三档位置和尺寸分别为 `(16,516.4,358,247)`、`(112,334.3,880,162)`、`(272,336,1136,162)`，原型与生产一致。弹窗宽 390px 时为 352px 且字段单列，1024/1440px 时为 768px 且字段双列；没有横向溢出。

ADR-0079 要求变更登录策略前告知目标租户旧会话将立即失效，固定原型的弹窗没有该提示。生产在保存按钮前显示“保存后，此租户现有会话将立即失效。”，不修改 OpenDesign。该提示使生产弹窗高度比原型在 390px 多约 39.1px、在 1024/1440px 多约 28.7px，未遮挡控件。2026-09-29，用户在获知此处精确差异及其取舍后要求继续推进任务；本切片因此沿用已接受的 ADR-0079 与 ADR-0086 安全提示，**仅将这项安全提示及其弹窗高度增量记为限定差异**。这不代表弹窗与原型完全相同，也不豁免其他导航、文案、间距或响应式差异。

首次实际验收的失败来自验收脚本把主动发送且被服务端拒绝的 PUT 算进下组 UI 保存次数；只读库核对证实当次产品保存只改目标策略。后续短按钮断言曾在 Fluent Dialog 进入缩放期间读取视觉宽度，20 次只读复现均显示动画时 `45.9/69.7px`、稳定布局为 `54/82px`；脚本改为测量布局宽度，未放宽字号或 1px 容差。上述失败日志和合成对象留在各自临时目录，未当作通过结果。

下一独立产品切片为 `platform-accounts:0` 的平台账户创建与首次登录，实施前须冻结专属 ADR、工作包边界和固定原型；角色目录及平台账户其他操作留待各自切片。`platform-tenant-detail:0` 的导航合同仍待处理。普通会员、模型、知识接入、查询等属于后续包；WP-0017 整包和 M6 仍未完成。
