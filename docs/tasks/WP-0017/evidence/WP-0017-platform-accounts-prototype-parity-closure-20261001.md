## 固定原型对照与失败记录

同一独立 Chrome 对固定 OpenDesign 和实际生产页执行 390/1024/1440px 页面对照，并检查创建、重置、状态弹窗的 390/1440px 状态。截图只在 `/private/tmp`，没有进入仓库；最终无秘密视觉指标 JSON 的 SHA-256 为 `b279ee2e4fef4af01827a2389d20ab5a13a9b02c6e2caa686aed3b1593a6d9d1`。暖色画布、正文和标题字体、侧栏品牌、页面结构、表格、分页、弹窗层级及短按钮均按固定原型人工复核。原型模拟账户数量、演示说明和未实施的 M8 导航不是生产业务事实，分别按 ADR-0083 的已接受范围处理。

旧候选在 390px 的末行“更多”与分页相差 64px。新候选让普通单元格保持原型的 48px 基线，末行“更多”与分页顶边在单行页面同为 `y=937px`，10 行筛选页面的相对差为 0px。固定原型在该位置的中心命中分页计数文字，无法点击；生产只调整触发器的叠放层级，视觉坐标不位移，中心命中 `SUMMARY`，点击和键盘均可展开。200% 文字时普通单元格按内容增高，无水平裁切。本片没有新增导航、文案、间距或响应式视觉例外，也没有修改原型；可操作性遵守 ADR-0087。

本轮完整验收曾有三次未通过，均未计为成功：第一次停在重置阶段，随后只读数据库证实该次重置尚未提交；对该精确合成账户定向复现得到重置 204、旧会话 401、旧密码 401、新密码登录 204，原始浏览器等待原因无法从当次屏蔽的错误中还原，脚本已增加不含秘密的阶段定位。第二次在读取密码不一致提示时发生瞬态失败，改为等待同一条精确提示后再检查零 POST。第三次新增的 390px 断言在从桌面视口切回移动端的媒体布局尚未稳定时读取；只读复现量得瞬态差 16px、稳定后差 0px，脚本改为等待实际 44px 触发区，再保留原有严格断言。最终固定脚本在新目录完整通过，先前失败对象及日志未删除。
