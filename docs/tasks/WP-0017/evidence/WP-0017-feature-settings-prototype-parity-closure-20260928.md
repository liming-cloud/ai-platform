## 固定原型对照与边界

同一独立 Chrome 分别打开固定原型和最终生产页，人工查看 390／1024／1440px 截图，并只读比较主标题、八项顺序、16px 正文、Georgia／宋体标题、暖色画布、导航、按钮、状态徽标、勾选框及编辑区位置。功能页只有一个“可用功能”主标题；390px 保存按钮为全宽，桌面为短按钮；三档均无横向溢出。编辑区原型与生产盒宽分别为 `358/358`、`880/880`、`1136/1136`px，起点和导航位置相同；主要文字和布局几何差值不超过 1px。观察数据 SHA-256 为 `ea965e3fb1fac8f43fa9f784849a6cb547bfdb33e6b0b05034110c4e995f9e92`。截图和观察日志仅在 `/private/tmp`，未提交仓库。

原型模拟租户名与正式接口创建的合成租户名不同，生产按真实服务端值显示。原型全局导航还含“平台运行状态”“备份与恢复”；当前生产 `NAVIGATION` 没有这两个尚未交付的入口。依用户已接受的“未实现功能到对应切片再验证”边界，本次不伪造可点击入口，也不把全局导航差异宣称为已闭合；本结论只覆盖 `platform-tenant-features:0`。后四项普通成员对话能力的直接执行约束由 WP-0018～0025 在对应能力交付时继续验证。
