## 布局修复和原型对照

旧镜像的复选框标签自带上下留白，使“撤销全部会话”区域高 88.25px，而固定原型为 76.91px。新候选将标题和说明放进同一个可点击标签，保留整块可点语义；在部署页点击说明文字会勾选复选框。密码字段、复选框和按钮只做本弹窗的间距校正，不更改密码或会话合同。本地预览曾读取滞后的 Vite CSS；只在确认新端口 HTTP 响应包含新规则后采信测量。`make frontend-test` 通过 43 个文件、222 项及构建，`make architecture-guard` 的 38 项和前后端门禁通过。

新镜像与固定原型在 390／1024／1440px 下的弹窗宽度同为 352／608／608px；原型高度为 565.8／446.6／446.6px，部署页为 565.6／446.4／446.4px，三档相差约 0.2px。新镜像页面横向溢出为 0；390px、200% 文字时两个密码输入完整、确认按钮可达，键盘可打开“更多”，说明文字点击可勾选复选框，reduced-motion 下无未完成动画。只读视觉探针拦截的业务 API 写入为 0。最终临时截图与无秘密几何记录位于 `/private/tmp/wp0017-admin-final12-visual2.kdyQnz/`，目录 0700、记录 0600；不进入仓库。首次原型静态资源加载未完成，未采信其失败截图；恢复静态服务后重新运行的完整对照错误日志为空。

用户 2026-09-24 明确允许生产安全说明替代原型“演示密码说明”，并将未实现功能的原型一致性留到相应功能切片。本页保留默认折叠说明，不展示演示口令；M8“平台运行状态”“备份与恢复”等无真实目标的入口不提前伪造。该决定只适用于所述范围，不把后续页面或 WP-0017 整包标记为通过。

## 尚未收口的差异

固定原型在 390px 下，表格行底和分页顶部同处 `y=644px`，“更多”触发区为 `y=644–688px`；滚动到该触发区后，其中心命中的是分页文本而不是“更多”。部署页把“更多”留在行内，中心命中自身，键盘展开也通过。此差异属于固定原型自身的交互遮挡，不在已接受的演示说明或未实现功能延期范围内；仍待明确验收处理，当前不声称管理员独立页原型一致性已通过。`platform-tenant-admins:0`、`:1` 保持 implemented，WP-0017 整包与 M6 均未完成；不启动配额、功能开关、登录策略、平台账户、普通会员或 M8 的实现。
