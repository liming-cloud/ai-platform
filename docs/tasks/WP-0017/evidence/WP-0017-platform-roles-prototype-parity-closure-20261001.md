## 红绿证据与控制面纠正

[上一轮部署验证](WP-0017-platform-roles-production-verification-20261001.md)保留原结论：角色正文一致，390px／200% 文字的共享导航仍阻断。新断言在旧实际前端 `af1e0f45664c5ccd1818f8731e2782c10da8a9f8` 明确失败，最终候选同一断言通过。同步阶段还发现入口数量导致自动拉伸、换行高度不同，先在原型固定已有宽度基线，再承接生产；未放宽字号、几何或裁切断言。

原型观测首轮错误要求短页面把顶栏完全滚出屏幕，随后错误要求桌面有界滚动区的全部导航同时在屏内。分别按真实文档坐标位移和滚动后逐项命中修正观测，保留失败日志；移动完整标签及零遮挡要求不变。

新原型使 `history-index` 的原文保留校验正确拒绝 CSS 变化。核对来源 `e7a1d673229acf8c7932dcae85699e517f2adab5` 原对象、原 SHA-256 `2e627c22e4a9ce1d37ce90ce95a92673b1bc13d3ddbcbf4f51f5eb33d215efa4` 与依赖后，只将 CSS 单条处置从 `keep` 改为现有 `update`，登记用户接受与本证据。650 条数量、历史来源、原摘要、旧证据与校验器均未改写；其余保留原文仍要求摘要一致。
