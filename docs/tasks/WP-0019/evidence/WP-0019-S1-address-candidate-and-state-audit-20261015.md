## 根因、修订与红绿

390px 上以原生 HTML 的只读 URL、可编辑 URL、只读 text 作对照，再对照原型和生产。原型及生产只读 URL 的 `scrollWidth/clientWidth` 均为 409/316；Home／End、系统首尾快捷键及全选后方向键不能可靠到达完整首尾，可编辑原生控件则可以。等待原生滚动稳定后结果相同，值和只读属性不变；不是生产独有 CSS 差异，也不能仅因存在内部滚动就断言全部内容可读。

候选仅在固定厂商地址下增加完整、可换行的非秘密地址说明，并由字段的 `aria-describedby` 关联。仍使用原 `runtimeBaseUrl` 输入及预设解析结果保存；地址展示用 `textContent`，不改变协议、认证、SSRF 或持久化。自定义输入、业务空间缺失和切回自定义时展示为空且隐藏，防止复制任意输入；没有新增保存边界。

在现行质量脚本增加三尺寸反例，原版本因缺少完整地址展示而三项失败；同一测试在候选上转绿。覆盖四个固定厂商的八组能力组合、63 字符合法业务空间、正常／200% 地址文字、字段值不变、隐藏和自定义切换，不缩小字号或放宽 1px 几何容差。冻结的历史模型浏览器脚本保持原 SHA-256 `56bc4a0976b46eab7b04f577806149dd6311299669d26907fcae712de2b72622`。
