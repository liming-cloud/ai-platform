## 决定与局部修正

用户明确回复“补齐原型既有操作入口（推荐）”，授权先修正原项目、形成可审阅候选，再按人工门禁承接生产。这是本次实施授权，不能替代对固定候选的人工接受。此前两条空态文案接受持续有效，见[接受记录](WP-0019-S1-prototype-acceptance-20261012.md)。

原型的评审 `empty` 原先被通用面板提前返回，目录没有创建按钮及弹窗，详情没有返回操作。进一步验证真实合成连接列表为空的路径：目录仍挂载创建按钮，但显示空表格而非已接受的空态说明；详情使用通用模型记录文案。本记录补足此前仅对评审空态观察的范围，不把它推导为所有真实空目录都不能创建。

通过 OpenDesign Cloud 文件工具修改原注册项目的 `prototype.js`，仅调整 `renderPlatformModelConnections` 与 `renderModelGovernance`：目录空态保留既有页头“新增供应商连接”及同一创建表单；详情空态保留“返回连接目录”。评审空态不重置演示集合；实际空集合使用相同说明面板。加载、错误、拒绝及其他模型入口仍由原路径处理；连接存在而发现候选为空仍展示连接详情。没有新操作 ID、共享状态机或生产公共契约变更。

未修改已接受说明、方舟独立发现认证、样式、厂商预设及 OpenDesign Cloud 项目定位。未创建副本，未改生产前后端、部署、数据库、fixture 路径或完成事实。

## 真实红绿与回归

在既有 `platform-connection-credentials.browser.test.cjs` 中新增 8 个行为场景。修改原型前实际执行：8 项均失败；三尺寸评审空态缺创建操作，三尺寸业务空集合缺说明面板，两种详情空态缺返回入口或已接受文案。失败来自目标行为，不是生产登录或厂商环境。

修正后保留中间失败日志。新增关闭测试最初只等弹窗隐藏／焦点归还，提前读取了异步 `close` 处理前的输入；一次未同步完成监听注册的尝试已终止。最终在关闭前同步注册原生事件，并在既有 5 秒界限内等待关闭处理完成，再严格断言三项输入清零、焦点恢复及集合不变。没有修改产品关闭处理、放宽清零断言或增大容差。刷新后重新放大文字，核对取消和保存时的实际输入字号均为原值两倍。
