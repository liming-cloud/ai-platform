## partial／disabled 的结论

原型两页 × 两态 × 三尺寸 × 两字号共 24 次观察通过：`partial` 页头为“部分完成”，`disabled` 为“暂不可用”，主写操作禁用，搜索、分页、查看和返回仍可用。原型页面禁用时仍可展示“已发布”对象，故页面可操作性不等同对象生命周期。

源码补齐既有连接 `DISABLED` 的三尺寸／两字号隔离回归：禁止探测、无发布动作、键盘返回且写入 0。这不是实际生产连接停用，也不证明页面级 `disabled` 已验收。现行 API 没有页面部分完成或全目录暂停事实；候选待确认、验证过期、缺少 AK/SK、某条连接停用均不能自行映射为页面状态。

[页面状态触发提案](../page-state-proposal.md)已提交为待审稿，绑定 5216bd2922ecd4dc8c6f5b07e7cc6f62f65e9a7d；建议有限辅助读取降级，并保留未定义的页面暂停缺口。未接受、未登记新 ADR、未实现降级，现行必要读取失败关闭和 401／403 清除行为不变。本轮没有给生产增加原型模拟 URL 开关。
