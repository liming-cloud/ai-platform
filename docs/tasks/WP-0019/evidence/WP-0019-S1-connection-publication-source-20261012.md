## 本轮结果与边界

实现 D1 的连接独立发布事实，不改变连接的 VERIFIED 状态或连接修订。发布绑定连接修订、有效成功探测、独立发布序号和操作者；重复命令返回同一条原事实。发布不创建模型部署、租户配置或授权，也不能据此声明模型可用。

写入在平台身份及 MODEL_PLATFORM_WRITE 权限通过后执行。仓储锁定平台连接，锁内读取当前修订并按读取时刻复验探测有效期；新探测、轮换、停用和过期不能借用历史发布。发布及最小审计在同一事实中原子保存。首次与重放均读取实际落库记录，避免 JVM／PostgreSQL 时间精度差异。缺少必需仓储时装配失败，不提供可空持久化回退。

接口为 POST `/api/v1/platform/model-supply/connections/{id}/publish`（必须提供非负 expectedVersion）及 GET 同资源的 `/publication?expectedVersion=...`。写入操作者只取正式平台上下文；公开视图只含连接标识、发布标志、两个修订及探测／发布时间，不含秘密、端点或审计主体。缺失请求版本拒绝为 400，权限不足和当前修订／状态冲突沿用既有异常映射。MockMvc 验证不能替代真实会话 HTTP。

新增迁移仅建立不可变发布表和唯一约束，不回填历史 VERIFIED 为已发布。本轮仅在 Testcontainers 隔离数据库执行迁移，没有在部署数据库应用迁移。
