## 接受与变更

用户明确回复“接受该候选，继续 S1 生产承接（推荐）”，已在实施前提交[人工接受记录](WP-0019-S1-prototype-acceptance-20261012.md)。旧[候选执行证据](WP-0019-S1-prototype-empty-actions-20261014.md)保留其提交时点的“待接受”，不改写日期和历史结果。

本批只修改两个平台连接组件、其样式及两个既有隔离浏览器脚本。原项目及原型源文件未改，前后端公共 API、权限、数据结构和业务操作不变。

- 未筛选的真实空目录采用已接受的说明面板及“暂无记录”，保留同一创建表单。搜索无匹配记录保留筛选和分页；已有连接的空候选仍显示连接详情，不能当成连接不存在。
- 仅精确连接读取的既有 HTTP 404／`MODEL_RUNTIME.RESOURCE.0001` 显示详情空态；匹配最终失败的错误对象，避免并发预设 403 被另一个 404 标记覆盖。其他读取失败和拒绝保留失败状态，返回目录保留页码、页大小和查询位置；重试后焦点归属恢复页。
- 使用正式 `DialogTrigger` 登记焦点恢复目标，解决真实主题包装下身份替换后模态隐藏范围残留。没有手工移除 `aria-hidden`、取消焦点约束或修改第三方包。
- 空态标题行高改为原型 1.35，覆盖旧 1.3 规则；弹窗说明位于标题之前，字体与间距按原型。下拉框随放大文字扩展高度，保留普通／紧凑／触控基线，不靠减小字号解决裁切。
