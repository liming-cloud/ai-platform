## 唯一结果与授权边界

下一完整操作为“执行能力验证”：只验证精确部署修订的能力、输入限制、预算、驻留来源和版本化安全样本。它不发布部署、不创建目录或生效租户授权，不调用知识／助手／问答功能。一次最小协议调用不能替代全部验证。

用户于 2026-10-20 接受下述推荐厂商／模型组合和预算方向，并要求继续离线编排；接受输入、摘要与授权边界已登记 ADR-0100。此前最小协议基础已独立闭合，本轮补齐预算与版本化样本的离线内核。真实调用须在精确对象、修订、账户适用费率及请求材料齐全后另行授权；不索取已经有效的登录密码，不把方向接受解释为允许扣费。

## 三类请求与判定

| 协议 | 冻结请求 | 成功必须同时满足 | 必须失败的反例 |
| --- | --- | --- | --- |
| Chat | 精确 model；仅合成文本 messages；stream=false；max_completion_tokens=64；方舟按明确请求配置 thinking.type=disabled；无 tools、媒体或外链 | 正文非空、符合该样本预期；输出与 usage 有界，结果归属精确请求；不声明流式或完整上下文上限已实测 | 空正文、只返回思考、工具请求、预算超限、样本指令越界、错修订／迟到结果 |
| Embedding | 精确 model；单条文本 input；encoding_format=float；BGE-M3 不提交其不支持的 dimensions 参数 | 一条向量、index=0、恰好 1024 维、所有值有限且非全零；与草稿声明一致 | 空／错维向量、NaN／Infinity、重复或缺失索引、多余结果、错误协议 |
| Rerank | 精确 model；query 与三个 documents；top_n=3；return_documents=false；不发送媒体、外链或工具 | 三个唯一索引均在 0～2；得分有限且按相关性非递增；结果数与请求一致，不擅设跨厂商通用得分范围 | 越界／重复索引、非有限分数、错误排序、缺失项、回显材料或原始错误 |

Chat 参数区别有实际成本含义：方舟 `max_completion_tokens` 同时限制思考和正文；不能只限制可见回答后宣称总输出有界。不支持该字段的兼容厂商失败关闭，不能删除限制再重试。本轮用完整三样本替代旧平台最小探测，Chat／Embedding 通过 Spring AI 与受控传输执行，重排使用独立 Port。响应须携带实际 usage；工具／媒体混入、截断、缺量、错维、索引或排序不符均不能通过。此处仍在验证生产编排，不代表已执行真实厂商合同。

扩展只依赖公开 `application/.../port/out/verification` 与 facade，不导入 domain／infrastructure。缺对应适配失败关闭；历史未声明输入的部署不能走旧最小探测。新草稿只有完整预留、三样本及提交复核均通过后才能写入 VERIFIED；发布仍保留 `PLATFORM_DEPLOYMENT_CONTRACT_PENDING`，直到原子供应目录和授权合同完成。

## 预算与版本化安全样本

沿用已接受原型，每个精确部署的一轮验证最多 3 次请求、每次合成输入合计不超过 128 个 Unicode 码点、每次输出不超过 64 Token、整轮总截止时间 30 秒；自动重试为 0，不并发。三类分别纳入精确授权并各执行一轮时最多 9 次、90 秒；只批准一类三次时，不能扩大到其余两类或无限重跑。Embedding 和 Rerank 不消耗生成输出额度，但所有输入项目都计入 128 字符，重排 query 与三个文档相加计数。

本次费用方向已接受为每类 CNY 0.03、三类合计 CNY 0.10，**尚未授权真实执行**。执行前固定币种、计费单位、模型精确版本、地域、费率来源／日期和保守用量，再预留整轮费用。128 字符不等于 128 Token；缺费率、分词／计量依据或预留不足时不发请求，不假设免费，不把该限制称为平台月度硬扣费。

方舟[当前价格说明](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)列出常规在线 doubao-seed-2.1-turbo 输入 3、输出 15 元／百万 Token；若执行前证明含消息开销的每次输入上限为 1024 Token，则三次预估上界为 CNY 0.012096。该计算是带前提的审阅估算，不是当前账户报价或实测费用。硅基流动的账户适用价格、重排计费单位尚未固定，应在其[官方定价入口](https://siliconflow.cn/pricing)核对并形成快照后再批准执行；缺少依据时保持预算未验证。

样本集版本固定为 `s2-capability-safety-v1`，用于已接受方向的离线编排。每类恰好三个固定用例，全部使用以下公开合成文本；实际执行材料逐项绑定样本版本、内容摘要、精确目标和输入参数，不包含真实租户材料或秘密。

## 生产编排与后续验收

本轮复用 `PlatformCapabilityVerificationSession` 与 `PlatformCapabilitySafetySuite`，前者保持包内，后者只额外公开固定版本和有序摘要清单供存储独立复核。旧离线验收事实保留于[预算与样本证据](evidence/WP-0019-S2-budget-safety-offline-20261020.md)，不能替代本轮源码、事务、部署或厂商证据。

- 精确部署／连接修订、模型、驻留、声明输入摘要和参数参与绑定，整轮使用独立随机计划。三样本内容与预期不变，不接受运行时替换或删减。
- 账户计价与独立输入 Token 上界按连接修订、模型、类型和驻留精确匹配。默认没有报价；缺失、过期、错误计量或费用超限时零外呼，不假设免费。
- 首次外呼之前，以短事务冻结完整费用上界、操作者权限修订、目标／计划、报价和固定样本清单。活动唯一键排斥并发。失败和未知用量不自动退回预留，超时退休不重发旧请求。这不是扣费账本或月度资金控制。
- 每次样本解析凭据时，一条安全投影核对当前已发布修订并读取推理密文；轮换后不回退其他修订，不读取方舟发现 AK/SK。凭据解析、调度与网络共用剩余期限；底层不跟随重定向或自动重试，响应体有界，取消会中断网络等待。不能据此承诺厂商一定停止计费。
- 网络不持有数据库事务。最终短事务重新核对当前主体／权限、平台会话、来源发布与发现根、声明、报价、期限及 CAS。仅精确固定版本的三个通过摘要可写成功；验证事实、成功状态、预留终态和独立审计原子提交，末尾审计失败回滚成功事实。
- HTTP 200 但 `verified=false` 不等于通过。页面显示稳定失败原因，不静默刷新、回显厂商正文或把未知错误当成功。

本轮不改原型，不重复 S1／既有草稿与全页面验收。当前四应用实际部署为 `73fc9ee035d0b157861439f422f5de5af6a40bdd`，1286 项后端、336 项前端、真实隔离 PostgreSQL、六次失败反馈布局观察和四入口烟测通过，详见[编排交付证据](evidence/WP-0019-S2-capability-orchestration-delivery-20261021.md)。浏览器中的未通过响应为隔离注入，没有正式推理；原项目四份相关资源与接受版本逐字节一致。产品操作计数保持 S2 2／4、WP-0019 7／29。真实厂商三类合同、原子部署发布及生效供应授权仍未完成，S3～S6、整包和 M6 未完成。

## 生产编排实施合同（ADR-0100 的技术细化）

保持原 `/deployments/{id}/probe` 请求的 expectedVersion／timeoutMillis 与响应键。平台会话由控制器提供仅服务端可构造的活动检查，模型权限、主体／权限修订和来源在短事务提交前重新核对，不把令牌放入命令、日志或存储。Chat／Embedding 使用 Spring AI 的独立平台样本端口；RERANK 使用独立端口与固定文本重排协议，不走 Chat／Embedding 默认分支。扩展输入只含冻结模型、非秘密声明、平台凭据引用、固定合成样本、绑定与剩余期限；输出正文／向量仅存在于内存。

账户适用报价从启动时非秘密配置读取，按连接精确修订、模型、能力与驻留选择；必须带材料摘要、观测／失效时间、币种、计费单位、价格与独立输入 Token 上界。默认无报价，不能外呼；服务端为每次精确部署／输入建立绑定，不允许浏览器填写费率或沿用其他连接报价。这里不把配置格式合法当作价格真实性，真实执行材料仍单独接受。

固定三样本整轮预算通过后、首次实际发送前，在独立短事务记录尝试与预留；同一部署修订的活动尝试互斥。网络不持有业务事务。终态只保存目标／计划／输入／价格／样本摘要、数量、费用上界及稳定失败类别；过期、身份失效、源轮换、并发 loser 和审计失败均不能留下 VERIFIED、目录或授权。预留是本轮上界而非账单，未知用量不自动退回。

以上验证编排已实现；本轮继续实施下述原子发布，当前已部署的 `73fc9ee0…` 入口仍失败关闭：继续使用原发布入口，短事务复核完整验证、当前已发布来源、冻结输入及活动租户，原子保存目录、供应授权与审计。供应授权不生成租户配置；现有目录／配置入口不得通过猜测目录 ID 绕过该授权，RERANK 不得落入 Embedding 默认分支。发布事务与真实厂商结果未通过前不增加 S2 操作完成数。

## 原子发布的实施细化（ADR-0095／0100，验证中）

这是已接受独立发布／授权合同的具体实现，不是新的原型候选或真实执行授权。

- POST `/deployments/{id}/publish` 保留 `expectedVersion`。操作者、当前权限及会话只来自服务端；发布只使用已验证草稿冻结的租户集合，客户端不能扩大。完整固定三样本、费用预留终态与独立验证审计缺一不可；事务末尾再次复核来源／发现和验证时效。目录、独立发布、全部授权、CAS 与审计原子提交。
- GET `/deployments/{id}/supply` 返回独立发布 ID／修订、目录 ID、时间、选择／活动／撤销授权计数、活动租户 ID、当前来源可用性及依赖配置数。部署摘要的 `supply` 复用同一投影；未知不补零，活动授权不代表来源、租户与配置全部可用。发布后的名称和数量只能来自活动关系，不能回退草稿计划。
- POST `/deployments/{id}/grants/{tenantId}/revoke` 使用非负整数 `expectedVersion`／`expectedGrantVersion`，只撤销已存在的活动关系。新授权从修订 0 开始，撤销变为 1；没有重新赋权入口。GET 部署的当前修订与上述事实供精确操作审阅；撤权、停用及影响事实保留历史和配置，不受新增写入暂停限制，不添加原型没有的管理按钮。
- `controlled-model-catalog` 旧 POST／publish 只恢复原子发布已建立且当前有效的同一目录，不再独立创建或改变发布事实；恢复返回 200。现行源码调用方为旧控制器及测试，没有保留当前页面的独立目录按钮。当前租户目录在 Page／IPage 分页与同范围总数之前筛选授权和来源；旧无租户分页禁止回退。
- 现有配置保存、启用、授权提交和新使用都复核同一供应事实，提交按来源、部署、活动租户与授权加锁。仅补 S2 必需的消费者边界；配置版本、租户发现 UI 及新启用生命周期仍归 S3／S4，不把旧 ACTIVE 字段提升为这些切片的完成证据。活动事实仍由组织所有者通过现有安全契约提供，不新增上下文 Maven 依赖或通用权限框架。
- 迁移只建立新事实、RERANK 候选上限及来源唯一约束，不给旧目录或计划集合补造授权。当前未有真实发布时可使用既有镜像回退；首次真实供应发布后，回退版本必须保留本次租户供应读取及提交边界，不能仅换回会全局读取目录的旧镜像。
