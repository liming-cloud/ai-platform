# S1 页面部分可用与禁用：触发合同提案

状态：有限辅助读取降级方向已于 2026-10-16 人工接受，登记 [ADR-0097](../../architecture/decisions/ADR-0097-platform-connection-auxiliary-read-degradation.md)；原型 `e7cd0ec22b3539033f374f4a8ca53c6b77d98ccc` 随后单独[人工接受](evidence/WP-0019-S1-prototype-acceptance-20261012.md)，[生产承接子任务已闭环](evidence/WP-0019-S1-partial-production-delivery-20261016.md)。页面 `disabled` 最小合同已于 2026-10-17 人工接受并登记 [ADR-0098](../../architecture/decisions/ADR-0098-platform-connection-write-availability.md)，[源码验证已完成](evidence/WP-0019-S1-write-availability-source-20261017.md)，生产部署与验收因 Docker 不可用尚待执行；S1 整体未完成，不替代 ADR-0095／0096／0097。

调查基线为 `9fd7601a4681c45ee520d10983cb4648691055b7`，验收工具修复为 `6d0f1324dff036f19d59425d65a3035d0b54ded0`。原型唯一来源为 OpenDesign Cloud 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7`，接受版本 `877a813652da2c96f960b71e29ed7a14eccb89c9`。本提案没有修改原型。

## 已确认的缺口

原型两页的 `partial` 显示“部分完成”，`disabled` 显示“暂不可用”；两者禁用新增／探测等主写操作，仍允许搜索、分页、查看和返回。它们来自原型评审状态，不是接口响应。页面禁用时，原型仍可展示一个“已发布”的连接，说明页面可操作性与对象生命周期是两件事。

调查时的读取合同提供连接 `DRAFT / VERIFIED / DISABLED`、探测事实、独立发布及发现结果，没有页面部分可用或全目录暂停事实。`DISABLED` 只证明这一连接已停用，不能推断整个目录或其他连接不可用。待管理员确认候选、验证到期、缺少 AK/SK、搜索无结果也不能替代页面 `partial`。原先两页必要读取失败会清除投影；现行有限降级仅适用下表已接受条件。

## 方案比较与建议

| 方案 | 行为与代价 | 判断 |
| --- | --- | --- |
| 以 URL、固定夹具或当前页全部停用推导页面状态 | 没有真实权限／全目录事实；分页、筛选和真实数据会被误判 | 拒绝 |
| 沿用调查时合同 | 单连接停用禁止探测与发布；读取故障失败关闭；页面级七态仍有缺口 | 调查基线，不冒称完整七态通过 |
| 有限读取降级 | 只在主读取成功、辅助读取发生网络／5xx 故障时展示已确认事实，禁用全部写操作 | 已接受并承接生产；原型、源码及最新部署分别验证 |
| 新增全局模型治理暂停开关 | 要求新的业务所有者、写入／恢复入口和服务端强制执行；不是一个前端样式修复 | 不纳入本次 S1 验收修复 |

下表的有限降级方向已接受；目录 `disabled` 继续明确为缺少合法触发，不能据此判定 S1 已完成。不为凑齐七态新增通用可操作性字段或管理开关。

## 已接受的最小降级规则

| 页面／状态 | 建议触发 | 必须保持的边界 |
| --- | --- | --- |
| 目录 `partial` | 当前同一请求所有者的连接列表和预设均成功，只有发布摘要发生网络或 5xx 故障 | 不猜发布计数；不把故障记为 0；禁用新增；搜索／分页保持只读 |
| 详情 `partial` | 当前同一连接修订及预设成功，只有候选或独立发布读取发生网络或 5xx 故障 | 只展示本轮已确认事实；不沿用旧候选／发布事实；不将未取得结果展示为“空”；禁用探测和发布；返回仍可用 |
| 详情对象 `DISABLED` | 正式接口返回当前连接已停用 | 保留“已停用”对象事实；禁止探测／发布，不自动映射为全页“暂不可用” |
| 两页 `disabled` | 尚无已接受的页面暂停事实 | 保留验收缺口，另行确定业务触发；不从对象状态、客户端参数或 HTTP 写入失败推导 |

401／会话失效、任一 403、精确资源 404、修订不一致、非法响应及主读取失败不进入降级。401／403 继续清除受保护内容；404 与错误分类保持现行精确规则。所有迟到响应、身份替换和搜索／分页请求所有者检查继续有效。新一次只读请求全部成功才能恢复原写操作，浏览器刷新不能绕过服务端权限或生命周期校验。

未取得的计数、候选及发布事实已由原项目 e7cd0ec2 候选补齐并单独接受后承接生产。后续如需新增正文或交互，仍须先在原项目形成可审阅候选并按 ADR-0079 接受，不能先修改生产再补造原型依据。

## 决定与验收入口

用户已接受上述有限降级方向及独立原型候选，页面 `disabled` 不在本次接受范围。决定依据及验收边界以 ADR-0097 为准；本文件保留原调查和方案比较，功能完成依据为单独生产证据。

测试必须区分网络／5xx 降级与 401／403／404 拒绝，覆盖并发读取、修订替换、身份失效、恢复和零写入；原型与最新部署分别覆盖两页、390／1024／1440、实际 200% 原生文字、键盘和 reduced-motion。真实停用对象及受控响应验收分别标注，不停用既有生产连接来制造条件。未筛选真实空目录和新方舟真实认证合同仍是独立缺口。

## 页面 disabled：独立提案（已接受）

本节调查固定于 `46e37094955df0aa1c1bf68bd4143bd284954d6b`，不重开已经闭环的 partial。产品目标仍是 S1 五项连接操作及已接受原型，两页页面禁用必须来自正式事实，不能只为七态截图制造开关。

### 已查明的实际边界

- `PlatformProviderConnectionService.requirePermission` 对创建、列表、摘要、预设、详情及探测使用同一个 `MODEL_PLATFORM_WRITE`。权限撤销应为 403／会话失效，不能凭空建立只读角色。
- `PlatformProviderConnectionController` 公开创建、列表、摘要、预设、详情和 probe；独立发现及发布也绑定当前连接修订。当前读取投影没有页面写入暂停字段；部署配置没有已声明的连接只读模式。
- 连接 DISABLED 是单对象事实。全目录、当前页或当前筛选结果全部停用，都不意味着禁止另建连接；不能据此禁用整个目录。
- 原型 `renderPlatformModelConnections`／`renderPlatformModelConnectionDetail` 的禁用来自评审态。目录仍能显示已发布连接，详情仍需保留原始对象事实；模型部署的 HEALTHY／DEGRADED／UNAVAILABLE 是 S2／S5 对象投影，不是 S1 页面事实。
- 当前实际前端仍为 `fac826e3aee42e1614a89fb840f5f13af4b30c9b`、三后端仍为 `7906451e3f2e04a03e098e601b37425e29857cb5`，七服务健康。已有 0600 登录来源可复用；登录和原项目连接不是本轮阻断。

### 比较与建议

| 方案 | 实际代价与限制 | 结论 |
| --- | --- | --- |
| 将单对象停用、过期、缺凭据、403 或网络错误转成全页 disabled | 事实不成立，混淆权限、生命周期和可用性，违反 ADR-0097 | 拒绝 |
| 为 S1 连接命令增加部署控制的只读模式 | 一个可信配置值、一处既有预设读取投影、所有 S1 写入口的同一强制检查；无管理页面、数据库表或动态开关 API | 推荐的最小真实触发，待接受 |
| 建立平台全局维护和运维编排 | 涉及多上下文、运行进程、暂停／恢复角色、审计和操作面板 | 属于后续运维设计，不在本轮引入 |
| 保留 disabled 为不可达评审态并直接宣布七态完成 | 无生产触发证据，不能满足当前完整还原目标 | 拒绝；不通过降低门禁收口 |

建议只新增 **S1 平台连接命令只读模式**，不暂停模型推理、租户配置或整个平台。它是显式的服务端可操作性事实，不从故障、行状态或权限推导。若人工不接受新增该能力，页面 disabled 继续保留为明确未完成项，不能重复截图后宣称通过。

### 拟冻结合同

1. 所有者为 model-runtime 的平台连接用例；建议部署配置为 `foundation.model-runtime.platform-connection-writes-enabled`，默认 `true`，由正常部署设置，非浏览器输入。本轮不新增配置编辑页或动态暂停／恢复接口。
2. 复用两页已经必读的预设响应，拟增加必需布尔字段 `writesAvailable`；现有 `version`、`items` 和厂商来源不变，不增加一次网络请求。它仅反映该配置，不宣称厂商健康、模型可调用或用户获得额外权限。
3. 读取权限、安全、响应格式和精确修订均通过，所有所需事实完整成功且 `writesAvailable=false` 时，整页显示原型“暂不可用”，关闭新增、旧表单提交、探测和发布；保留查询、分页、查看、返回。辅助读取降级仍按 ADR-0097 显示未知事实，不能因暂停模式补造完整结果。
4. 401／403、精确 404、主读取失败、畸形或缺失可操作性字段保持既有失败关闭。`writesAvailable=true` 不覆盖对象 DISABLED、缺少用途凭据、探测过期或原权限限制；恢复后必须完整重读。
5. 创建、独立发现、旧 probe 和发布的正式服务端入口均先授权，再检查同一配置，随后才允许秘密解析、外呼或持久化。客户端缓存旧 `true` 也不能绕过；建议以新稳定 CONFLICT 错误拒绝暂停期间的写请求，具体错误编号在接受后的 ADR／首个失败测试中冻结。
6. 配置在应用实例启动时固定，不承诺热切换或中止已经受理的外呼。正常更新只约束新实例接受的新命令，不回滚旧业务事实。实现前核对实际命令扇出，禁止只禁用按钮或漏掉已有入口。
7. 不改变现有连接／发布／发现历史，不停用生产连接，不创建模型部署或租户授权。暂停验收使用隔离服务合同与受控 HTTP 反例；是否临时切换当前部署做真实暂停／恢复验收，需在可审阅的部署步骤中明确范围后按已有授权核对。

本提案会增补公共读取和命令失败语义，必须人工接受后登记新 ADR，再开始实现；届时明确替代 ADR-0097 关于“暂无页面暂停事实”的范围，历史记录不改写。当前生产继续执行已接受合同。

### 接受后的完整退出条件

- 正反例证明默认可写、显式暂停、完整重读恢复、无权／非法投影、对象停用及验证过期分别处理；暂停期间全部正式 S1 命令均在秘密读取／外呼／写库之前拒绝。
- 两页使用真实服务端字段触发，生产 URL 无模拟参数；旧表单和迟到响应不能恢复写入口，旧客户端仍由服务端拒绝。
- 三尺寸、实际 200%、键盘和 reduced-motion 对照已接受原型的 disabled；源码、隔离合同、实际部署和受控响应分别结论。不复制原型模拟身份或业务状态。
- 更新当前恢复入口、执行所属验证及项目门禁，中文精确路径提交、推送并核对精确 CI；通过只关闭此子任务，不提升 S1、WP-0019 或 M6 完成状态。
