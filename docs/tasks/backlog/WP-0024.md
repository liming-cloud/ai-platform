## 问题

原 WP-0019 普通问答计划迁入本包，映射以 ADR-0079 为准。会员需要自己的登录、授权助手、持久化会话和真实流式问答，不能以管理员会话、一次性问答或同步结果的 SSE 回放代替。

## 本工作包唯一结果

用 WP-0018 的真实验收会员，完成授权登录、助手选择、流式问答、引用、历史切换与续问、取消及断线恢复的纵向闭环。

## 原型承接

3 个 screen：`login`、`assistants`、`conversation`。生产入口为 `/app/login`、`/app/assistants`、`/app/conversations/:conversationId`；会话页左侧历史、顶部助手信息、中央消息流，消息不增加第二套页码分页。

## 范围内

- `QUERY_APP` 访问渠道复用浏览器会话机制，服务端确认 `QUERY_USE`、成员状态和至少一个已授权发布助手；无授权时不能进入查询应用。
- 会话创建固定已发布 `AssistantVersion`；新发布不迁移已有会话，提示可新建会话；保留旧会话所需索引与来源版本。
- 普通会员只能访问本人会话；每次正文、引用、历史恢复和持续输出重新检查当前权限，撤权立即失败关闭。
- 提交轮次带 `clientRequestId`，快速返回 `202` 与 QueryRun；同一会话同时最多一个运行中轮次，同 ID 同载荷返回原运行，冲突载荷拒绝。
- 复用 WP-0021 共用流式执行与 WP-0022 检索；真实持久化 `RUN_ACCEPTED`、`RETRIEVAL_COMPLETED`、`TOKEN_DELTA`、`CITATIONS_FINALIZED`、`COMPLETED`、`REFUSED`、`FAILED`。
- token 每 100 ms 或 256 字符合并持久化；最终答案、引用和终态原子提交，事件序号在单个 QueryRun 内单调递增。
- 完成取消、失败、重试、`Last-Event-ID` 续传和迟到回调防护；部分输出不标为完整答案，输出后不能暗中更换模型重新回答。
- 完整历史持久化仅用于会员查看与恢复；检索上下文最多最近 6 个已完成轮次且不超过 3,000 tokens，用于独立问题改写，超出部分使用版本化、可重建摘要。
- 相同问题以冻结版本、`temperature=0`、供应商支持时固定 seed 和确定性检索/重排追求事实稳定，不承诺逐字一致。

## 范围外

- 前置 WP-0023 已提交并发布助手、分配会员授权；使用 WP-0017 的登录策略、WP-0018 的账户/权限及 WP-0021/0022 的真实执行。
- 不新增 v2 API，不建第二套查询流水线、独立记忆库、用户长期记忆、多知识库助手或最终答案缓存。
- 管理员只能看脱敏治理指标，不能读取会员问答正文；治理页面由 WP-0025 承接。
- 不复制原型演示密码修复、审查器、定时模拟 token 或本地夹具状态。

## 公共接口与数据

实现前接受会话、轮次、取消、事件留存与内容保护、背压、摘要和授权撤销专属 ADR；更新 M1 不持久化 token 的限制，不扩大管理员正文权限。

| 接口 | 行为 |
| --- | --- |
| `POST /api/v1/conversations` | 创建会话并固定授权助手版本 |
| `GET /api/v1/conversations?page=&size=` | 本人会话目录，页码、页大小与总数 |
| `GET /api/v1/conversations/{id}/messages?beforeSequence=&limit=` | 事件序号读取历史窗口 |
| `POST /api/v1/conversations/{id}/turns` | 幂等提交问题，快速返回 `202` 与 QueryRun |
| 现有 QueryRun 事件端点 | 真实 SSE 与 `Last-Event-ID` 恢复，不平行另建 API |

原始消息、模型上下文、摘要与脱敏运行事实分开；缓存键包含 tenant、member、grant fingerprint、assistant/index version。固定历史版本不能冻结权限或扩大证据范围。

## 约束

- 模型调用在服务端真实异步执行，HTTP 接受不能等待最终答案；最终事件原子性、幂等和计量一致性不可依赖前端。
- 模型和文档指令是不可信数据，历史及摘要不能制造授权或未经确认的长期事实。
- 密码不进入 Git、日志、截图和报告；真实验收会员使用独立浏览器会话，不通过管理员状态冒充。
- 控件、分页、文字、三档尺寸、中文状态和 reduced-motion 遵循 ADR-0079，保留现有管理端路由。

## 验收标准

- 真实会员从密码登录、授权助手搜索、会话创建到实际 token、引用、历史切换、续问均可用，刷新恢复服务端事实。
- 首个增量必须早于完整生成结束；幂等并发、重复连接、旧 Last-Event-ID、取消、超时、部分失败和迟到回调只形成正确唯一终态。
- 撤销助手、关闭会员对话功能、停用账户和变更登录策略后，运行中输出、引用、历史及重连立即拒绝；跨租户/他人会话不泄漏资源存在性。
- 新助手发布后旧会话仍固定原版本；10,000 条事件下有界加载，不无限堆积 DOM。
- 用户端首 token p95 < 4 s，记录真实浏览器与供应商环境；同题 5 次无事实矛盾或无依据引用，不能用执行层指标替代浏览器结果。
- 三角色路由无回归；390/1024/1440、200% 文字放大、键盘、reduced-motion 及适用七态通过。
