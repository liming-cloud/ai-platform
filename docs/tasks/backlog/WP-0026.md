## 问题

原 WP-0020 质量计划迁入本包，映射以 ADR-0079 为准。原型验收、页面数量、代码存在和局部测试不能证明生产产品安全、准确、易用且可恢复。

## 本工作包唯一结果

对 66 个 M6 入口和跨包旅程执行冻结质量、安全、性能、生产浏览器、Compose 与备份恢复门禁，形成证据并交回 WP-0014 人工复评。

## 原型承接

覆盖 WP-0017～0025 的 66 个 M6 screen 及每项生产操作，不增加独立业务页面。操作台账必须完整分类为生产实现、原型专用、暂缓或禁止；M7 的 4 页、M8 的 6 页及暂缓占位不冒充 M6 待完成业务。

## 范围内

- 每知识库至少 100 题：60 可回答、20 应拒答、10 越权/无授权/撤权、10 多轮指代；保存期望证据块、来源修订、原文位置、内容哈希和索引映射。
- 真实运行 RAG 评测，冻结模型、索引、分块、分词、rerank、阈值和指标版本；任何版本变化必须重测。
- 测试 ANN、FTS、rerank、引用、缓存、历史和 SSE 各层授权；跨租户、成员越权、撤权及管理员正文不可见。
- 测试提示注入、内容投毒、恶意 PDF/Office、压缩炸弹、OCR 超时、摘要和会话/缓存污染。
- 验证首增量、重连、取消、幂等、迟到回调与终态事务；同题重复 5 次无事实矛盾或无依据引用，不要求逐字一致。
- 独立平台、租户管理员和真实普通会员浏览器会话，从空环境走完整旅程，密码不进入 Git、日志、截图或报告。
- 覆盖 390/1024/1440、200% 文字放大、键盘、reduced-motion 与七态；压力覆盖 1,000 文档、1,000 成员、200 助手、100 版本、10,000 记录。
- Compose 部署、健康检查、数据库/对象存储一致备份、隔离恢复、会话失效及重入验证，形成真实运行手册。

## 范围外

- 前置 WP-0025 已提交，WP-0017～0025 的生产操作已完成；业务缺口回原责任包，不在本包新增功能或补造审计。
- 不新增业务 API、领域模型、管理页面、M7/M8、邮件邀请、渠道绑定或设备凭据。
- 不以人工浏览代替自动安全/质量，不以演示模型或脚本单测代替真实供应商，不降低门禁换发布日期。
- 本包完成仅表示自动证据可供评审；M6 人工接受由 WP-0014 登记，不自行宣布 M6 批准。

## 公共接口与数据

只完善验收入口、隔离夹具、质量快照、报告与发布证据。接口行为需要变化时，先回责任包接受契约并重验上下游。

测试正文保持私有，报告仅保留最小目标版本、计数、指标、失败分类、环境和提交。会员使用合成身份和独立会话，不赋予管理权限。

## 约束

| 门禁 | 要求 |
| --- | --- |
| 跨租户及越权泄漏 | 0 |
| Recall@10 | ≥ 0.85 |
| 引用正确率 | ≥ 0.95 |
| 拒答准确率 | ≥ 0.98 |
| 结构化查询内部 p95 | < 500 ms |
| 完整混合检索 p95 | < 800 ms |
| 供应商健康时用户端首 token p95 | < 4 s |
| 同题 5 次 | 无事实矛盾、无无依据引用 |

- 固定硬件、模型、维度、规模、并发和冷暖状态；浏览器首 token 不用执行层或直接供应商耗时代替。
- 仅准确识别的开发基座数据允许备份后重建；先列数据库、对象存储与卷并验证隔离恢复。不触碰原型、密钥、用户文件或其他项目，不宽泛清卷。
- 截图仅临时检查，不入库；OpenDesign 保持设计事实源，不改变管理路由、权限、独立保存和目录分页。
- 缺 Docker、模型配置、worker 或冻结集为阻塞，不得静默跳过或用缓存报告通过。

## 验收标准

- 冻结指标、负向测试及原始计数可复现；质量、安全、性能或可访问性任一硬门禁失败阻断 M6。
- 空环境完整旅程：平台开户及租户管理员创建 → 模型配置 → 知识接入 → 评测和索引激活 → 助手发布 → 真实会员授权 → 会员流式问答、引用、历史续问 → 撤权后立即拒绝。
- 关闭会员对话、停用账户、修改登录策略后的会话失效和历史/引用/SSE 拒绝全部通过；三角色不能相互代替验收。
- 全量页面控件对齐误差 ≤ 1px，触控、长数据与文字放大无裁切、遮挡或新增横向溢出。
- 全新 Compose 按手册部署，一致备份可隔离恢复；恢复后旧会话不能绕过认证。
- 操作台账无遗漏，证据绑定提交；交付 WP-0014 的材料明确通过项、真实限制和风险。
