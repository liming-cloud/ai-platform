# M6 OpenAI 风格企业产品 UI 设计简报

## 产品目标

管理控制台参考 OpenAI Platform／Developers 的克制、中性和高信息密度；可信问答参考 ChatGPT 的单一阅读流与固定输入区。参考的是信息层级和交互语言，不复制 OpenAI 商标、字体或专有资产。

## 视觉合同

- 继续只使用 Fluent UI React v9 和系统无衬线字体。
- 白色画布、浅灰次级表面、近黑主文本与主操作；语义颜色只表示真实状态。
- 页面标题 `28/36`、区块标题 `20/28`、正文 `14/20`、辅助文字 `12/16`。
- 间距固定为 `4/8/12/16/24/32/48`；控件圆角 8px，面板与 Dialog 圆角 12px。
- 管理壳使用 56px 顶栏、232px 侧栏和 1440px 最大内容宽度；问答壳使用 52px 图标栏、768px 对话列和固定输入区。
- 禁止渐变、玻璃拟态、超大营销标题、装饰性卡片堆、大面积品牌色背景和脱离账户菜单的退出按钮。

## 角色信息架构

- 平台管理员：运营总览、租户、平台账户、平台模型。
- 租户管理员：运营总览、成员、数据、模型、助手与评测、可信问答。
- 普通用户：可信问答。

无权入口从界面移除，直接路由仍由服务端授权。

## 状态与文案

- 加载使用匹配最终布局的骨架。
- 空状态说明当前事实和唯一下一步，不伪造演示数据。
- 错误只显示任务、影响与恢复动作，不显示后端 `message`、错误码、`traceId`、异常或内部地址。
- 成功提示使用资源名称和业务结果，不显示内部标识、修订或结果编码。
- 页面中所有资源关系都通过名称选择器建立；用户不输入内部 ID。

## 基准页面

首个视觉基准为平台运营总览：紧凑指标行、七天查询趋势、状态分布、租户注意事项分页表格和明确刷新时间。必须在 1440×900、1024×768、390×844、200% 缩放、键盘和减少动态效果条件下完成三轮对比。
