# 产品与前端设计基线

状态：已接受。依据：章程，ADR-0059、0067、0073、0074、0078、0079、0080。负责人：产品、前端、安全。该文档描述接受设计，不声明全部实现。

## 用户与任务

产品只保留平台管理员、租户管理员、普通会员。平台拥有租户及管理员生命周期、模型供应和租户功能上限；租户管理员治理普通会员、知识、模型使用、评测与助手；普通会员只使用获授权助手及本人对话、历史和引用。活动平台资格与启用租户成员资格互斥，平台不能读取租户正文。导航能力不代替服务端授权。

核心链为知识接入与质量 → 候选索引 → 评测与授权激活 → 助手版本发布 → 成员授权 → 可信问答及撤权复验。M6 包顺序与责任以任务矩阵为准；渠道绑定、设备凭据、邮件邀请暂缓，M7/M8 不提前实现。

## 交互与数据权威

唯一 React/Fluent SPA。路由、筛选、页码支持刷新及前后退。普通列表默认每页20，选项10/20/50/100，服务端返回总数；事件、候选与内部批次沿用各自协议。写后读取服务器事实，不以 localStorage 合成状态代替持久化。

一页一个主任务、一个主要保存边界。简单编辑使用受控弹层，跨步骤流程独立路由；无嵌套弹窗，初始焦点与关闭后恢复明确。覆盖加载、空、错误、无权、禁用、部分结果和成功；无权内容不泄漏。

浏览器会话由 HttpOnly Cookie/CSRF 及范围隔离合同承接，客户端不读取或保存 Token。密码不进入草稿、URL、日志或证据。平台与租户入口分别验证，切换身份显式退出；真实会员旅程按责任包依次建立。

## 原子开户与后续设置

ADR-0080 规定三步原子创建租户和初始管理员；成功概览只展示固定原型已经交付的事实。配额保存通过正式 API/只读数据库核验，不增加原型没有的概览区。200% 文字时步骤圆圈自适应属于已有明确许可，不能扩大成其他视觉例外。

管理员管理、配额编辑、功能开关、登录策略分别冻结 ADR、保存边界和反例，不因概览页面存在提前交付。未实现入口不伪造可用按钮。

租户管理员页按 ADR-0083 以当前租户管理员资格执行停用和恢复；同一身份只能管理一个租户，新增、替换和恢复资格不得形成跨租户管理员权限。用户明确将对应按钮文案从原型的“停用账户／恢复账户”修订为“停用管理员资格／恢复管理员资格”。密码仍属于全局唯一身份，重置会撤销该主体的旧会话，页面必须说明该影响。固定原型的其余结构、控件与样式继续逐项对照，不以这项文案修订豁免其他差异。

## 验收

390/1024/1440、200% 文字、键盘、焦点、reduced-motion、刷新/返回/取消、错误恢复均验证。功能通过与原型一致性分开结论；截图仅 /private/tmp。部署验收固定前端、后端镜像及原型版本；原型模拟账户、数据、密钥和行为不得进入生产。
