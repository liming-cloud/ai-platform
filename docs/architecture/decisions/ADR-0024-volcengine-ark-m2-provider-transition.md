# ADR-0024：M2 真实模型验证切换至火山方舟

## 状态

已接受

## 日期

2026-07-28

## 决策负责人

产品负责人确认：因原研发订阅到期，M2 真实模型受控验证切换至火山方舟。

## 背景

`WP-0010` 已完成模型配置、数据库密文和受控运行时的实现，但真实调用尚未通过。继续保留原供应商的端点、模型默认值或密钥文件，会使后续研发误用已停止的计费与认证路径。

火山方舟公开文档说明其 OpenAI 兼容请求使用 HTTPS 基础地址
`https://ark.cn-beijing.volces.com/api/v3`，以方舟 API Key 鉴权；模型调用使用账户创建并授权的推理接入点。来源：[火山方舟 Responses API](https://www.volcengine.com/docs/82379/1958524)。

## 决策

1. M2 的唯一真实供应商目标为火山方舟；移除仓库当前文档、默认值、测试夹具和研发证据中的原供应商专属内容。
2. 保持 `ProviderKind.OPENAI_COMPATIBLE` 与既有 Spring AI 工厂不变。供应商差异仅保留在平台受控目录条目，不进入领域、助手、检索或公共 HTTP 契约。
3. 验收脚本默认使用方舟 OpenAI 兼容基础地址，但必须显式提供 Chat、Embedding 推理接入点 ID，以及由平台确认的上下文窗口、输出上限和嵌入维度；不得猜测模型编码或能力值。
4. API Key 只从权限为 `0600` 的本地文件读取一次，写入模型配置的数据库密文后立即清除；不得进入容器环境、命令行、日志、证据或版本控制。
5. 已存在的原供应商目录、模型配置、索引和助手版本属于历史测试数据，不在本工作包中自动删除。删除持久化数据或桌面旧密钥文件前，必须确认准确目标并获得可恢复性安排。

## 后果与验收

- 真实调用前必须在方舟控制台创建并授权一个 Chat 推理接入点与一个 Embedding 推理接入点，并由平台管理员在受控目录中冻结其能力。
- `MODEL_ALLOWED_ENDPOINTS` 与模型目录端点必须一致，且继续经 ADR-0010 的 HTTPS 公网出站策略校验。
- M2 的真实调用证据必须记录脱敏摘要和稳定错误码，不能以脚本或 Mock 通过替代真实调用。
- 切换不改变 M2→M3 的人工评审门禁。
