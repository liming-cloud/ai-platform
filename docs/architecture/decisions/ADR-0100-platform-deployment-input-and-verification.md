## 决定

1. 保留 S2 两页、四项责任操作与草稿保存边界。在已发现模型的所属选择区补齐未知候选的显式类型／能力确认，以及当前类型必需的上下文、输出、向量维度或重排候选上限。已知事实与管理员声明分别保存来源和修订，不从名称、地址或首个选项猜测。管理员确认不替代真实能力验证；官方文档最大值不标为实测最大值。确认与参数的具体交互先形成原项目候选，人工接受后才承接生产。
2. “预算与安全样本”首版表示本次验证的预授权请求数、输入／输出限制、总超时及版本化合成安全样本。真实 Chat、Embedding、RERANK 各证明自己的协议与边界；没有对应真实合同的能力不能可用。费用依据缺失时不得宣称月度费用核验或全平台硬扣费。具体厂商、模型、次数及费用上限在执行材料可审阅后单独授权；不沿用 S1 只读发现或精确连接发布授权。
3. S2 主列表和精确详情失败关闭。仅已定义的辅助摘要网络／5xx 故障可进入 partial，缺失事实保持未知并禁止创建、能力验证、发布及授权扩大。401 清会话；403 拒绝；精确 404、畸形响应、修订不一致与迟到安全拒绝不能降级或恢复旧数据。辅助事实与重读恢复须在原型候选中明确表达，不能复制完整演示事实。
4. S2 页面 disabled 由自己独立、实例启动时固定的写入可用性事实触发，默认开启；不增加动态管理页面或通用权限框架。该事实只暂停本片创建、能力验证、部署发布及授权扩大，读取和安全撤权／停用继续有效；权限优先于可用性。不能复用 ADR-0098 仅管 S1 的开关，也不能用 URL、单条 DISABLED 或网络错误假造页面状态。具体安全投影字段及装配配置在所属源码子任务开始前固定样例。
5. 草稿租户集合只记录选择，不提供可用供应。独立发布原子冻结当前连接／候选／能力／驻留及授权集合，之后只允许仍有效且被选中的租户新使用；撤权／停用不删除历史或改写租户配置。该项承接 ADR-0095，不新增自动赋权语义。
