# ADR-0089：租户概览的真实事实与只读设置导航

## 状态

已接受。2026-10-01。依据用户继续按 OpenDesign 逐切片交付并闭环推送的授权，以及 ADR-0041、ADR-0048、ADR-0079、ADR-0080、ADR-0083～0088。原型来源为项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7`，业务页面固定于 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`，共享移动布局采用已接受修订 `47c4f6f31823617633ce0bac98074208781f5565`。本决策冻结已有读取与导航的验收范围，不增加权限、API 或持久化结构。

## 问题

原子开户已交付真实概览和租户登录入口；五项独立设置也已分别闭合，但 `platform-tenant-detail:0` 尚无独立合同和部署验收。代码图谱确认概览已有受限读取、异步结果归属和五页导航；不能为补齐矩阵另建一套概览数据或模拟保存。只读对照发现安全保障正文被写成段落，标题字重、行高及租户编码字体尚未完全承接原型。

## 决定

1. `/platform/tenants/{tenantId}` 是平台治理的只读租户概览。目标标识只选择资源；身份、能力和后端权限仍由已验证的平台会话恢复。匿名、租户会话及失效会话不得读取或显示平台租户事实，不能以路由或导航代替授权。
2. 复用 `GET /api/v1/platform/tenants/{tenantId}` 和限量的管理员分页读取，展示真实名称、编码、生命周期状态和管理员摘要。只有一个管理员时显示登录名，多个时显示总数；没有管理员时显示真实空结果，不编造“已分配”。不显示内部标识、角色代码、凭据或其他租户成员。继续执行 ADR-0080 的既定边界：不复制演示驻留区域，也不在概览读取或展示额外配额。
3. 概览、管理员、资源配额、可用功能和登录安全五个入口均进入已有独立路由，保持同一目标租户；概览为当前项。刷新及浏览器前后退恢复目标与当前页。返回目录只导航；本片不重判尚未完成的租户目录／生命周期切片。每项设置的保存与权限仍由各自 ADR 决定，概览不预先保存、改变状态或自动分配身份。
4. 安全保障沿用原型的分区说明、真实标题和三项不可关闭底线。生产的字体、控件、间距、分栏、移动换行和共享布局按固定原型验收，不新增视觉例外。真实名称、管理员数量及合法生命周期状态按服务端事实显示；`SUSPENDED` 继续称“已暂停”，不复制模拟账户的“已停用”语义。
5. 加载、请求失败、资源不存在、权限拒绝和会话失效必须由真实读取结果驱动，失败不显示上次目标的事实，重试重读服务器。只读页面没有可编辑草稿、部分保存或提交禁用状态，不为原型状态开关增加虚假业务数据。既有登录入口按 ADR-0080 仅导航，不暗中切换平台身份。

## 验证与边界

先在实际旧部署上用标题语义及原型字体断言证明差异，再局部修复；已有目标切换、取消后的迟到结果和会话失效测试继续回归。`SLICE=overview` 使用已有隔离租户，不创建、删除或更改业务对象，覆盖真实事实、五页导航、刷新／历史、失败恢复、角色隔离、退出、三尺寸、200% 文字、键盘和 reduced-motion，并记录业务写请求为零。登录回归、精确对象的只读数据库事实和 OpenDesign 对照分别提供证据。截图只存 `/private/tmp`。
