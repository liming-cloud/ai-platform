# ADR-0097：S1 平台连接辅助读取有限降级

## 状态

已接受。用户于 2026-10-16 回复“接受该方向（推荐）”，接受 [S1 页面触发提案](../../tasks/WP-0019/page-state-proposal.md)的有限辅助读取降级方向。可评审提案提交为 `5216bd2922ecd4dc8c6f5b07e7cc6f62f65e9a7d`，接受前正文 SHA-256 为 `81ade4228d5afa920b2c07702c432a25b5591e16ed1b6d35fd2aac36e87f5751`。实施调查基线为 `f3b25b511e195b646fa53d9427f1731d6bc8a8ac`；责任任务为 WP-0019 / S1。

本决定只接受读取失败语义，不接受新的原型候选，不证明实现、部署、S1、WP-0019 或 M6 完成。

## 问题与选择

当前两页将全部必要和辅助读取作为整体成功条件；原型的 `partial` 只显示“部分完成”并禁用主写操作，正文仍有完整演示事实。现有对象 `DISABLED` 不能证明整个页面暂停。选择有界的辅助读取降级，保留主读取、安全和修订错误的失败关闭；不新增全局暂停开关、通用权限框架或生产模拟参数。

## 决定

1. 目录的连接列表和厂商预设是主读取；独立发布摘要是唯一可降级的辅助读取。主读取在当前请求所有者下全部成功，且仅摘要发生网络或 HTTP 5xx 故障时，页面进入 `partial`。显示本轮确认的连接列表，发布总数保持未知，不能使用 0、当前页计数或旧摘要补齐。
2. 详情的精确连接及厂商预设是主读取；该修订的候选与独立发布是可降级的辅助读取。主读取全部成功，且辅助读取仅发生网络或 HTTP 5xx 故障时，进入 `partial`。各辅助读取独立保留本轮成功事实；失败部分显示尚未取得，不显示空列表、未发布或旧版本事实。候选搜索所需的总数读取同属候选辅助事实，失败时不得猜测全目录数量。
3. `partial` 禁止新增、探测、发布及已打开表单提交；保留只读搜索、有效分页、查看、返回和重新载入。只有新的读取在当前身份、请求及连接修订下完整成功，才能按原权限、凭据和验证时效恢复写操作。缺失或过期验证不能因恢复而有效。
4. 主读取失败、任一 HTTP 401／403／404、非法或畸形响应、修订不一致均不得进入 `partial`。HTTP 401／403 按原始状态识别，不依赖错误正文能否解析；会话失效、拒绝与精确资源不存在沿用当前分类并清除受保护投影。并发辅助故障不能掩盖迟到的安全拒绝；旧请求、身份替换及退出后的结果不能恢复旧事实。
5. 连接 `DISABLED` 保留“已停用”对象事实并禁止探测／发布，不自动成为页面 `disabled`。两页的页面级 `disabled` 暂无合法触发，继续登记验收缺口，不从 URL、当前页行状态或 HTTP 写入错误创造开关。
6. API、后端权限、生命周期、审计、厂商外呼及持久化结构不变。ADR-0010、0023、0060、0066、0070、0095 和0096 的秘密、范围、验证及发布事实边界全部继续有效；前端可用性不是服务端写授权。
