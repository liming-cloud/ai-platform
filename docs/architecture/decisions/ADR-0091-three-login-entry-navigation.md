# ADR-0091：三类登录入口导航

## 状态

已接受。2026-10-01。依据用户明确选择“保持 M6 范围，先完成登录入口切换”，以及 ADR-0048、ADR-0067、ADR-0078、ADR-0079。用户同时要求保持已验收 OpenDesign，不修改原型；此前目录修订的授权不能扩展至本切片。

## 问题

生产管理登录页仅连接另一个管理员入口，缺少已验收原型中的普通用户问答入口。平台概览的首个阻断项及三类风险记录依赖 M8 页面与事实源；本次不扩大到这些依赖，不用演示数据伪造概览完成。

## 决定

1. 关闭 WP-0017 的 `tenant-login:1` 导航切片。原型 `console-login`、`tenant-login`、`login` 分别承接现有 `/login`、`/tenant/login`、`/ask`；不新增会话资源或第二个问答入口。
2. 匿名入口的“其他登录入口”按原型固定顺序展示另外两个链接：平台管理登录、租户管理员登录、普通用户问答登录；当前入口不重复展示。使用原生链接，支持键盘、刷新、前后退和直接访问。
3. 导航只选择入口，清除离开页面的密码输入，不带入 URL、浏览器存储或下一页。已有会话不得因链接访问自动登出、替换、增权。两个管理员入口继续同时检查服务端角色与工作区；问答入口沿用既有租户工作区能力和固定回跳规则，不将租户管理员既有问答权限收紧为成员专用。
4. 本次只承接三入口链接、相对顺序、主题、尺寸及响应式；问答页完整布局、普通成员建立与登录业务仍由 WP-0018、WP-0024 负责。该边界符合 ADR-0083 中用户接受的未实现功能延期，不把本次导航通过登记为 `login:0` 或完整普通成员登录通过。
5. OpenDesign 原项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7` 保持不变。入口及操作固定版本 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`；共享移动布局沿用 `47c4f6f31823617633ce0bac98074208781f5565`。只读取得当前正式预览地址并核对原文件；第三方预览容器注入基址引发的 404 不构成修改原型或复制项目的理由。

## 验证与边界

先用最小失败测试证明缺失问答入口，再验证三入口链接、当前入口排除、完整切换、密码不继承、回退／刷新、真实会话身份保留、错角色入口和键盘。实际前端 Compose 部署后执行独立 `SLICE=login-entries` 与既有 `SLICE=login` 回归；业务写入为零，数据库只读复核。390/1024/1440、200% 文字与 reduced-motion 对照原项目导航，不新增视觉例外。源码提交、实际镜像、原型固定版本和执行证据分别绑定后才标记 `tenant-login:1` 通过；WP-0017、M6、平台概览及既有分页守卫退出条件保持未完成。
