# ADR-0083：租户管理员设置页的资格与凭据边界

## 状态

已接受。

## 日期与依据

2026-09-23。平台管理员独占租户管理员治理依据 ADR-0073；统一身份与密码、会话撤销依据 ADR-0012、0048、0078；页面结构依据 WP-0016 已验收的 OpenDesign 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7`、固定提交 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`。用户本轮先确认停用只作用于当前租户管理员资格，随后进一步确定同一身份只能管理一个租户，禁止跨租户管理员资格；页面文案改为“停用管理员资格”。后续决定替代此前的跨租户管理员场景。

## 问题

已验收原型的管理员页以“停用账户／恢复账户”描述行操作，模拟状态修改的是全局账户；现有生产接口修改的却是目标租户成员资格。直接复用原型文案会误导操作者，把资格变更误认为全局账户变更。密码属于全局唯一 `SubjectIdentity`，不能在每个租户复制一份或伪装成租户范围密码。

## 决策

1. `platform-tenant-admins` 是独立页面，URL 为 `/platform/tenants/{tenantId}/admins`。租户标识只选择受管资源，不决定操作者身份；后端从平台会话恢复授权。目录只展示该租户管理员，采用服务端分页、登录名搜索与状态筛选；刷新和浏览器前后退恢复筛选及页码。“最近安全变更”从身份与成员的实际更新时间投影；没有后续变更时显示原型的“初始凭据已设置”，不编造历史操作。概览和管理员页使用已验收的标题、信息层级、暖色主题、表格与导航样式；其余设置页未交付前不提供假入口。
2. 同一全局身份至多持有一个租户的管理员资格，停用资格仍占用原租户；分配、替换及恢复时在主体锁内校验，数据库唯一约束防止并发绕过，候选目录不展示已任其他租户管理员的身份。历史重复资格使迁移失败，不自动删除或改写。拒绝使用稳定冲突码 `ORGANIZATION_ACCESS.CONFLICT.0004`。
3. “停用管理员资格／恢复管理员资格”只更改目标租户的管理员成员资格，使用成员资格引用与预期版本；不改变全局账户状态。最后一位启用管理员不得停用。变更后撤销该主体的旧租户会话族；会话撤销失败则事务回滚。确认框说明影响、恢复与审计范围。此条只对上述原型账户文案作用户明确要求的修订，不将差异扩展到页面布局和其他控件。
4. “重置密码”作用于全局唯一身份，不能改变成员资格或重新启用停用的身份。平台管理员只能在目标确为当前租户管理员时经本租户的受限入口发起；目标身份由服务端根据成员资格定位，不接受调用方另传主体标识。使用现有强哈希端口和全范围会话撤销，在同一事务中提交；失败回滚。重置表单须两次输入一致，并明确提示该身份的旧会话都会失效；密码、摘要与会话值不出现在响应、日志、审计或证据。既有 `/platform/accounts/{subjectId}/password-reset` 只治理平台管理员账户，不得以可猜测主体标识绕过租户管理员页的目标资格校验。
5. 管理员目录和重置接口不得泄露全局主体标识、密码摘要、其他租户角色或成员详情。无权、错租户、错成员、并发旧版本、最后管理员、失效会话及 CSRF 均失败关闭；写后重读服务器事实。账户全局停用仍归平台账户治理，不由本页提供。
6. 本片只交付管理员独立页及其两项操作。资源配额编辑、功能开关、登录安全、平台账户目录和普通会员分别按后续独立契约交付；本片通过不表示 WP-0017 整包或 M6 完成。

## 验证

先以失败测试证明：同一主体不能在两个租户取得管理员资格，即使一个资格已停用也不能绕过；原平台账户重置路径不能借主体标识重置租户管理员；本租户受限重置可撤销全部旧会话且失败回滚。再验证真实 PostgreSQL/Redis、HTTP 角色与 CSRF、生产浏览器的分页筛选、状态及重置流程。按固定原型检查 390/1024/1440、200% 文字、键盘、焦点和 reduced-motion；截图只在 `/private/tmp`。记录实际运行前后端提交和镜像，不能以源码测试或原型浏览器结果替代部署验收。

## 2026-09-24 原型验收范围补充

状态：已接受。用户明确允许两项限定处理；固定 OpenDesign 提交和已有验收证据均不修改。

1. 固定原型重置弹窗的“演示密码说明”只服务模拟身份。生产页可以在相同的默认折叠位置使用“密码安全说明”及真实身份语义；不显示公开演示口令，不放宽密码、会话撤销或秘密保护要求。这一例外只覆盖演示说明及由真实凭据语义必需的文案，不豁免其他已实现控件的结构、交互和响应式验收。
2. 固定原型中属于尚未实现功能的入口和页面，在对应功能切片交付时再做原型一致性验收。本片不为 M8 的“平台运行状态”“备份与恢复”或 WP-0017 后续设置功能添加无真实目标的入口；这些缺席不单独阻断管理员独立页验收，也不表示它们已实现或通过。
3. 本补充不处理固定原型 390px 下“更多”与分页重叠的可操作性差异，也不自动豁免弹窗剩余尺寸差异。管理员切片仍须按实际运行镜像、固定原型和本片全部功能证据独立收口；WP-0017 整包与 M6 保持进行中。
