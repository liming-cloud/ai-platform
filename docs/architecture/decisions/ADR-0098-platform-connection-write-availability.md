# ADR-0098：S1 平台连接写入可用性与表单说明边界

## 状态

已接受。用户于 2026-10-17 明确回复“接受 disabled 最小触发提案、三处原型专用说明的生产表达，以及原型错误色候选 cce686e4”，并要求先登记决策再实施。责任任务 WP-0019／S1；可评审提案与完整表单证据固定于 `e1e1459c8bd8f161aa477d36289c0cbcb1a89d49`。

本决定不证明实现、部署、真实厂商、S1、WP-0019 或 M6 完成，不开放 S2～S6。ADR-0010、0060、0066、0070、0095、0096 的权限、秘密和供应链边界继续有效。

## 决定

1. model-runtime 以启动配置 `foundation.model-runtime.platform-connection-writes-enabled` 控制 S1 平台连接命令，默认 `true`。配置在实例启动时固定，不提供动态 API、管理页面、数据库表或通用权限框架；不暂停推理、租户配置或其他切片。
2. 既有 `GET /api/v1/platform/model-supply/connections/presets` 增加必需布尔字段 `writesAvailable`，保留 `version`、`items` 和厂商来源。它只表示上述配置，不证明权限、厂商健康、模型可调用或探测有效，不新增网络读取。
3. 创建、独立发现、旧 probe 和独立发布均先验证可信平台权限，再检查同一不可变配置；暂停时在凭据解密、出站调用及业务持久化之前返回 HTTP 409、`MODEL_RUNTIME.CONFLICT.0011`，安全消息“平台连接写入暂不可用”。重复请求和旧客户端也必须拒绝。已经受理的旧实例请求不承诺中止或回滚。
4. 所需读取完整成功、身份／修订有效且 `writesAvailable=false` 时，两页显示原型“暂不可用”，禁用新增、旧表单提交、发现和发布；保留搜索、分页、查看和返回。辅助读取故障仍按 ADR-0097 显示 partial 和未知事实，暂停不能补造结果。401／403、精确 404、主读取失败、畸形或缺失字段继续失败关闭；生产路由没有评审模拟参数。
5. 新实例恢复配置后，前端必须完整重读，才按当前身份、连接状态、用途凭据及探测时效恢复操作。`true` 不覆盖对象 DISABLED、过期、缺凭据和权限限制。单对象停用、搜索结果、网络故障或 403 不能作为页面 disabled 的触发。
6. 此决定仅替代 ADR-0097 第 5 项“暂无页面暂停事实”的现行缺口；其余辅助读取、失败关闭和恢复规则不变，原 ADR 不改写。

此接受不扩展到其他正文、字段、保存边界、秘密合同或视觉例外。对照报告保留原始字面差异，仅单独标识这三处接受范围及可证明的自然换行影响，不放宽几何、字号或裁切断言。
