# ADR-0096：S1 目录搜索与平台连接发布摘要

## 状态

已接受。用户于 2026-10-13 明确回复“接受提案，按此继续实现（推荐）”，接受工作树中可评审的目录查询提案；提案 SHA-256 为 `a8edce80a738e3e6cca8d6377e69b3911a9491457492091fedb027af7e216e33`。责任任务：WP-0019 / S1。调查基线：`220cf68663564aef8a0d444419f3917d957a2848`。本决定增补 ADR-0095 的只读目录合同，不表示实现、生产或原型验收通过。

## 目标与来源

按 OpenDesign Cloud 原项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7`、已接受版本 `d5deddaa1955814c5f08795b0b1ca58a7e6ac784` 承接两页“搜索当前目录”和页头摘要。`prototype.js` 的目录摘要统计全目录已发布连接；`object-workspaces.js` 的搜索先筛选全部安全显示行再分页。生产不能只筛选当前页或拉取全量再切页。

当前 HTTP 列表只有页码、页大小，连接列表没有全目录发布计数。搜索字段及摘要响应尚未冻结，本记录冻结公共合同；已有 ADR-0022／0079 的分页控件与页大小承接可以独立继续。

## 决定

1. 两个现有 GET 列表增加可选 `q`：连接目录及精确连接的 `model-candidates`。省略或空白表示不筛选；去除首尾空白，最多 64 个 Unicode 码点。按单个连续词组、不区分大小写的字面包含匹配，不接受正则、SQL、通配符、任意字段或排序。`%`、`_`、反斜线按字面转义。
2. 连接搜索限于已公开的连接名称及摘要：受控厂商名称、运行协议、能力、当前显示状态。候选搜索限于当前修订中可公开的模型名称及能力摘要；分类未知继续显示待确认，不从名字推导能力。不搜索 Endpoint、业务空间、秘密引用、凭据、密文、原始厂商正文、内部审计或其他租户内容。
3. `q`、作用域、精确连接／修订和时效谓词在数据库分页之前执行；数据与总数使用相同谓词和固定排序。保留 `pageNumber`、`pageSize` 及既有 `PageResult` 字段；页码从 1 开始，默认 20、最多 100、偏移最多 100000；越界返回空页和真实总数，不静默改页。页面根据总数恢复到有效页，并把有效页码写回 URL。
4. 新增同属平台连接目录的只读 `GET /api/v1/platform/model-supply/connections/summary`，只返回 `{"publishedConnections": 非负整数}`。计数来自全目录当前连接修订的独立发布事实，排除停用及其他修订；不受当前搜索和分页影响。VERIFIED、凭据存在、历史发布或当前页计数都不能替代该事实；计数不宣称连接健康或模型可调用。
5. 两个列表和摘要均沿用可信平台会话及现有模型平台权限，不增加普通用户或租户可见性。拒绝客户端注入所有权／租户及未知参数，读取无业务写入、厂商外呼或秘密解密；错误只返回安全消息。
6. 页面 URL 保存搜索词及页大小；修改搜索词或页大小回到第一页，详情返回目录保留原查询位置。旧请求迟到、身份替换或退出不能覆盖新查询或恢复旧数据。

## 比较与选择

- 选择服务端筛选及独立摘要读取：保持有界响应、真实总数和唯一事实归属，符合既有四层及公开投影。
- 不选择当前页前端过滤：漏掉其他页，分页和总数错误。
- 不选择全量拉取后前端切页：无界读取、重复计算发布事实，无法证明服务端分页。
- 不选择通用搜索／统计框架：当前只有两类目录，无需新增模块、索引表、后台任务或缓存。

## 实施与验收边界

按本 ADR 先固定反例再实施；新索引只在真实执行计划证明必要时另行评估，本决定不增加持久化表或授予业务写入权限。触及路径的默认空实现／兼容构造器须先复现再局部清理，不批量重构其他上下文。

最小反例覆盖 21／101 条、跨页命中、空结果、大小写、中文、字面通配符、超长词、稳定同时间排序、越界及最大偏移；数据和 count 的安全谓词一致。摘要验证跨页计数、搜索不改变总数、VERIFIED 未发布、旧修订发布、停用及重复发布历史。真实 PostgreSQL adapter、HTTP／权限、身份／请求竞争、三尺寸／200% 文字、刷新和返回恢复均需独立证据。

本决定不开放 S2～S6，不调整原型，不替代真实厂商、草稿／发现／发布的生产验收；S1、WP-0019 和 M6 完成事实不变。
