# ADR-0088：平台固定角色只读视图与账户导航

## 状态

已接受。2026-10-01。依据用户继续推进 WP-0017 的授权、已接受 ADR-0067、ADR-0075、ADR-0079 与 ADR-0087，以及 OpenDesign 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7` 固定提交 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`。本决策承接既定角色和原型，不增加角色、权限或持久化结构。

## 问题

现有 `/platform/roles` 复用三角色目录，展示租户角色、详情抽屉与额外任务切换。这与唯一平台角色模板及固定原型的只读详情页冲突，旧测试还把三个角色视为正确结果。`platform-roles:0` 的唯一生产操作是“管理账户”导航，不能以新增角色 API 或模拟保存承接。

## 决定

1. 平台页只解释已发布的 `PLATFORM_ADMINISTRATOR` 固定模板。租户管理员和普通成员仍由租户角色页解释；本片不改变其行为。固定职责说明随产品版本发布，不读取账户数量、成员明细、租户正文或凭据，也不表示所有后续能力已经交付。
2. `/platform/roles` 继续由现有浏览器会话与 `platform:accounts:manage` 能力保护。导航显示不构成授权；租户会话、失效会话和缺少能力的直接访问不得加载平台工作区。角色说明不签发权限、修改绑定或绕过后端授权。
3. 页面沿用固定原型：“平台治理”位置、“平台固定角色”标题、“平台管理员／固定模板”对象行，四项事实为“平台治理：租户生命周期与模型供应链”“运营读取：仅脱敏聚合”“租户正文：禁止访问”“成员明细：禁止访问”；右侧“需要关注”说明沿用原型正文。移除本页的三角色列表、详情抽屉和额外任务页签，不修改 OpenDesign。
4. “管理账户”是唯一主要操作，导航到现有 `/platform/accounts` 默认目录，支持刷新、前进和后退。点击只改变浏览器导航，不执行账户、角色、租户或配置写入；不提供创建角色、编辑权限、绑定或撤销按钮。账户操作仍由 ADR-0087 的独立页面和后端合同完成。
5. 固定模板没有可编辑草稿或数据库加载状态，不为模拟原型七态新增虚假数据源。会话验证、代码加载、拒绝访问及退出继续使用现有真实状态；事实页在已授权会话内可用，不以账户目录读取成功作为显示说明的前提。
6. 先用失败测试证明当前错误角色集合和额外操作，再实现局部视图。验收覆盖实际 Compose 前端、无业务写入的导航、平台与租户入口隔离、刷新和历史恢复，以及固定原型的 390/1024/1440px、200% 文字、键盘和 reduced-motion。截图只存 `/private/tmp`，凭据和会话不写仓库或日志。

## 边界与证据

复用四层后端、唯一 SPA 和现有会话能力，不增加无调用方接口。图谱的 `RoleDirectoryWorkspace` 影响集中在自身与 `ConsoleApp`；仅整改平台分支及其装配，租户分支保持原行为。最终证据分别记录源码、实际前端镜像、后端运行版本及 OpenDesign 固定版本；全部门禁通过后才关闭 `platform-roles:0`。本片不完成租户概览、WP-0017 整包或 M6。
