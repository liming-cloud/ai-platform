# ADR-0087：平台管理员账户目录与完整账户操作

## 状态

已接受。2026-09-29。依据用户要求完成 WP-0017 的完整账户操作、已验收 OpenDesign 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7` 固定提交 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`，以及 ADR-0048、ADR-0061、ADR-0073、ADR-0078、ADR-0079、ADR-0080、ADR-0083。本决策只冻结 `platform-accounts:0–4`；`platform-roles:0` 另行交付。

## 问题

生产 `/platform/accounts` 仍以“人员账户目录”展示全部全局身份，建立接口只写无角色账户，页面还允许从账户行授予和撤销平台角色。这与已验收原型及 WP-0017“只创建和展示平台管理员”的目标冲突。当前后端已有账户重置、停用、恢复和最后管理员保护，但页面没有完整接线；目录缺少服务端搜索和状态筛选，页大小、跳页及筛选不能按原型恢复。仅修改页面文案会留下无法首次登录的无角色账户。

## 决定

1. `/platform/accounts` 只展示具有活动 `PLATFORM_ADMINISTRATOR` 绑定的身份，已停用身份继续展示以便恢复。其他全局身份及已撤销角色的历史对象不删除、不迁移、不从本页暴露。平台角色目录及既有受控绑定接口保留各自职责，本页不提供独立角色授予或撤销入口。本条在平台账户页面与建立接口范围内取代 ADR-0061 的“先建无角色账户再单独授权”交互，不改变唯一身份、角色互斥和其他角色治理约束。
2. 现有 `POST /api/v1/platform/accounts` 只接受登录名和初始密码；平台账户治理权限先于任何身份事实读取。一次数据库事务建立全局唯一 `SubjectIdentity`、活动 `PLATFORM_ADMINISTRATOR` 绑定及认证权限修订；任一步失败整体回滚，不留下无角色新身份。响应只返回安全摘要，不返回明文、摘要或会话。新身份须能从独立平台入口用初始凭据首次登录，租户入口不得借此取得成员资格。不增加邮件邀请、默认公开密码或强制首次改密流程。
3. `GET /api/v1/platform/accounts` 采用固定排序的服务端分页，支持 `pageNumber`、`pageSize`、最多 64 字符的登录名子串搜索和 `ACTIVE`／`DISABLED` 状态筛选；默认 20、可选 10/20/50/100、页码从 1 开始。总数与筛选结果同范围，空结果仍显示创建入口。搜索、状态、页码与页大小写入 URL，刷新及前后退恢复；越界跳页在页面给出反馈，不猜测成功。接口用受控资源标识定位行操作；页面只展示登录名、状态、非秘密安全变更时间及当前账户标记，不渲染内部主体标识、角色代码或认证修订。
4. 重置、停用及恢复只作用于当前仍具有活动平台管理员绑定的目标。重置必须两次输入一致并确认撤销全部会话；只提交新密码，服务端在同一事务更新唯一身份并撤销目标的全部平台和租户会话。停用立即阻止该身份登录并撤销全部旧会话；恢复只恢复登录资格，不复活旧会话。当前操作者不得从本页重置或停用自己；最后一名可用平台管理员不得停用。无权、错角色目标、缺失 CSRF、重复登录名、旧状态及会话撤销失败均失败关闭。取消零写入，成功后重读服务端事实。
5. 创建、重置、停用和恢复的成功事实记录操作者、目标、操作、时间、结果和非秘密版本，并与业务写入同事务提交；审计写入失败则回滚。失败请求的通用 HTTP 安全日志不被本条宣称为完整账户操作审计。任何日志、响应、证据及仓库文件均不得含密码、摘要、Cookie 或 Token。
6. 页面沿用固定原型的“平台账户”任务、汇总条、搜索与状态筛选、表格、行操作、三种弹窗、空态和分页。原型演示密码说明按 ADR-0083 的真实凭据例外使用安全说明，不复制演示口令或本地模拟状态。确认弹窗说明影响、恢复和审计；390/1024/1440px、200% 文字、键盘及 reduced-motion 与固定原型逐项对照。截图只在 `/private/tmp`。

## 验证与边界

先用最小失败测试证明当前新账户无角色、目录混入无关身份及筛选缺失，再修复。服务端覆盖真实 PostgreSQL 的原子提交和审计失败回滚、角色互斥、登录名唯一、权限与 CSRF、最后管理员、自身操作、会话撤销失败回滚及分页总数。生产浏览器经正式接口创建独立合成平台管理员，验证首次登录、重置后的新旧凭据边界、停用与恢复、空态及 URL 分页筛选；登录回归和只读数据库事实分开记录。固定 OpenDesign 对照与实际 Compose 镜像均通过后，才将 `platform-accounts:0–4` 标为已验证。本片不交付角色目录、租户普通会员、WP-0017 整包或 M6。
