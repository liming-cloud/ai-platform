# ADR-0085：租户可用功能的独立配置与即时撤销

## 状态

已接受。2026-09-28。依据已接受的 ADR-0075、ADR-0079、WP-0017 和 OpenDesign 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7` 的固定提交 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`；本决策只冻结这些输入在生产中的保存和执行边界。

## 问题

固定原型的“可用功能”页有八项开关、取消与独立保存；生产尚无配置事实。若只保存勾选外观，现有直接 API 仍可访问，或旧租户会话继续持有先前能力，就不能称为功能控制。另一方面，普通成员、助手交付和真实问答尚未按 M6 顺序交付，不能把配置页验收说成这些功能已经上线。

## 决定

1. 功能目录只包含原型的八项稳定代码：`knowledgeManagement`、`modelGovernance`、`assistantDelivery`、`evaluationGovernance`、`assistantSelection`、`conversation`、`ownHistory`、`authorizedCitations`。前四项控制租户治理能力，后四项是普通成员对话功能的租户上限。租户隔离、权限检查、凭据保护和平台治理不在可关闭目录中。新增或改义代码须另行决策。
2. `organization-access` 拥有每租户一份独立配置，八项均为布尔值，初始全开以保持已交付能力；“开”仅表示平台允许，不代表对应下游功能已经发布，也不自动授予成员或对象权限。迁移时为现有租户显式回填；新租户在原子开户事务中写入。缺失配置或损坏值不能静默补默认值。
3. 平台管理员以平台范围会话和租户治理权限读取、完整替换八项配置；`tenantId` 只定位资源。保存携带非负 `expectedVersion`，旧版本冲突拒绝，成功版本递增。未知、缺失、非布尔字段拒绝。取消只丢弃浏览器草稿；刷新和重新进入从服务端加载。页面不以本地存储模拟成功。
4. 成功改变任一开关时，立即撤销目标租户所有旧租户范围会话，包括其他页签、浏览器和同租户其他成员；不撤销平台范围或其他租户会话。撤销失败则配置事务回滚，不能显示成功。恢复上级开关只恢复平台上限，不替成员补发此前没有的权限。新会话及直接路由仍须按“角色 ∩ 租户功能 ∩ 成员与对象授权”判定。
5. 对本切片时已发布的租户功能，服务端在各自受保护 HTTP/API 边界检查对应开关，不能只隐藏前端导航；读取与写入均拒绝，不删除已有资源。控制面由组织上下文的配置存储检查，查询进程只装配同一组织上下文拥有的只读事实检查器，不开启账户写入或平台管理入口。不存在配置、功能关闭或事实源不可用时失败关闭。公开认证、平台治理、会话检查与不对应八项的人员管理入口不受这些开关阻断。后续 WP-0018～0025 每交付一项新能力时，必须把它接入相同配置事实和直接访问反例；配置页的通过不能代替该能力的生产验收。
6. 生产页承接固定原型的独立路由、八项顺序、标题、帮助、取消、保存、反馈、三尺寸与键盘行为。原型合成身份和模拟状态不进入生产；截图只在 `/private/tmp`。

## 验证与后果

先以失败测试证明当前缺少保存和直接 API 拦截，再覆盖权限优先、字段严格性、并发版本、跨租户隔离、成功恢复、撤销故障回滚、旧会话失效与新会话有效。受控 Compose、实际生产浏览器、只读数据库事实和 OpenDesign 固定版本对照均通过后，才关闭 `platform-tenant-features:0`。本决策不把 WP-0017 整包、66 页或 M6 认定为完成。
