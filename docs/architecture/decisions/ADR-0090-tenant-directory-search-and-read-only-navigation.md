# ADR-0090：租户目录搜索与只读导航

## 状态

已接受。2026-10-01。查询与导航合同依据用户继续按 OpenDesign 闭环交付 WP-0017 的授权、已接受的 ADR-0022、ADR-0041、ADR-0079、ADR-0080 与 ADR-0089。原型为 OpenDesign 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7`，原页面固定于 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`，共享移动布局为 `47c4f6f31823617633ce0bac98074208781f5565`。目录的事实冲突按下节用户接受的原项目修订解决；新版本通过验证并固定提交前，不宣称视觉验收。

## 问题

实际部署忽略租户搜索条件：用已有隔离租户的精确编码查询仍返回全部 70 个租户的第一页。旧目录采用卡片和额外生命周期／管理员弹窗，未承接已验收目录的搜索、状态、表格及完整分页；旧异步请求也没有归属保护。原型的区域与安全异常数字没有生产事实源，不能用静态演示值填补。

## 决定

1. 复用 `GET /api/v1/platform/tenants`，仅增加可选 `query` 与 `status`。查询去掉首尾空白后最多 64 字符，对租户业务名称和编码做不区分大小写的字面子串匹配；`%`、`_`、反斜线不是通配符。状态为空时读取全部，否则只允许 `PROVISIONING`、`ACTIVE`、`SUSPENDED`。页码、总数、默认 20 与上限 100、固定排序继续遵守 ADR-0022，不增加任意排序、游标或旧路径回退。
2. 平台治理权限在读取任何列表、总数或管理员事实之前检查；租户、匿名和失效会话拒绝。过滤与分页在 PostgreSQL 中执行，使用既有 MyBatis-Plus 分页及参数绑定，不在前端过滤当前页。同范围总数与行结果一致，排序仍为最后变更时间、租户标识降序。
3. 目录只返回真实名称、编码、生命周期及非秘密管理员资格数量；数量从同一上下文的成员资格聚合，不返回成员、主体、角色明细或凭据，不逐行请求管理员接口。零资格不能显示“已分配”。`SUSPENDED` 保持 ADR-0041／0089 的“已暂停”语义，不能作为全局账户停用。
4. `/platform/tenants` 的 URL 保存搜索、状态、页码和页大小；搜索、筛选及页大小变化回到第一页，刷新和前后退恢复。支持 10/20/50/100 条及有效页跳转；失败、空结果、加载和越界有真实反馈，目标变化、旧请求迟到和会话失效不能恢复旧结果。
5. “建立新租户”仅导航到已交付原子开户向导；取消不创建对象。“查看详情”仅进入已交付概览，管理员与其他设置由五页导航管理。旧目录的额外写操作不作为这两个原型操作的交付依据；既有后端生命周期命令及历史证据不删除、不改写。
6. 目录结构、控件、键盘、三尺寸、200% 文字及 reduced-motion 必须对照已接受的 OpenDesign 目录版本。本次修订不成为生产自行偏离其他原型内容的许可；未通过实际部署验证时，不宣称视觉验收或本切片完成。

## 2026-10-01 目录原型修订接受依据

用户明确要求“修订并接受 OpenDesign 目录设计”。在同一原项目中修订 `platform-tenants`，不建立副本，不把生产差异列为视觉例外：

1. 删除没有事实源的“驻留区域”列。保留租户名称与编码、生命周期、管理员资格摘要和查看详情；本片不增加区域配置。
2. 摘要采用“租户目录 · 生命周期摘要”和“安全边界异常：尚未核实”，不将没有监测结果的异常数写成 0，也不以本片实现异常监控。
3. 状态按现行领域展示为“待启用”“活动”“已暂停”，筛选保持“全部状态”。管理员摘要按真实资格数量区分“已分配”和“未分配”；原型用已有合成成员事实演示，不复制生产身份或秘密。
4. 保持已接受主题、页面标题、导航、搜索、建立入口、查看详情、标准分页及七态。目录名称和编码完整换行，事实行随文字放大撑开；该修订只作用于 `platform-tenants`，解决人工发现的 390px／200% 文字省略及重叠，不改变其他页面或共享视觉基线。新固定版本、原项目差异和浏览器验证登记在本包证据，生产按该版本承接后再独立验收。

目录修订固定提交为 `9a1747609d41bf546e78486954539cd4b79fbbb9`，原型 9 项契约／渲染及 11 项真实浏览器检查通过；见[原型修订接受证据](../../tasks/WP-0017/evidence/WP-0017-tenant-directory-opendesign-acceptance-20261001.md)。该接受不代表生产目录切片通过。

同日空结果补充复核发现原型四列表格被共用函数插入 `colspan="20"`，导致空结果表头挤窄。按本次已授权的目录修订，仅对租户目录恢复 `colspan="4"`，没有以生产布局反推设计或改变其他目录。最新目录固定提交为 `d36c7f46d0187c0421d4989c12f601d5c190d73f`；补充断言先失败，原型 10 项及浏览器 12 项通过，生产须承接此版本再收口。原 `9a174760…` 的接受和测试范围保留，不以其结果证明新增空结果回归。

## 验证与边界

先保留真实部署忽略搜索的失败复现，再增加过滤、字面通配符、状态、页边界与总数、权限优先及迟到／失效结果的测试。真实 PostgreSQL 与 HTTP 合同分别验证；生产浏览器使用已有隔离对象，搜索、分页、创建入口取消及详情导航业务写入为零。最终实际前后端 OCI revision、镜像、登录回归、只读业务事实与原型对照分别绑定，全部通过后才关闭 `platform-tenants:0–1`。本片不重新执行开户写验收，不增加区域调度、安全异常监控、普通会员或后续工作包，不完成 WP-0017 或 M6。
