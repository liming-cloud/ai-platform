# ADR-0090：租户目录搜索与只读导航

## 状态

已接受。2026-10-01。查询与导航合同依据用户继续按 OpenDesign 闭环交付 WP-0017 的授权、已接受的 ADR-0022、ADR-0041、ADR-0079、ADR-0080 与 ADR-0089。原型为 OpenDesign 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7`，页面固定于 `21b45c347a4008f5959b1b972e3ffd8a5aadcc6f`，共享移动布局为 `47c4f6f31823617633ce0bac98074208781f5565`。本条不接受尚未解决的目录区域与异常统计展示差异。

## 问题

实际部署忽略租户搜索条件：用已有隔离租户的精确编码查询仍返回全部 70 个租户的第一页。旧目录采用卡片和额外生命周期／管理员弹窗，未承接已验收目录的搜索、状态、表格及完整分页；旧异步请求也没有归属保护。原型的区域与安全异常数字没有生产事实源，不能用静态演示值填补。

## 决定

1. 复用 `GET /api/v1/platform/tenants`，仅增加可选 `query` 与 `status`。查询去掉首尾空白后最多 64 字符，对租户业务名称和编码做不区分大小写的字面子串匹配；`%`、`_`、反斜线不是通配符。状态为空时读取全部，否则只允许 `PROVISIONING`、`ACTIVE`、`SUSPENDED`。页码、总数、默认 20 与上限 100、固定排序继续遵守 ADR-0022，不增加任意排序、游标或旧路径回退。
2. 平台治理权限在读取任何列表、总数或管理员事实之前检查；租户、匿名和失效会话拒绝。过滤与分页在 PostgreSQL 中执行，使用既有 MyBatis-Plus 分页及参数绑定，不在前端过滤当前页。同范围总数与行结果一致，排序仍为最后变更时间、租户标识降序。
3. 目录只返回真实名称、编码、生命周期及非秘密管理员资格数量；数量从同一上下文的成员资格聚合，不返回成员、主体、角色明细或凭据，不逐行请求管理员接口。零资格不能显示“已分配”。`SUSPENDED` 保持 ADR-0041／0089 的“已暂停”语义，不能作为全局账户停用。
4. `/platform/tenants` 的 URL 保存搜索、状态、页码和页大小；搜索、筛选及页大小变化回到第一页，刷新和前后退恢复。支持 10/20/50/100 条及有效页跳转；失败、空结果、加载和越界有真实反馈，目标变化、旧请求迟到和会话失效不能恢复旧结果。
5. “建立新租户”仅导航到已交付原子开户向导；取消不创建对象。“查看详情”仅进入已交付概览，管理员与其他设置由五页导航管理。旧目录的额外写操作不作为这两个原型操作的交付依据；既有后端生命周期命令及历史证据不删除、不改写。
6. 目录结构、控件、键盘、三尺寸、200% 文字及 reduced-motion 必须对照原 OpenDesign。当前任务单独登记区域与异常统计的事实冲突；用户确认承接方案前不把这两项差异列为例外，不宣称视觉验收或本切片完成。

## 验证与边界

先保留真实部署忽略搜索的失败复现，再增加过滤、字面通配符、状态、页边界与总数、权限优先及迟到／失效结果的测试。真实 PostgreSQL 与 HTTP 合同分别验证；生产浏览器使用已有隔离对象，搜索、分页、创建入口取消及详情导航业务写入为零。最终实际前后端 OCI revision、镜像、登录回归、只读业务事实与原型对照分别绑定，全部通过后才关闭 `platform-tenants:0–1`。本片不重新执行开户写验收，不增加区域调度、安全异常监控、普通会员或后续工作包，不完成 WP-0017 或 M6。
