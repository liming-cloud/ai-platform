## M6 能力顺序

平台身份与租户开通 → 成员授权 → 模型供应 → 知识接入 → 评测和共用流式执行 → 索引检索 → 助手交付 → 普通会员问答 → 查询治理 → 平台治理概览 → 全量质量复验 → 人工评审。ADR-0092 只调整平台概览在 M6 内的责任与顺序，不删除其已接受原型或后续依赖。

具体工作包依赖、进度和证据只保存在 [任务索引](../tasks/README.md)及[M6 实现矩阵](../tasks/milestones/M6/README.md)。长期路线不复制实时任务状态。M7 设备与同意、M8 正式生产环境继续遵守各阶段人工门禁。
