# WP-0016 普通用户问答原型闭环

## 目标与边界

本切片验证：普通用户能否从独立登录开始，选择授权助手，创建、恢复并继续一个固定版本的会话，查看引用和从失败恢复。产物可丢弃，只使用合成账号和本地合成状态，不接真实模型、API、凭据或数据库，不推进 WP-0017。

保留原 OpenDesign 项目和 68 页清单；只调整 login、assistants、conversation 及其最小共享依赖。平台角色页等通用视觉整改留在后续切片。产品以“先能用，再好用”为验收顺序。

## 已确认选择

- ADR-0074/0075：固定三角色，两级功能和助手对象授权；每次读取历史、引用或继续生成都重验授权。
- 浏览器只记合成会话事实，不保存输入密码。演示登录使用明确公开的假账号 `demo.user`、组织 `spruce-demo`、演示口令 `demo-only`；错误输入有反馈。不得把这当作真实认证实现。
- 问答状态由一个可测试来源驱动：会话、轮次、消息序号、增量偏移、引用和终态。刷新、切页或中断后恢复同一轮，不重复创建问题。禁止继续用临时 DOM 作为消息事实。
- 会话 URL 包含 `conversationId`，刷新、深链接和前进后退恢复同一对象。点击助手创建新会话，历史选择恢复旧会话，不静默替换助手或版本。
- 首版只模拟有确定证据的示例问题；超出示例范围明确拒答，不让所有问题返回同一段年假答案。
- 断线、失败和重试有可操作的合成演示入口；显式退出、切换成员、权限撤销后旧计时器不得恢复旧主体内容。
- 用户于本轮确认使用 `DESIGN_VARIANCE=7`、`MOTION_INTENSITY=5`、`VISUAL_DENSITY=7`，替代此前的 4/2/6。本次问答页与既有设计参数统一；保留既有企业色彩与图标，不全仓换皮，仍必须保证对齐、可读性和 reduced-motion。
- 普通用户只看到简洁登录、助手、会话和引用；演示选择/模拟失败等工具放入审查器，不进入正常产品正文。

## 验收合同

保留已有稳定控件 `#login-form`（tenantCode、username、password）、`#assistant-search`、`[data-assistant-id]`、`#question-input`、`[data-conversation-id]` 和 `[data-citation-id]`。

新增稳定验收标记：新会话 `[data-new-conversation]`、退出 `[data-query-logout]`、活动轮次 `[data-run-state]`（大写状态）、重试 `[data-query-retry]`、继续接收 `[data-query-resume]`。这些只是可丢弃原型的 DOM seam，不是公共产品 API。

- 未登录的助手/会话深链接不返回受保护内容；已有合成会话不等于已登录。
- 正常登录后仅授权助手可见；新增会话固定已发布版本，两个会话内容互不串线。
- 已完成和接收中的轮次刷新后不丢失、不重复；失败重试不会重复问题。
- 历史筛选、选择、续问、按序号加载更早消息都有实际数据变化。
- 退出及成员/权限变更立即隐藏正文和引用，停止旧生成回调；不使用前端隐藏证明生产安全。
- 存储失败显示未保存且可恢复的错误，不假称已完成。
- 键盘、390/1024/1440、reduced-motion；保留其余页面回归并诚实记录范围外既有失败。

## 验证

父任务 `scripts/query-journey.test.cjs` 的五项红灯保留在 `artifacts/query-closure-red.tap`，没有为实现改写。新增状态与边界测试先保存红灯，再验证权限投影无嵌套正文、独立登录态、序号幂等、版本固定、退出重登续接及存储失败。`query-resilience.test.cjs` 通过真实浏览器验证跨标签撤权、接收恢复、小屏主操作、引用点击和 reduced-motion。

合成登录态单独保存在 `wp0016-query-session-v1`，聊天记录保留在业务演示状态中；退出移除登录态，不清除历史。浏览器拒绝移除登录态时，当前页面仍失败关闭并明确提示记录未清除，不能据此证明生产认证安全。重新登录把旧接收轮次转为暂停，需本人显式继续。

本机获准的 Playwright 已执行专项与全平台复验；OpenDesign 内部运行无法启动 Chromium 的旧记录只是子进程限制，不是当前用户权限阻断。最终报告为 `artifacts/query-closure-full-browser-final-20260903/verification.json`，专项报告为 `artifacts/query-closure-browser-green.tap`。人工确认仍未通过，局部绿灯不代表整个平台通过。
