# 独立评测治理原型

## 用户任务

租户管理员维护与知识库绑定的冻结评测数据集，用同一个稳定助手的冻结版本执行可复现评测，比较候选与基线，并把失败分类转成可跟踪的修复事项。

## 页面闭环

1. `evaluation-datasets`：建立空白数据集，或显式复制同知识库的已发布基线；复制品始终是独立草稿。
2. `evaluation-dataset-detail`：维护合成问题摘要、期望结果和期望证据；满足 60 个可回答、20 个证据不足拒答、10 个权限拒绝和 10 个多轮样本后，发布不可变版本。
3. `evaluation-run-create`：只接受当前租户、同一知识库的冻结助手版本和已发布数据集版本。
4. `evaluation-run-detail`：固定助手、索引、模型配置修订和数据集版本，依次执行检索与生成、评分和门禁聚合。
5. `evaluation-comparison`：只比较同一稳定助手、同一数据集版本的完成运行；安全、质量、性能或一致性回退都会阻止放行。
6. `evaluation-failure-analysis`：按失败类别和数量建立去重修复事项，不复制问题、回答或引用正文。

## 原型边界

- 页面、状态和结果均为合成数据，不执行真实模型调用、检索、评分或工单创建。
- 浏览器持久化只用于演示刷新恢复，不能作为生产事务或授权证明。
- OpenDesign 是原型内容与视觉事实源；验证截图只保存在系统临时目录，不进入项目。
- 自动门禁通过不代表人工验收通过，`WP-0016` 在产品负责人确认前保持进行中。
