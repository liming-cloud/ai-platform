# WP-0016 知识库与资料接入原型

## 用户任务

租户管理员可以在平台分配的配额内创建知识库，随后向当前知识库添加一份粘贴文本或本地文件，并从资料目录进入文档详情查看处理进度、失败原因和恢复动作。

## 可操作闭环

1. `knowledge-directory` 创建知识库，支持取消、名称冲突、配额到顶、保存失败与刷新恢复。
2. `source-add` 只提供“本地文件”和“粘贴文本”，不提供远程 URL。允许 TXT、Markdown、DOC/DOCX、XLS/XLSX、CSV、PDF、PNG、JPEG 和 WebP。
3. 提交前按平台配额校验单文件与粘贴文本大小；扩展名、MIME、加密、Office 宏和压缩包损坏异常失败关闭。原型不上传真实内容，也不把粘贴正文写入浏览器状态。
4. 文档按 `RECEIVED -> SCANNING -> EXTRACTING -> EXTRACTED -> CHUNKING -> INDEXING -> READY` 推进；失败记录结构化错误码且不进入索引。
5. 失败来源从安全阶段重试；就绪来源“重新处理”创建新修订，活动索引继续使用上一修订。更新文档进入资料接入页，全库重建进入独立索引任务页。

## 产品边界

- 本原型验证信息架构、交互、状态和失败语义，不执行病毒扫描、文件解析、OCR、分块、Embedding 或索引写入。
- 平台管理员只能配置配额和租户功能上限，不能从平台范围读取租户资料正文。
- OpenDesign 项目是视觉事实源；浏览器截图只写系统临时目录，仓库保留状态测试、浏览器测试和机器可读报告。
- 人工验收仍未通过；本闭环不授权 WP-0017 或生产代码修改。
