# WP-0016 业务闭环与验收边界

## 当前结论

2026-09-07 新一轮人工拒绝仍有效。本轮整改租户拆页、平台账户职责、新租户直接创建管理员、三类登录入口、通用分页、运行记录和恢复摘要。当前共 73 页，其中 61 个 M6 页面属于交互审查范围；原三项暂缓及 10 个 M7/M8 前置页面边界不变。

尚未闭合两项：普通成员账号创建/重置的职责边界待用户确认；供应商厂商类型与自动预填待确认只读官方资料核对方式。不能宣称整套原型可验收，不能进入 WP-0017。

## 已实现路径与真实边界

| 路径 | 当前原型行为 |
| --- | --- |
| 平台账号 | 只创建和治理平台账户，不混入租户人员；认证版本不作为日常列 |
| 新建租户 | 信息、配额、管理员账号三步；原子提交；独立入口登录自己的组织 |
| 租户设置 | 概览、管理员、配额、功能、登录安全五页，独立保存、取消与刷新 |
| 普通成员 | 保留添加已有合成账号、对话功能与助手授权；新增凭据管理尚待决定 |
| 知识与索引 | 粘贴/文件、状态推进、重试、来源版本、单文件/全库重建及确认激活 |
| 模型与助手 | 供应、配置、部署、探测与版本；助手永久关联知识库并经评测发布；厂商预填待补 |
| 普通问答 | 登录、授权助手、固定版本会话、增量回答、引用、历史、续问及恢复 |
| 公共分页 | 完整夹具行分页，数字页码、大小、跳页、筛选与刷新；事件流不分页码 |
| 运维前置 | 脱敏链路与有限高度事件记录、恢复点选择及隔离演练状态；不执行真实运维动作 |

账号仍是统一人员身份，不建立共享租户密码或第二套凭据。旧演示登录修复保留业务数据、不启用停用身份；不得自动清空用户浏览器。

所有扫描、OCR、模型调用、质量指标和运维数据都是合成夹具。状态机、浏览器测试、控件接线枚举和全页矩阵分别验证不同层次；监听器不等于闭环，模拟指标不等于生产安全或准确率。
