# 结构化数据与对象范围原型边界

## 结构化数据版本

- 页面任务是冻结一个 CSV 来源版本的标题顺序、字段类型、业务含义、查询资格和敏感级别，不是提供任意 SQL 或直接修改活动索引。
- 主内容与标题只能选择公开文本字段；禁止进入检索的字段不能通过查询资格绕过。
- 草稿必须先运行抽样预检，检查标题一致、空内容和敏感正文；发布后形成不可变结构版本。
- 页面与持久状态不保留样本值，拒绝态不披露字段名或来源事实。
- 结构版本发布不自动重建或切换活动索引，后续索引影响进入独立任务。

## 对象范围登记

- 平台先为租户签发受控文本范围；租户知识管理员只能选择当前租户已有范围并登记到本租户知识库。
- 页面不接收或展示 bucket、object key、endpoint、access key、secret key 等基础设施定位与凭据。
- 登记成功只建立“待探测”来源，不自动同步、解析、索引或发布。
- 重复提交同一名称保持幂等；伪造范围版本、跨租户范围、越权、功能关闭和存储失败均不改变状态。

## 交互与视觉

- 桌面端使用单一字段表完成扫描与编辑；移动端转为两列字段卡片，不产生第二套业务表单。
- 390px 下管理导航改为不遮挡正文的粘性顶部栏；1024px 与 1440px 保持统一租户导航。
- 产品正文不解释实现技术，只保留任务、状态、失败原因和下一操作。
- OpenDesign 是内容与视觉事实源；自动检查截图仅在系统临时目录生成，不进入项目。
