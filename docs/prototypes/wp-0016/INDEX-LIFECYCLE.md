# WP-0016 全库索引生命周期原型

## 用户任务

租户管理员可以从知识库索引目录发起全库重建，观察候选版本的构建与冻结评测结果，并在旧索引持续服务的前提下决定是否激活新版本。

## 可操作闭环

1. `index-versions` 只承担版本比较和进入重建，使用一个普通目录分页。
2. `index-rebuild` 明确触发原因并冻结活动来源清单、Embedding、维度、距离度量、解析器版本和分块策略；提交后创建独立候选版本，不修改活动索引。
3. `index-detail` 按冻结清单、分块、向量、混合索引和评测五个阶段推进；刷新可恢复同一状态。
4. 冻结评测检查 Recall@10、引用正确率、拒答准确率、越权泄漏和检索 p95。任何一项失败时版本进入阻止状态，不显示可用的激活动作。
5. 授权管理员确认后一次性切换活动指针并把旧活动版本标记为已替代；取消、越权、并发构建和保存失败均保持旧版本继续服务。

## 产品边界

- 本原型只验证信息架构、交互、不可变版本和失败语义，不执行真实分块、Embedding、pgvector、FTS、RRF 或 rerank。
- 模型、维度、距离度量、解析器或分块策略变化只创建重建任务，不自动激活；质量结论不能跨版本沿用。
- OpenDesign 项目是原型内容与视觉事实源。浏览器核对图只写系统临时目录，仓库仅保留契约、测试和机器可读报告。
