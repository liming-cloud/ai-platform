# WP-0016 可信 RAG 高保真原型设计

## 2026-09-08 阶段一、二候选

当前视觉采用 OpenDesign 本机 Claude (Anthropic) 参考包。它是整理后的参考设计，不代表 Anthropic 官方完整企业组件规范。包内 token 名称保留在 `tokens.css`；中文字体、企业密度、较深行动色集中扩展。暖纸色 #F5F4ED、面板 #FAF9F5、陶土 #C96442、暖黑 #141413；不用专有字体。标题 Georgia / 中文宋体回退，正文中文 sans，正文 16px、表格至少 15px，区块间距 24–32px。7/5/7 保持。

原 73 个页面的逐项去向位于唯一清单 `page-inventory.json` 各项 `migration`。旧 screen 和 route 不删除；新增 4 个成员页及 `assistant-overview` 后共 78 个入口。原 61 个 M6 任务仍是目标范围，10 个 M7/M8 只做视觉与信息架构，渠道绑定、设备凭据与邮件邀请暂缓。`阶段二样板` 是实施范围，不表示人工通过；`阶段三待迁移` 不得批量标完成。

知识库是内容唯一全局入口，子导航为概览、文档、处理任务、索引管理。成员目录只承担查找和生命周期操作；成员账号、对话功能、可用助手分别进入对象页，成员开户使用三步独立页面。成员 URL 选择不切换登录身份。助手工作区沿用冻结版本、测试、质量门禁和发布确认；旧会话仍固定版本。平台租户五页保留。

弹窗容器统一承担 24px 内边距，不依赖内部 form；长任务移入页面。组件演示位于原型场景审查工具，支持即时结果、可中断重播与减少动态效果。动效 150/200/240ms，统一 cubic-bezier(0.2,0,0,1)；权限撤销与业务结果不等待动画。

阶段二续修已接线：文档内容预览/处理记录/版本在旧 `source-detail` URL 下以 `documentView` 区分；正文是明确标注的合成提取文本，不是真实 PDF 渲染。处理记录来自原型状态操作序号，初始未操作对象仅标记初始快照。助手增加概览，冻结配置只读，模型中文名称默认可见，内部标识与策略码进入技术详情。发布确认使用标题、内容、操作三区，继续调用原评测与发布门禁。

成员两个保存页调用 `saveMemberScope`，只提交白名单范围，通过既有管理员授权与原子存储回滚。未保存离开时提供保留/放弃；界面草稿按租户、操作者和登录代次隔离，刷新恢复非秘密输入，失效草稿清除。密码仅存在表单，公开演示密码可在创建步骤发现。非法成员标识不回退到他人。

`createStressSnapshot(base)` 是独立测试快照工厂，不自动写入日常浏览器或重置账户。压力数据覆盖 1000 文档、1000 普通成员、200 助手候选、100 文档版本和 10000 处理记录；目录进入 DOM 前切片，默认 20 行，事件使用序号窗口。真实浏览器验证搜索、跳页、刷新、助手选择焦点与记录窗口，不靠挂载全部数据再隐藏。

本轮 161 项 Node、157 项浏览器与 1638 个页面状态/视口场景通过。连续任务在五种布局下从新建知识到本人问答完成；手机步骤、独立保存、非秘密草稿、浏览器返回确认、禁用态、正常与减少动态效果均有专项验证。报告见 artifacts/stage-two-validation-summary.json。截图仅临时保存并抽查；机器验证不代表人工认可。样板方向待确认，阶段三和全量送验均未启动。

## 视觉与交互基线

保持用户确认的 `DESIGN_VARIANCE=7`、`MOTION_INTENSITY=5`、`VISUAL_DENSITY=7`。保留 Fluent 企业组件语义及 MIT 图标，视觉 token 已替换为上文 Claude 参考包，不再使用深绿品牌强调。保持清晰边界、紧凑事实与表格，不加入营销图案或无意义动画。

- 一个页面一个主要任务；页头只包含页面、对象、状态及主要操作，不混入工程接口和架构解释。
- 目录、详情、向导、运行结果、时间线和风险核对采用不同任务布局，共享控件保持一致。
- 导航来自 `navigation.js`；图标为本地 Microsoft Fluent System Icons SVG 图片，来源、版本与 MIT 许可保留在 `assets/icons/`。
- 使用 4/8px 间距体系；中文正文至少 15px，数字可用等宽字形。表单按标签、控件、帮助三个层级对齐，帮助不拉伸输入框。
- `fact-list` 提供统一键值网格，数字、时间、状态有明确层级；窄屏改为单列，不使用浏览器默认裸文字列表。
- 390、1024、1440 均需验证；手机步骤操作固定可达，长表单、弹窗和时间线有明确滚动边界，不能遮住焦点。
- 动效限于控件、弹窗、内容进入等短时反馈，通常 160–240ms；reduced-motion 下不依赖位移或持续动画获得结果。
- 每页覆盖 loading、empty、error、denied、partial、disabled、success；加载、失败和拒绝态不暴露受限对象正文。

## 目录分页统一契约

`directory-pagination.js` 只负责可丢弃原型的完整夹具行切页，生产仍需遵守 ADR-0059 的服务端分页。

- 默认每页 20，可选 10/20/50/100；显示总数、当前范围、数字页码、上一页/下一页以及指定页跳转。
- 跳转必须是有效整数，越界时原页不变并定位错误。改变页大小或筛选时回到第 1 页。
- URL 的 page/size/q/status 支持刷新和浏览器返回恢复；跨任务导航不携带另一目录的分页参数。
- 筛选隐藏和分页隐藏分别管理；来源的失败说明附行跟随所属来源，不留孤立错误行。
- 模型表格使用统一分页容器。评测样本不再硬截前 6 条，全部冻结样本可按页查看。
- 一页最多一个普通目录分页；关联对象用搜索选择器。聊天消息、处理记录与事件流仍按序号加载，不显示页码。

## 身份、入口与租户设置

依据 ADR-0078，保留统一人员身份、全局唯一登录名和固定三角色；管理界面的职责拆分不意味着第二套密码库或新的角色体系。

| 入口 | 账号职责 | 原型 screen |
| --- | --- | --- |
| 平台管理登录 | 平台管理员 | console-login |
| 租户管理员登录 | 指定组织的租户管理员 | tenant-login |
| 普通用户问答登录 | 指定组织且已授权助手的普通成员 | login |

三个入口彼此可发现，共用认证机制；入口名称和 URL 不授予权限。平台管理员不因打开租户入口而获得租户权限。新租户详情提供带租户编码的管理员登录链接，本人仍须输入凭据。

平台账户目录只展示和创建平台账户。租户管理员在对应租户的“管理员”页查看、重置密码、停用或恢复；“认证版本”仅作为内部会话失效机制，不占日常列表列。已有演示账号、停用状态和用户数据不自动重置或迁移。

租户详情固定对象标识 `platformTenantId`，拆分五页：

| 页面 | 唯一职责 |
| --- | --- |
| 概览 | 基本信息、安全保障与管理员登录入口 |
| 管理员 | 当前租户管理员账号治理 |
| 资源配额 | 五项配额独立编辑、取消、保存 |
| 可用功能 | 平台分配租户的功能上限，独立保存 |
| 登录安全 | 三项登录策略独立编辑、取消、保存 |

新建租户为“租户信息 → 配额设置 → 管理员账号”。最后一步直接填写登录名、初始密码与确认，不选择已有账户。组织、身份及管理员资格原子提交；失败不留下孤儿账号或无管理员租户。非秘密草稿支持回退、刷新和取消，密码不跨步骤保存，提交后清空输入。

配额、三项登录策略沿用 ADR-0076：正数/整数校验、不能低于已用量、租户只读。租户隔离、权限校验和密码不回显始终开启；生产策略上限与既有会话生效时机留待实施包冻结。

普通成员由租户管理员直接创建账号、设置公开合成口令、对话功能和已授权助手；身份与成员资格一次提交。重置仅限唯一归属当前租户的普通成员，不能影响其他租户身份或管理员；旧口令和会话失效。停用需确认，只影响本租户成员资格，恢复不扩大原助手授权。邮件邀请、自助激活仍暂缓。

## 演示凭据与旧数据

只接受公开合成口令：内置未修改账号为 `demo-only`，创建或重置时可选择 `Initial-only-2026!`、`Reset-only-2026!` 等页面列出的公开夹具。必须使用该次实际选择的口令，并非任意演示口令都可登录。

原型只保存非秘密登录场景码，不保存明文、密码摘要、真实密钥或令牌。旧数据缺少登录场景时，用户可明确确认“修复演示登录”；修复保留业务数据，不覆盖已轮换身份，不恢复停用账号，也不自动登录。原型重置全部数据是另一个明确且破坏性的用户操作。

如内置租户管理员已被人工停用，可由平台管理员在对应租户“管理员”页明确恢复；不会自动恢复，也不需要清空全部演示内容。

## 运维与恢复前置原型

- 平台运行状态只展示脱敏业务影响；链路步骤、开始时间、复查次数和状态采用结构化 UI。
- 处理记录最新在前，首次显示 5 条，每次加载更早 5 条；时间线有可聚焦的有限高度滚动区域，不增加目录分页。
- 备份与恢复以“选择备份 → 完整性检查 → 隔离恢复 → 校验报告”为状态机。恢复点选择、隔离目标、生产边界、检查清单和报告分层展示。
- 完整性未通过不能创建隔离环境；不提供生产覆盖恢复。所有运行数据为 M8 合成演练，不代表生产运维能力。

## 人工门禁

按“功能能用 → 功能好用”顺序完成三角色连续操作，再逐页核对异常、三档视口和键盘。所有待决策与未闭合项必须保留真实状态；不得以监听器、页面数量、HTTP 200、模拟指标或本机截图替代产品闭环与人工验收。
