# WP-0016 助手交付原型

## 产品任务

稳定助手在创建时永久关联一个知识库；后续版本只能更新冻结的索引、模型配置修订和问答策略。知识库存在活动索引即可创建助手，正在构建的新索引候选不会阻断旧索引上的业务。

## 页面闭环

| 页面 | 用户结果 |
| --- | --- |
| 助手目录 | 查看已发布版本和唯一候选，继续现有候选或创建新版本 |
| 创建助手 | 搜索活动索引可用的知识库，建立永久关联的稳定助手 |
| 草稿配置 | 冻结知识库、索引、Chat/Embedding/Rerank 配置修订及检索、引用、拒答策略 |
| 单题测试 | 使用冻结依赖返回有定位引用的回答或明确拒答，并把结果加入评测集 |
| 发布门禁 | 运行冻结评测；质量、越权泄漏或首 token 门禁失败时禁止请求发布 |
| 发布确认 | 原子更新稳定助手的发布指针；新会话使用新版本，旧会话保持原版本 |

创建页采用桌面双列、移动端单列表单。字段帮助不进入单个输入框下方撑开布局；同排输入框顶部与高度误差均不超过 1px。页面继续使用 `DESIGN_VARIANCE=7`、`MOTION_INTENSITY=5`、`VISUAL_DENSITY=7`。

## 不变量与失败关闭

- 一个稳定助手永久对应一个知识库，同一助手最多保留一个未发布候选。
- 版本保存时冻结索引和三类模型配置的明确修订，不读取后续活动配置漂移。
- 越权泄漏必须为 0；`Recall@10`、引用正确率、拒答准确率和首 token 时延必须同时达到 M6 门禁。
- 功能关闭、越权、存储失败、无活动索引和非活动模型配置均不留下部分状态。
- 发布不迁移旧会话；夹具会话显式固化原 `AssistantVersion` 与 `IndexVersion`。
- 这是合成状态原型，不执行真实模型调用、评测任务、后端授权或原子数据库事务。
