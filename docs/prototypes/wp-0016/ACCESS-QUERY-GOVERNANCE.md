# 访问策略与查询治理原型

## 范围

本切片在 OpenDesign 项目 `249f81f2-6f1a-46ff-988c-da3cdedb35e7` 中闭环三个页面：

- `access-policy-detail`：保存、预览并发布普通成员的助手授权策略版本。
- `governance-query`：查看部署配置中的查询配额和脱敏终态运行摘要。
- `query-diagnostic`：读取一次查询的冻结诊断事实并建立去重修复事项。

页面继续使用 `DESIGN_VARIANCE=7`、`MOTION_INTENSITY=5`、`VISUAL_DENSITY=7`。截图只用于临时视觉核对，不属于原型事实源，也不写入仓库。

## 访问策略

- 策略只授权活动普通成员使用一个已发布助手，不创建自定义角色，也不配置菜单或内部 API。
- 知识库由助手的永久关联关系自动确定，页面不能另选知识库。切换助手时立即回显新的只读知识库，保存后重新生成授权预览。
- 发布前必须通过 24 个允许样本和 8 个拒绝样本；预览覆盖助手目录、对话、本人历史、引用访问和撤权失败关闭。
- 发布形成不可变版本并替换同一策略的上一发布版本。助手发生变化时先撤销旧助手范围，再授予新助手，不能累加为隐式越权。
- 合成状态保存失败、普通成员越权、助手未发布、成员不可用或未生成预览时，策略保持原状态。

## 查询配额

- ADR-0018 明确查询配额来自受控部署配置，当前产品不提供在线修改。因此原清单中的“调整查询配额”已修正为“查看配额规则”。
- 页面只读展示 UTC 每日已接受请求上限、最大并发运行和运行租约。请求一经接受即消耗当日额度，后续失败或拒答不返还。
- 目录只有一个普通分页，展示合成运行编号、助手名称、终态和耗时；不展示问题、回答、引用正文、模型原始响应、模型修订或租户内部标识。

## 查询诊断

- 诊断来自运行终态原子写入的历史事实，页面不重新检索，也不根据当前授权或配置推断过去结果。
- 允许披露候选收集状态、授权后候选数量、授权判定、Chat/Embedding 修订和引用校验结果；拒绝态不确认运行、策略或模型修订是否存在。
- 已回答运行只读展示结论，不提供修复入口。拒答或失败运行可以建立修复事项，分类默认匹配当前失败阶段。
- 修复事项只保存运行引用、失败阶段、分类、候选数量、事项名称和负责人；同一运行与分类的未关闭事项幂等返回，不复制问题、回答、引用或供应商错误。

## 验收边界

- 状态测试覆盖派生知识库、切换助手撤销旧授权、预览门禁、不可变版本、越权、存储失败、只读配额、冻结诊断和修复事项去重。
- 浏览器测试覆盖保存、预览、发布、刷新恢复、配额弹窗无编辑控件、运行选择、诊断修复、拒绝态、不可用态和 390/1024/1440 三档视口。
- 原型不执行真实授权查询、配额扣减、模型调用、查询重放或工单创建，不能作为生产安全、容量或性能结论。
