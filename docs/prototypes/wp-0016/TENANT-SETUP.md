# WP-0016 租户开通与独立设置

## 当前边界

本轮按 ADR-0078 修正人工拒绝项，仍为 7/5/7 的可丢弃 OpenDesign 原型，不修改生产合同。

1. 新建租户：租户信息 → 配额设置 → 管理员账号。直接输入新账号和演示口令，不再选择已有“合资格”账户。
2. 最后一步确认后，租户、人员身份、管理员资格一次提交；重名、非法配额、口令不一致、无平台权限和存储故障均不留下部分对象。
3. 非秘密草稿可回退、刷新、取消；密码仅在最后一步输入，提交后清空，不写入草稿。
4. 租户设置为概览、管理员、资源配额、可用功能、登录安全五页。通过 URL 固定租户，各页独立保存，不聚合一个大保存请求。
5. 配额不能低于已用量。会话有效期、失败次数和锁定时长可编辑；隔离、权限校验、凭据不回显不能关闭。
6. 平台账户页只管理平台账户；租户管理员账号由平台在当前租户的管理员页治理。普通成员账号创建/重置的新权限尚未确认，不能从聊天推断授权。
7. 租户概览提供带编码的管理员登录入口；平台、租户和普通用户登录彼此可发现，但入口本身不授予权限。

## 原型测试入口

- `#tenant-create-form` 与 `[data-tenant-step]` 表达真实步骤。
- `createTenant(input, actorAccountId)` 接收组织信息、配额、管理员输入与确认；仅平台账号可开通，原子保存合成状态。
- `createAccount(input, actorAccountId)` 在平台目录只创建平台账户。
- `saveTenantQuotas`、`saveTenantSecurity`、功能草稿提交分别维护各自白名单字段；不改变其他设置。
- `platformTenantId` 由共享详情上下文恢复；分页 URL 不充当权限边界。
- `scripts/account-entry.test.mjs`、`scripts/platform-usability.browser.test.cjs` 覆盖新职责，既有配额、登录和租户隔离专项继续回归。

这些都是可丢弃原型的测试 seam，不是新生产 API。正式凭据初始化与事务边界须在对应后续实施包冻结。

## 验收

核对创建 → 查看 → 编辑单项 → 刷新 → 管理员登录 → 空工作区连续路径。另测取消、错误定位、同排对齐、390/1024/1440、reduced-motion 和密码不入存储。截图只用于临时目视检查，人工拒绝不因自动测试通过而失效。
